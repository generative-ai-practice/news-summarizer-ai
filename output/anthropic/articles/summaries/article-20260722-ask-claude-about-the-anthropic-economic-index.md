# Ask Claude about the Anthropic Economic Index

## Key Points
- Anthropicは、AIと仕事に関する疑問に実データで答えるための「Anthropic Economic Index」のClaudeコネクタをリリースしました。
- このコネクタにより、ユーザーはClaudeを通じてAIが経済でどのように利用されているかを示すデータを直接探索できるようになります。
- ユーザーは「どの職種がAIを最も利用しているか？」や「教師はClaudeをどのようなタスクに利用しているか？」といった具体的な質問をClaudeに投げかけることができます。
- コネクタはclaude.aiのメニューから簡単に有効化でき、インストール不要で任意のClaudeモデルとの会話で使用可能です。
- IndexのデータはClaudeの利用パターンに基づいているため、労働市場全体を反映するものではないという限界があり、Claudeはその情報源と限界をユーザーに提示します。
