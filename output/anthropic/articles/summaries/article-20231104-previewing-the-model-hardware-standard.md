# Previewing the Model Hardware Standard

## Key Points
- AIエージェントが物理デバイスを安全に操作するための共有仕様であるModel Hardware Standard (MHS) の研究プレビューが、科学研究機関と先進的メーカー向けに開始されました。
- MHSは、従来の数週間から数ヶ月かかっていたハードウェア統合作業を数時間〜数分に短縮し、AIエージェントによる複数の機器の自律的な操作を可能にします。
- 標準化されたドライバーと自然言語によるデバイス特性のタグ付けにより、AIエージェントは未知のデバイスも安全に操作できる情報を得られ、Model Context Protocolなどの標準プロトコルでアクセスできます。
- Genentechでの創薬実験、ワシントン大学でのラボ機器遠隔監視、カーネギーメロン大学での用量反応曲線測定、QuEra Computingでの量子レーザー安定化など、様々な分野でMHSの初期導入事例が報告されており、大幅な効率改善が見られました。
- Claudeの物理的推論の限界やプログラミングインターフェースを持たないハードウェアへの対応など、オープンソース化に向けたさらなる安全評価と技術的改善が進められています。
