# Introducing Claude Opus 4.7

## Key Points
- Claude Opus 4.7は、高度なソフトウェアエンジニアリングタスクにおいてOpus 4.6から大幅に性能が向上しており、複雑で長時間のタスクを厳密かつ一貫して処理し、指示に正確に従い、自己検証能力を持つ。
- モデルの視覚能力も大幅に改善され、最大2,576ピクセル（約3.75メガピクセル）の高解像度画像を認識でき、より高品質なインターフェース、スライド、ドキュメントの生成が可能。
- サイバーセキュリティに関しては、Claude Mythos Previewよりも能力が控えめに設定されており、禁止された高リスクな利用を自動的に検出・ブロックする安全対策が導入されている。
- Opus 4.7は、全てのClaude製品、API、Amazon Bedrock、Google Cloud Vertex AI、Microsoft Foundryで利用可能で、価格はOpus 4.6と同額（入力100万トークンあたり5ドル、出力100万トークンあたり25ドル）。
- 新機能として、推論とレイテンシーのバランスを調整する`xhigh`エフォートレベル、APIでのタスク予算（パブリックベータ）、Claude Codeでの`/ultrareview`コマンドとMaxユーザー向けオートモードが追加された。
