# Expanding the Cyber Verification Program

## Key Points
- Anthropicは、資格のあるセキュリティプロフェッショナル向けに高度なサイバー機能と緩和されたブロック分類器を提供する、新しい拡張版「Cyber Verification Program (CVP)」を2026年10月6日に発表しました。
- CVPは「Defense Access」「Red Team Access」「Specialized Access」の3つのアクセスティアで構成され、Claude Opus 5.5、Claude Sonnet 5.5、Claude Mythos 5.1などの高性能モデルへのアクセスを提供します。
- 一般公開モデルの厳格な安全対策とは異なり、CVPは防御的なサイバー作業や承認された侵入テストに対してブロックレベルを調整し、防御者がより強力なツールを利用できるようにします。
- CyScenarioBenchによるテストでは、Red Team Accessティアでブロックなしで高いタスク完了率を示し、先行プログラムであるProject Glasswingは2026年4月から7月の間に129,000件以上の脆弱性特定に貢献しました。
- プログラム参加組織はデータ保持が義務付けられていますが、2026年秋に提供予定のEnterprise Frontier Safeguards (EFS)により、ゼロデータ保持でのデータ管理が可能になります。
