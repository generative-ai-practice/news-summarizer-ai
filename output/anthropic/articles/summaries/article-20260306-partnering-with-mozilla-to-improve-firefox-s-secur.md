# Partnering with Mozilla to improve Firefox’s security

## Key Points
- AnthropicのAIモデル「Claude Opus 4.6」はMozillaと協力し、2週間でFirefoxの22件の脆弱性を発見しました。そのうち14件は高Severityに分類され、2025年に修正されたFirefoxの高Severity脆弱性の約5分の1を占めます。
- このコラボレーションにより、AIが複雑なソフトウェアのセキュリティ脆弱性を非常に迅速に特定し、修正プロセスを加速できることが実証されました。Mozillaは、発見された脆弱性の一部をFirefox 148.0で修正しました。
- Claudeは脆弱性の発見には優れていますが、それらを悪用（exploit）する能力はまだ限定的で、発見にかかるコストよりも悪用作成にかかるコストの方が桁違いに高いとされています。
- AIを活用したサイバーセキュリティのベストプラクティスとして、AIの作業を検証する「タスク検証ツール」の利用と、報告時に最小テストケース、概念実証、候補パッチを含めることが推奨されています。
- 将来的にAIの悪用能力が向上する可能性があるため、開発者はソフトウェアのセキュリティ強化を加速し、悪意ある行為者によるAIモデルの悪用を防ぐための追加的な安全策を検討する必要があります。
