# Project Glasswing: An initial update

## Key Points
- Project Glasswingでは、Claude Mythos Previewを活用し、約50のパートナーと共同で1万件以上の高または重大度のソフトウェア脆弱性を発見し、バグ発見率を大幅に向上させました。
- 1,000以上のオープンソースプロジェクトをスキャンした結果、推定6,202件の脆弱性（うち90.6%が真陽性と確認された高・重大度脆弱性1,587件を含む）が発見され、AIによる脆弱性検出の効率性が示されました。
- AIが脆弱性を迅速に発見できる一方で、人間による検証、開示、パッチ適用がボトルネックとなり、この時間差がサイバーセキュリティにおける新たなリスクを生み出しています。
- Anthropicは、Claude Enterprise顧客向けにClaude Securityのベータ版をリリースし、3週間で2,100件以上の脆弱性を修正しました。また、Project Glasswingで使用された高度なツールも一部の顧客向けに提供し、防御側の能力向上を支援しています。
- Mythosクラスモデルの一般公開は、現在十分なセーフガードが開発されていないため見送られていますが、将来的にはより強固なセーフガードを開発した上で一般公開し、ハッキングが少ない、より安全な世界を目指しています。
