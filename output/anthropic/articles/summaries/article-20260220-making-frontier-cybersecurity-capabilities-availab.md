# Making frontier cybersecurity capabilities available to defenders

## Key Points
- Web版Claude Codeの新機能「Claude Code Security」が限定研究プレビューとして提供され、コードベースのセキュリティ脆弱性をスキャンし、人間がレビューするソフトウェアパッチを提案します。
- このツールは、従来のルールベースのツールが見逃すような、コードの相互作用やデータフローに基づく複雑な脆弱性を人間のように理解・推論して特定できます。
- 検出された脆弱性は多段階の検証プロセスを経てアナリストに提示され、修正には常に人間の承認が必要であり、Claudeは発見内容に確信度も提供します。
- Anthropicは、Capture-the-Flagイベントや重要インフラ防御の研究を通じてClaudeのサイバー防御能力を向上させ、Claude Opus 4.6を用いてオープンソースコードベースで500以上の未検出脆弱性を発見しました。
- AIが攻撃にも利用される将来において、防御側がAIを活用して脆弱性を迅速に特定し修正することの重要性が高まっており、本機能はそのための第一歩となります。
