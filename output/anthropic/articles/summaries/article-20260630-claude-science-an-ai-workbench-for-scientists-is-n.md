# Claude Science, an AI workbench for scientists, is now available

## Key Points
- Claude Scienceは、科学者向けに設計されたAIワークベンチで、研究者が常用するツールやパッケージを統合し、監査可能な成果物を生成し、柔軟な計算リソースへのアクセスを提供します。
- このアプリは、断片化された研究ツールを単一の環境に統合し、文献分析、多段階研究の実行、詳細な成果物生成、および図や原稿の反復的な修正を可能にします。すべての出力には、結果の検証と再現を容易にする監査可能な履歴が含まれます。
- ゲノミクス、単一細胞、プロテオミクス、構造生物学、ケモインフォマティクスなど60以上の分野に特化したスキルとコネクタが事前設定されており、NVIDIAのBioNeMo Agent Toolkitや研究室独自の信頼性の高いツールとの連携も可能です。
- 大規模な分析に必要な計算リソースの管理を自動化し、ラップトップ、Linuxボックス、HPCログインノードなど、研究室の既存インフラ上で分析を単一GPUから数百のGPUへとオンデマンドでスケーリングできます。
- Claude Scienceは、2026年6月30日よりClaude Pro、Max、Team、Enterpriseユーザー向けにmacOSおよびLinuxのベータ版として提供され、最大50のAI for Scienceプロジェクトには最大$30,000のクレジットとModalからの$2,000のコンピューティング支援が提供されます（応募締め切りは2026年7月15日）。
