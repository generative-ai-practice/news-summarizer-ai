# Apple’s Xcode now supports the Claude Agent SDK

## Key Points
- AppleのXcode 26.3において、Claude Agent SDKのネイティブ統合が導入されました。これにより、開発者はXcode内でClaude Codeの全機能（サブエージェント、バックグラウンドタスク、プラグインを含む）を直接利用できます。
- 以前のXcode 26でのClaude Sonnet 4は単一のターンごとのリクエストに限定されていましたが、今回の統合により、より洗練された長期的な自律コーディングタスクが可能になりました。
- Claudeは、Xcode Previewsをキャプチャして視覚的検証を行うことで、SwiftUIなどのインターフェース構築においてデザイン意図に近い高品質なコードを生成できます。
- プロジェクトのファイル構造全体を探索し、Appleプラットフォームの多様なフレームワーク間での連携を理解し、アプリ全体のアーキテクチャを考慮してコード変更を提案・実行できます。
- Claudeに目標を与えることで、タスクを自律的に分解し、ファイルを変更し、必要に応じてAppleのドキュメントを検索しながら、タスクが完了するまで作業を継続できるため、開発者の時間を大幅に節約します。
