# Agents for financial services

## Key Points
- Anthropicは、ピッチブック作成、KYCファイルスクリーニング、月末締めなど、金融サービスにおける時間のかかる作業を効率化する10種類の既製エージェントテンプレートをリリースしました。
- ClaudeはMicrosoft Excel、PowerPoint、Word、およびOutlook（近日公開）向けのアドインを通じてMicrosoft 365と連携し、アプリケーション間でコンテキストを自動的に引き継ぎ、作業の円滑な移行を可能にします。
- 金融市場データ、調査プラットフォーム、企業の内部システムにアクセスするための新しいコネクタやMoody'sのMCPアプリを含むパートナーエコシステムを拡大しました。
- これらの新機能は、金融タスクで最先端の性能を誇り、Vals AIのFinance Agentベンチマークで64.37%を達成したClaude Opus 4.7と組み合わせて利用することで最高の効果を発揮します。
