# Expanding Project Glasswing

## Key Points
- Project Glasswingは、約50の初期パートナーから、15カ国以上に拠点を置く約150の新規組織へと拡大されました。
- 新規パートナーには、電力、水、医療、通信、ハードウェアなどの重要インフラプロバイダーや、他の組織が依存するコードベースを管理するベンダーが含まれます。
- 初期のProject Glasswingパートナーは、Claude Mythos Previewを用いて10,000以上の高・重大度セキュリティ脆弱性を発見しました。
- このプログラムは、安価で高速なAIモデルがサイバーセキュリティを変革する現状に対応するため、防御側が適応するための新しい運用規範を促進することを目的としています。
- 今後、AnthropicはMythosレベルのサイバー防御機能を一般に安全に提供し、Project Glasswingをさらに拡大する計画です。
