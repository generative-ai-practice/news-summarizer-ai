## Updates (translated)
# 2026-07-17 リリースノート

- Claude Consoleの従来のWorkbench ([platform.claude.com/workbench](https://platform.claude.com/workbench)) は廃止され、2026年8月17日にアクセスが終了します。保存されたプロンプト、変数、評価は、更新された[Workbench](https://platform.claude.com/playground)ではサポートされません。保持したいデータは、バナーから、または組織設定の下からエクスポートできます。詳細については、Claudeヘルプセンターの[Workbenchの使用方法](https://support.claude.com/en/articles/8606378-how-do-i-use-the-workbench)をご覧ください。
- プロンプトの生成、改善、テンプレート化のための実験的なプロンプトツールAPI (`/v1/experimental/generate_prompt`、`/v1/experimental/improve_prompt`、`/v1/experimental/templatize_prompt`) は、2026年8月17日にWorkbenchとともに廃止されます。削除後、これらのエンドポイントへのリクエストはエラーを返します。
