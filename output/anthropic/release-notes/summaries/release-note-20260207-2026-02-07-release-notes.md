# 2026年2月7日 リリースノート

- 当社は、Opus 4.6向けに、`speed`パラメーターを介して大幅に高速な出力トークン生成を提供する[高速モード](https://platform.claude.com/docs/en/build-with-claude/fast-mode)の研究プレビュー版を開始しました。高速モードは、プレミアム料金で最大2.5倍高速です。ご興味のあるお客様は、[待機リスト](https://claude.com/fast-mode)にご参加ください。
