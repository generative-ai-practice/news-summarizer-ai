## Updates (translated)
# 2026年8月18日 リリースノート

- Claudeコンソールにおいて、ワークベンチが[Playground](https://platform.claude.com/playground)になりました。PlaygroundはすべてのMessages APIパラメータをサポートしており、コード実行やウェブ検索といったAPI機能を示すテンプレートを含んでいます。これは、APIを理解しそれを使って構築するのに役立つよう、各実行における完全なSDKリクエストとAPIレスポンスを表示します。詳細については、[Claudeヘルプセンター](https://support.claude.com/en/articles/8606378-how-do-i-use-playground)をご覧いただくか、[platform.claude.com/playground](https://platform.claude.com/playground)でお試しください。
