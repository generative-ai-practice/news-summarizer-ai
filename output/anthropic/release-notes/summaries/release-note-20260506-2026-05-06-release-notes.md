## Updates (translated)
# 2026年5月6日 リリースノート

-   [マルチエージェントセッション](https://platform.claude.com/docs/en/managed-agents/multi-agent)と[成果](https://platform.claude.com/docs/en/managed-agents/define-outcomes)が、標準の `managed-agents-2026-04-01` ベータヘッダーの下でパブリックベータになりました。
-   `mcp_oauth` 認証情報で、Vault認証情報のバックグラウンド更新がサポートされるようになりました。詳細については、[Vaultsで認証](https://platform.claude.com/docs/en/managed-agents/vaults)を参照してください。
-   Claude Managed Agents のWebhooksがサポートされるようになりました。Webhookイベントタイプには、セッションとVaultのライフサイクルイベントが含まれます。詳細については、[Webhooksの購読](https://platform.claude.com/docs/en/managed-agents/webhooks)を参照してください。
-   追加のフィルタリングとソートオプションがサポートされるようになりました。セッションはステータスでフィルタリングでき、イベントはタイプでフィルタリングできます。イベントは作成時間でフィルタリングできるようになりました。
