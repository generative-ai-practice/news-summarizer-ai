## Updates (translated)
# 2026年5月6日 リリースノート

-   [マルチエージェントセッション](https://platform.claude.com/docs/en/managed-agents/multi-agent)および[成果](https://platform.claude.com/docs/en/managed-agents/define-outcomes)が、標準の`managed-agents-2026-04-01`ベータヘッダーの下でパブリックベータになりました。
-   Vault認証情報のバックグラウンド更新が、`mcp_oauth`認証情報でサポートされるようになりました。詳細については、[Vaultsで認証する](https://platform.claude.com/docs/en/managed-agents/vaults)を参照してください。
-   Claudeマネージドエージェント用のWebhookがサポートされるようになりました。Webhookのイベントタイプには、セッションおよびVaultのライフサイクルイベントが含まれます。詳細については、[Webhookを購読する](https://platform.claude.com/docs/en/managed-agents/webhooks)を参照してください。
-   追加のフィルタリングおよびソートオプションがサポートされるようになりました。セッションはステータスでフィルタリングでき、イベントはタイプでフィルタリングできます。イベントは作成時間でフィルタリングできるようになりました。
