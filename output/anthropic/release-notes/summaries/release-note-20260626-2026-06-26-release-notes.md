## Updates (translated)
# 2026年6月26日 リリースノート

-   Claude API全体で[レート制限](https://platform.claude.com/docs/en/api/rate-limits)を引き上げました。Claude SonnetとClaude Haikuのレート制限が、すべての使用ティアでClaude Opusと一致するようになりました。また、使用ティアはStart、Build、Scaleの3つに統合されました。ほとんどの組織がより高いティアに移行し、以前より低い制限を受ける組織はなく、いかなる対応も不要です。お客様のティアと現在の制限は、[Claudeコンソール](https://platform.claude.com/settings/limits)で確認できます。
