## Updates (translated)
# 2026年7月10日 リリースノート

- フィルターの例、イベントペイロードの例、および2つの保存理由コード（`policy_violation_investigation`、`csae_report`）を追加して、[アクセス透明性](https://platform.claude.com/docs/en/manage-claude/access-transparency)の`cmek_preserve`イベントに関するドキュメントを拡張しました。このドキュメントでは、保存が人間のレビュー担当者によって開始されたか、自動化された安全パイプラインによって開始されたかに関わらず、保存イベントが書き込まれることも明確にしています。[CMEKコンテンツ保存](https://platform.claude.com/docs/en/manage-claude/access-transparency#cmek-content-preservation)をご覧ください。
