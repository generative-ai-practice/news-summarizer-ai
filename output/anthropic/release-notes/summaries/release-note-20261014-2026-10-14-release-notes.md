# 2026-10-14 リリースノート

- オブザーバビリティバックエンドでMessages APIリクエストとClaudeマネージドエージェントのセッションをトレースできるように、[OpenTelemetryエクスポート](https://platform.claude.com/docs/en/manage-claude/opentelemetry)のベータ版をリリースしました。Claude SDKは、Python、TypeScript、C#、Go、Java、PHP、およびRubyでスパンを生成します。APIからスパンを取得するには、Claudeコンソールで[OpenTelemetry送信先を追加](https://platform.claude.com/docs/en/manage-claude/opentelemetry/api#add-a-destination)してください。
- Claudeマネージドエージェントの[スケジュールされたデプロイ](https://platform.claude.com/docs/en/managed-agents/scheduled-deployments)が、[Claude Platform on AWS](https://platform.claude.com/docs/en/build-with-claude/claude-platform-on-aws#claude-managed-agents)で利用可能になりました。
