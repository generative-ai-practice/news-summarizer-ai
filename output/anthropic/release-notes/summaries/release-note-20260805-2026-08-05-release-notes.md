## Updates (translated)
# 2026年8月5日 リリースノート

- 推論フックは、Claude Enterprise組織向けにベータ版になりました。Claudeを組織のAIセキュリティサーバーに向け、claude.ai、Cowork、Claude Code全体で管理される各プロンプトは、推論が進む前にサーバーの許可または拒否の判断を待機します。リクエストは署名され、障害処理は構成可能であり、すべての拒否はコンプライアンスの[アクティビティフィード](https://platform.claude.com/docs/en/manage-claude/compliance-activity-feed)に記録されます。[推論フック](https://platform.claude.com/docs/en/manage-claude/inference-hooks)をご覧ください。
