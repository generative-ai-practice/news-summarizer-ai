## Updates (translated)
# 2026年4月7日 リリースノート

- [Claude Mythos Preview](https://anthropic.com/glasswing) が、[Project Glasswing](https://anthropic.com/glasswing) の一環として、防御的サイバーセキュリティ作業向けのゲート付きリサーチプレビューとして利用可能になったことを発表しました。アクセスは招待制です。
- [Messages API](https://platform.claude.com/docs/en/api/messages) が、Amazon Bedrock でリサーチプレビューとして利用可能になりました。`/anthropic/v1/messages` にある新しいAmazon Bedrock上のClaudeエンドポイントは、ファーストパーティのClaude APIと同じリクエスト形式を使用し、オペレーターによるアクセスがゼロのAWSマネージドインフラストラクチャ上で動作します。`us-east-1` で利用可能です。アクセスをリクエストするには、Anthropicのアカウントエグゼクティブにご連絡ください。詳細については、[Claude in Amazon Bedrock](https://platform.claude.com/docs/en/build-with-claude/claude-in-amazon-bedrock) をご覧ください。
