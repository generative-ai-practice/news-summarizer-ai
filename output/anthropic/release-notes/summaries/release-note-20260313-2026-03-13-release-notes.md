## Updates (translated)
# 2026-03-13 リリースノート

- [100万トークンコンテキストウィンドウ](https://platform.claude.com/docs/en/build-with-claude/context-windows)が、Claude Opus 4.6およびSonnet 4.6で標準価格で一般提供されるようになりました。20万トークンを超えるリクエストは、これらのモデルでベータヘッダーなしで自動的に動作します。100万トークンコンテキストウィンドウは、Claude Sonnet 4.5およびSonnet 4では引き続きベータ版です。
- すべてのサポート対象モデルで、専用の100万トークンレート制限を撤廃しました。標準のアカウント制限が、すべてのコンテキスト長に適用されるようになりました。
- 100万トークンコンテキストウィンドウを使用する際、メディア制限をリクエストあたり画像またはPDFページ100枚から600枚に引き上げました。
