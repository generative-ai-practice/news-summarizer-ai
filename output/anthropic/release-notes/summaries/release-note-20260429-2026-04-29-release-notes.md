# 2026年4月29日 リリースノート

- [Claude APIスキル](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/claude-api-skill)をリリースしました。これは、オープンソースの[エージェントスキル](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)で、Messages APIとClaude Managed Agents上で構築するための最新の参考資料を8言語でClaudeに提供します。このスキルはClaude Codeにバンドルされており、[Anthropicスキルリポジトリ](https://github.com/anthropics/skills/tree/main/skills/claude-api)で利用可能です。
