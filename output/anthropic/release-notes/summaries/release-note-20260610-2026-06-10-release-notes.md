# 2026年6月10日 リリースノート

- [セルフホスト型サンドボックス](https://platform.claude.com/docs/en/managed-agents/self-hosted-sandboxes)の保留中の作業をリスト表示する`GET /v1/environments/{id}/work`エンドポイントが、[Claude Platform on AWS](https://platform.claude.com/docs/en/build-with-claude/claude-platform-on-aws)で利用可能になりました。それを承認する`GetEnvironment`アクションについては、[Claude Platform on AWS の IAM アクション](https://platform.claude.com/docs/en/api/claude-platform-on-aws-iam-actions)を参照してください。
