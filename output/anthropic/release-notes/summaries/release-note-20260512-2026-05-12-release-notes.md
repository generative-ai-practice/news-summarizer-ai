## Updates (translated)
# 2026年5月12日 リリースノート

- [高速モード](https://platform.claude.com/docs/en/build-with-claude/fast-mode)（研究プレビュー）がClaude Opus 4.7に対応しました。`speed: "fast"` を `model: "claude-opus-4-7"` および `fast-mode-2026-02-01` ベータヘッダーとともに設定することで、プレミアム価格で出力トークン生成が大幅に高速化されます。料金、レート制限、およびアクセスはOpus 4.6高速モードと同じです。ご希望のお客様は[ウェイティングリスト](https://claude.com/fast-mode)にご参加ください。
