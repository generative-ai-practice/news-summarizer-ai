```markdown
# 2026-03-30 リリースノート

- 2026年4月30日をもって、Claude Sonnet 4.5およびClaude Sonnet 4向けの100万トークンコンテキストウィンドウベータ版を廃止します。この日以降、これらのモデルで`context-1m-2025-08-07`ベータヘッダーを含むリクエストは400エラーを返します。100万トークンのコンテキストウィンドウを引き続き使用するには、[Claude Sonnet 4.6](https://platform.claude.com/docs/en/about-claude/models/overview#latest-models-comparison)または[Claude Opus 4.6](https://platform.claude.com/docs/en/about-claude/models/overview#latest-models-comparison)に移行してください。これらは、ベータヘッダーなしの標準価格で、完全な100万トークンコンテキストウィンドウをサポートしています。
```
