## Updates (translated)
# 2026年6月25日 リリースノート

- Claude Opus 4.7向けの[高速モード](https://platform.claude.com/docs/en/build-with-claude/fast-mode)を非推奨とし、2026年7月24日に削除します。削除後、`claude-opus-4-7`への`speed: "fast"`を伴うリクエストはエラーを返します。Claude Opus 4.8向けの高速モードに移行してください。詳細については、[高速モード](https://platform.claude.com/docs/en/build-with-claude/fast-mode#supported-models)をご覧ください。
