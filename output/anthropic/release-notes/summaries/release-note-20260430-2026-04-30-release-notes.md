## Updates (translated)
# 2026-04-30 リリースノート

- Claude Sonnet 4.5およびClaude Sonnet 4向けの1Mトークンコンテキストウィンドウベータ版（`context-1m-2025-08-07`）を廃止しました。これらのモデルではベータヘッダーは効果がなくなり、標準の200kトークンコンテキストウィンドウを超えるリクエストはエラーを返します。1Mコンテキストウィンドウを使用するには、[Claude Sonnet 4.6](https://platform.claude.com/docs/en/about-claude/models/overview#latest-models-comparison)または[Claude Opus 4.6](https://platform.claude.com/docs/en/about-claude/models/overview#latest-models-comparison)に移行してください。これらのモデルでは、ベータヘッダーは不要で標準料金で一般提供されています。
