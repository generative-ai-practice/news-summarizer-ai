## Updates (translated)
# 2026-07-08 リリースノート

- [Claude Console](https://platform.claude.com/settings/keys)でAPIキーまたは管理者APIキーを作成する際に、有効期限を設定できるようになりました。プリセット、カスタム期間、または「期限なし」を選択してください。有効期間が7日以上のキーについては、Anthropicは有効期限が切れる前に作成者へメールで通知します。既存のキーには影響ありません。管理者APIは、各キーの有効期限を[`expires_at`](https://platform.claude.com/docs/en/api/admin/api_keys/list)フィールドで報告します。[認証](https://platform.claude.com/docs/en/manage-claude/authentication#key-expiration)を参照してください。
