# 2026年9月18日 リリースノート

- [Compliance API](https://platform.claude.com/docs/en/manage-claude/compliance-api) のローカルセッションエンドポイントが、Claude Enterprise組織向けベータ版として、既存のCompliance Access Keyと`read:compliance_user_data`スコープを使用して、ChromeセッションにおけるClaudeのトランスクリプト（`product_surface`値は`claude_in_chrome`）も返すようになりました。詳細については、[ユーザーのマシン上のセッション](https://platform.claude.com/docs/en/manage-claude/compliance-sessions#retrieve-local-sessions)を参照してください。
