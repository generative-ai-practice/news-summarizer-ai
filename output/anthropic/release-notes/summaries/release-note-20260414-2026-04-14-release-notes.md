# 2026年4月14日 リリースノート

- 当社は、Claude Sonnet 4モデル (`claude-sonnet-4-20250514`) およびClaude Opus 4モデル (`claude-opus-4-20250514`) の非推奨化を発表しました。Claude APIにおける提供終了は2026年6月15日に予定されています。それぞれ[Claude Sonnet 4.6](https://platform.claude.com/docs/en/about-claude/models/overview#latest-models-comparison) および[Claude Opus 4.6](https://platform.claude.com/docs/en/about-claude/models/overview#latest-models-comparison) への移行を推奨します。詳細については、[モデルの非推奨化](https://platform.claude.com/docs/en/about-claude/model-deprecations)をご覧ください。
