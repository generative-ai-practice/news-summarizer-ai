## Updates (translated)
# 2026-04-08 リリースノート

- Claude Managed Agentsをパブリックベータ版として公開しました。これは、セキュアなサンドボックス、組み込みツール、およびサーバー送信イベントストリーミングを備えた、Claudeを自律エージェントとして実行するための完全マネージド型のエージェントハーネスです。APIを介してエージェントの作成、コンテナの設定、セッションの実行が可能です。すべてのエンドポイントには、`managed-agents-2026-04-01`ベータヘッダーが必要です。詳細については、[Claude Managed Agentsの概要](https://platform.claude.com/docs/en/managed-agents/overview)をご覧ください。
- `ant` CLIを公開しました。これはClaude API用のコマンドラインクライアントで、Claude APIとのより高速な対話、Claude Codeとのネイティブ統合、およびYAMLファイルでのAPIリソースのバージョン管理を可能にします。詳細については、[CLIリファレンス](https://platform.claude.com/docs/en/api/sdks/cli)をご覧ください。
