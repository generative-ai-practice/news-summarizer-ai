# 2026-05-11 リリースノート

- AWS上でClaude Platformをローンチしました。これにより、Claude APIがAWSを通じてアクセス可能なAnthropic管理のインフラストラクチャで利用可能になり、AWS請求およびIAM認証が適用されます。Messages API、Files API、Message Batches API、Claude Managed Agents、Agent Skills、コード実行、ツール使用の全機能に、ネイティブのAWSエンドポイントを通じてアクセスできます。詳細については、[AWS上のClaude Platform](https://platform.claude.com/docs/en/build-with-claude/claude-platform-on-aws)をご覧ください。
