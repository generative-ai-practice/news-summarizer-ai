- Released[prompt-to-voice](https://platform.openai.com/api/docs/guides/custom-voices#create-a-voice-from-a-description)for all API customers. Create a custom voice from a text description through the API or voice Playground, then reuse it in GPT-Live sessions. Creating a prompt-generated voice is free; speech generation uses regular GPT-Live session billing.
- Added nine[natural voices for GPT-Live](https://platform.openai.com/api/docs/guides/live-conversations#voice-options): Nuri, Juni, and Flitz (German); Brise and Sillage (French); Nira (Hindi); Harema and Shida (Japanese); and Noeul (Korean).
