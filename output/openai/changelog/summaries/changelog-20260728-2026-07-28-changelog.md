# 2026-07-28 更新履歴

- 正確なファイル文字起こしと、コミット済みのRealtimeの応答の最終文字起こしに対応する[GPT Transcribe](https://platform.openai.com/api/docs/models/gpt-transcribe)と、低遅延ストリーミング文字起こしに対応する[GPT Live Transcribe](https://platform.openai.com/api/docs/models/gpt-live-transcribe)をリリースしました。
- 両モデルは、自由形式の文字起こしコンテキスト、キーワードヒント、および複数の想定入力言語をサポートしています。[文字起こしガイド](https://platform.openai.com/api/docs/guides/transcription)で、サポートされている出力とワークフローを比較してください。
