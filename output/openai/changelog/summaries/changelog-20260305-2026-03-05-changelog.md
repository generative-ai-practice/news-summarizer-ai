# 2026-03-05 変更履歴

- プロフェッショナルな作業向けに開発された当社の最新フロンティアモデルである[GPT-5.4](https://platform.openai.com/api/docs/models/gpt-5.4)をChat Completions APIとResponses APIでリリースし、さらに、より多くの計算資源から恩恵を受ける困難な問題向けに[GPT-5.4 pro](https://platform.openai.com/api/docs/models/gpt-5.4-pro)をResponses APIでリリースしました。
- 次のものもリリースしました:
- Responses APIにおける[ツール検索](https://platform.openai.com/api/docs/guides/tools-tool-search)。これにより、モデルは大規模なツール群のロードを実行時まで遅延させることができ、トークン使用量を削減し、キャッシュパフォーマンスを維持し、レイテンシを改善します。
- GPT-5.4における、スクリーンショットベースのUIインタラクションを可能にするResponses APIの`computer`ツールを介した組み込みの[コンピュータ使用](https://platform.openai.com/api/docs/guides/tools-computer-use)サポート。
- 長時間実行されるエージェントワークフロー向けの、1Mトークンのコンテキストウィンドウとネイティブな[圧縮](https://platform.openai.com/api/docs/guides/compaction)サポート。
