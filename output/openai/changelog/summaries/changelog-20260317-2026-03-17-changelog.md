## Updates (translated)
# 2026-03-17 変更履歴

- Chat Completions および Responses API に[GPT-5.4 mini](https://platform.openai.com/api/docs/models/gpt-5.4-mini)と[GPT-5.4 nano](https://platform.openai.com/api/docs/models/gpt-5.4-nano)をリリースしました。GPT-5.4 mini は、GPT-5.4クラスの機能を、大量のワークロードに対応する、より高速で効率的なモデルにもたらします。一方、GPT-5.4 nano は、速度とコストが最も重要となる、単純な大量タスク向けに最適化されています。
- GPT-5.4 mini は、[ツール検索](https://platform.openai.com/api/docs/guides/tools-tool-search)、組み込みの[コンピューター使用](https://platform.openai.com/api/docs/guides/tools-computer-use)、および[圧縮](https://platform.openai.com/api/docs/guides/compaction)をサポートしています。GPT-5.4 nano は圧縮をサポートしますが、ツール検索またはコンピューター使用はサポートしません。
