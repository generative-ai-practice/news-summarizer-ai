# 2026-05-12 変更履歴

- DALL·EモデルのスナップショットおよびRealtime APIベータが非推奨となりました。
- DALL·Eモデルのスナップショット`dall-e-2`および`dall-e-3`は非推奨となり、2026年5月12日にAPIから削除されました。代わりに`gpt-image-2`、`gpt-image-1`、または`gpt-image-1-mini`の使用を推奨します。
- Realtime APIベータは非推奨となり、2026年5月12日にAPIから削除されました。もしベータインターフェースをまだご使用の場合は、リリース版のRealtime APIへ移行してください。[移行ガイド](https://platform.openai.com/api/docs/guides/realtime#beta-to-ga-migration)および完全な[非推奨ページ](https://platform.openai.com/api/docs/deprecations)をご覧ください。
