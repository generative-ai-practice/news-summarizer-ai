# 2026年7月20日 変更履歴

- OpenAI APIプラットフォームに組織およびプロジェクトの利用上限を追加しました。APIコストを監視するために月間の利用上限を設定したり、組織またはプロジェクトが上限に達した後にAPI応答が失敗するように厳格な制限を適用したりできます。詳細については、[利用上限ガイド](https://platform.openai.com/api/docs/guides/spend-limits)をご覧ください。
