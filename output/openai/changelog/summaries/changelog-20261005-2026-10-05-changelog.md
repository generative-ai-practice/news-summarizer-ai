# 2026-10-05 変更履歴

- APIの[組織設定 > 一般](https://platform.openai.com/settings/organization/general)に、HIPAA準拠サポートのための製品内フローを追加しました。資格のある組織の管理者は、標準の事業提携契約（BAA）に同意し、組織のHIPAA準拠サポートを有効にできるようになりました。資格、対象サービス、および構成要件については、[ヘルプセンター](https://help.openai.com/en/articles/8660679-getting-a-business-associate-agreement-for-the-openai-api)を参照してください。
