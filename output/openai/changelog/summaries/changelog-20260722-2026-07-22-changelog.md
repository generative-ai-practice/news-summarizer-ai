# 2026-07-22 変更履歴

- OpenAI APIプラットフォームにおいて、組織およびプロジェクトに対するハード支出制限を追加しました。追跡された支出が制限に達すると、影響を受けるAPIリクエストが`429`エラーを返すようにする月次上限を設定します。トラフィックが中断される前に通知を受け取るために、支出アラートを使用してください。詳細については、[支出制限ガイド](https://platform.openai.com/api/docs/guides/spend-limits)を参照してください。
