# 2026-06-02 変更履歴

- 2026年6月2日より、対象となるコンテナセッションは、20分間のセッション料金が全額課金されるのではなく、最低5分からの1分単位での課金となります。基となる1分あたりの料金は変更されません。
- この更新は、短いセッションに対する課金をより細かくし、顧客の実質的なコストを削減することを目的としています。
- 現在の組み込みツールの料金は、弊社の[API料金ドキュメント](https://platform.openai.com/api/docs/pricing#built-in-tools)でご確認いただけます。
