# 2026-07-29 変更履歴

- OpenAI APIプラットフォームのリソースをInfrastructure as Codeとして管理するための公式の[OpenAI Terraformプロバイダー](https://platform.openai.com/api/docs/guides/terraform)をリリースしました。
- プロジェクト、ユーザー、グループ、ロール、アクセス割り当て、サービスアカウント、証明書、招待、およびプロジェクトレベルのレート制限をプロビジョニングし、管理します。標準的なTerraformワークフローを使用して、変更を確認して適用し、既存のリソースをインポートし、設定のドリフトを検出して調整します。プロバイダーは[Terraform Registry](https://registry.terraform.io/providers/openai/openai/latest)からインストールしてください。
