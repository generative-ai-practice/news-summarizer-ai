# 2026年8月21日 変更ログ

- APIを利用されているお客様は、グローバル地理設定を持つプロジェクトからのAPIキーとプレフィックス付きドメインを使用することで、個別のリクエストに対してリージョン処理を選択できるようになりました。既存の資格要件、データ保持管理、エンドポイント、およびモデルサポート要件は引き続き適用されます。詳細については、[データ管理ガイド](https://platform.openai.com/api/docs/guides/your-data#select-a-processing-region-per-request)をご覧ください。
