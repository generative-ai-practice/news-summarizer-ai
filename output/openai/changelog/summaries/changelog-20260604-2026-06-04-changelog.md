# 2026-06-04 変更履歴

- Responses APIとChat Completions APIにモデレーションスコアを追加しました。生成リクエストで`moderation`オブジェクトを渡すことで、モデル入力と生成出力の両方のモデレーション結果を同じレスポンスで受け取ることができます。
- 詳細については、[モデレーションガイド](https://platform.openai.com/api/docs/guides/moderation#moderate-generated-content)をご覧ください。
