# How NVIDIA engineers and researchers build with Codex

## Key Points
- NVIDIAのエンジニアと研究者は、GPT-5.5を搭載したCodexを、生産システムの開発や研究アイデアを実行可能な実験へと転換するための主要ツールとして活用しています。
- Codex with GPT-5.5は、より自律的に動作し、複雑なエンジニアリングタスクや長時間のセッションにおいても高い精度を維持し、元のプロンプトに含まれない問題やアイデアを提示する能力を持っています。
- 研究ワークフローにおいて、Codexは研究領域の特定から機械学習実験のスクリプト作成、リモートマシンでの実行までエンドツーエンドのプロセスを自動化し、10倍の速度改善を実現しています。
- また、Codexは古いPythonコードをRustに機械翻訳することで20倍の効率向上を達成するなど、コードの最適化にも貢献しています。
- 現在、4万人のNVIDIA社員がCodexにアクセスしており、エンジニアリングおよび研究チーム全体の作業効率を大幅に加速させています。
