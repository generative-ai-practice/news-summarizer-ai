# Now everyone can put data to work

## Key Points
- ChatGPT Workの新しいData agentは、自然言語の質問だけで企業のデータを分析し、洞察を導き出し、インタラクティブなダッシュボードを構築できます。
- Amazon Redshift、Snowflake、Google BigQueryなどの複数のデータソースに接続し、組織のビジネス用語や指標定義をコンテキストとして活用できます。
- 企業管理者はデータ接続とアクセス権限を細かく制御でき、テーブル、行、列の制限を含む既存のデータ権限がクエリに適用されます。
- このツールは、分析結果の深掘り、ダッシュボードの作成、次のステップの推奨、およびSlackやメールを通じた結果の共有など、一連のデータ活用プロセスを支援します。
- OpenAI社内で広く活用されており、NTT DataやThermo Fisherなどの企業もAlphaプログラムを通じて sales and spending analysisやreporting errorsの特定に利用しています。
