# GPT-5.6 is now the preferred model in Microsoft 365 Copilot

## Key Points
- OpenAIはGPT-5.6を発表し、Microsoft 365 Copilot（Word、Excel、PowerPoint、Chat、Cowork）の新しい推奨モデルとなる。
- このアップデートにより、Microsoft 365ユーザーは日常業務でより高性能なAIアシスタンスを活用し、より質の高い成果物を少ない労力で作成できるようになる。
- GPT-5.6は、トークンあたりの有用な作業量が増え、コストパフォーマンスが向上し、最も複雑なタスクにも対応するオンデマンド機能を提供する。
- MicrosoftはOpenAI APIを通じてGPT-5.6をMicrosoft 365顧客に提供し、両社のパートナーシップをさらに強化していく。
