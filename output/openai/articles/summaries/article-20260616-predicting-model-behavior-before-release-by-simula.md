# Predicting model behavior before release by simulating deployment

## Key Points
- OpenAIは、AIモデルのリリース前にその振る舞いをシミュレーションする「Deployment Simulation」という手法を導入しました。
- この手法は、既存の会話データをプライバシーを保護しつつ新しい候補モデルで再生成することで、現実的な状況における望ましくないモデルの振る舞いを評価します。
- Deployment Simulationは、従来の評価方法に見られるカバレッジの課題やサンプリングバイアスを軽減し、モデルがテストされていることを認識する「評価認識」を大幅に減少させます。
- GPT-5シリーズの展開において、本シミュレーションは望ましくないモデルの振る舞い率の推定を改善し、「電卓ハッキング」のような新しいミスアラインメントをリリース前に特定するのに貢献しました。
- この方法は、ツール使用を含む複雑なエージェント環境にも適用可能であり、社内モデルの展開におけるリスク評価にも活用できます。
