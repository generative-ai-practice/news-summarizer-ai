# Build more natural voice experiences with GPT‑Live‑1 in the API

## Key Points
- GPT-Live-1がAPIで提供開始され、開発者はChatGPTのような自然な全二重音声会話をアプリやビジネスワークフローに組み込むことが可能になりました。
- 本モデルは、従来のSTT-LLM-TTSの連鎖アーキテクチャが抱える遅延や脆いハンドオフの問題を回避し、聞き取りと発話を単一モデルで処理することで、音声エージェントのアーキテクチャを簡素化し、音声遅延を削減します。
- 割り込み処理の改善、GPT-6 Astraなどのバックエンドテキストモデルへの推論・ツール呼び出しの委譲、エージェントのトーン・ペース・会話スタイルのシステムプロンプトによる制御、バックグラウンドノイズのより良い処理、長時間の会話におけるコンテキスト保持と会話品質の向上、電話サポートなどが主要な強みです。
- 評価では、GPT-Realtime-2.1と比較してFull Duplex Bench性能が30パーセンテージポイント向上し、会話の遅延と対話行動が大幅に改善され、Tau3ベンチマークでフロンティア音声エージェントの知能において第1位を獲得しました。
- GPT-Live-1はAPIで1分あたり0.05ドルで提供されており、カスタム音声アクセスについては営業担当への問い合わせが必要です。
