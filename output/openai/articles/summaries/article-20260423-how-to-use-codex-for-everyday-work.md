# How to use Codex for everyday work

## Key Points
- ChatGPT Codexは、カレンダー、メッセージ、メール、ドキュメント、スプレッドシートなどの既存の業務コンテキストを活用し、日報、週次レポート、意思決定メモなどのレビュー可能な初版成果物を生成できます。
- 日常業務のインプット（カレンダー、未読メッセージ、メールなど）から、優先順位、会議準備、返信が必要なメッセージ、決定事項、FYIを含む日報を作成し、日中の変更も監視できます。
- 週間の会議、ドキュメント、メッセージ、トラッカーなどから、完了した作業、決定事項、重要な変更点、障害、次の優先順位を含むマネージャー向けの週次サマリーを生成します。
- プロジェクト概要、元資料、指標、顧客コンテキストなどを用いて、スライド構成、発表者ノート、チャート、レイアウト修正、欠落データフラグを含む編集可能なプレゼンテーション資料のドラフトを作成します。
- 散らばったCSVやスプレッドシートなどの元ファイルを統合し、フィールドの標準化、重複排除、レコードの再フォーマットを行い、レビュータブと変更ログ付きのクリーンなワークブックを生成できます。
- 煩雑なワークフローの監査では、現在のトラッカー、プロセス文書、KPIダッシュボード、チケット履歴などを用いて、現在のステップ、問題点、所有者、自動化候補を特定し、更新されたプロセス文書と自動化仕様書を作成します。
