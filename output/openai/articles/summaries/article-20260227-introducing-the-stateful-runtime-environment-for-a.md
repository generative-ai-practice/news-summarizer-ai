# Introducing the Stateful Runtime Environment for Agents in Amazon Bedrock

## Key Points
- OpenAIとAmazonの共同開発により、Amazon Bedrockにステートフルなランタイム環境が導入され、エージェントの多段階AIワークフローにおける永続的なオーケストレーション、メモリ、セキュアな実行を可能にする。
- このランタイムは、エージェントの複雑なワークフローにおける状態の保存、ツールの呼び出し、エラー処理、長期間のタスクの再開といった運用上の課題を軽減する。
- 開発チームは、ランタイムが永続的なオーケストレーションと状態管理を担うことで、スキャフォールディングではなくワークフローとビジネスロジックに集中でき、多段階ワークフローの生産開始までの時間を短縮できる。
- 顧客のAWS環境内でネイティブに動作するように設計されており、既存のセキュリティ体制、ツール統合、ガバナンスルールに容易に準拠できるため、長期的な作業や複雑なプロセスに適している。
- Stateful Runtimeは近日中にAmazon Bedrockで利用可能になる予定で、多システム顧客サポート、営業業務、社内IT自動化などのソリューションを容易に提供できるようになる。
