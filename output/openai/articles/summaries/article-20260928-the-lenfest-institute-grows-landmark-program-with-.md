# The Lenfest Institute grows landmark program with expanded OpenAI support

## Key Points
- Lenfest InstituteのAIフェローシッププログラムは、OpenAIからの追加支援（資金500万ドル、ソフトウェアクレジットおよびエンジニアリングサポート最大500万ドル）を受け、拡大されます。これはOpenAIの以前の支援を倍増したものです。
- 2024年に開始されたこのプログラムは、AIエンジニアをローカルニュース組織に配置し、イノベーション加速、事業の持続可能性強化、新技術の責任ある導入に成功しています。
- AIエンジニアフェローは、ニュースルームのリーダーやスタッフと協力し、組織固有の課題に対応する実用的なAIソリューションを構築し、安全で倫理的なポリシーを策定します。
- 参加する11の組織において、フェローはアーカイブ検索、多言語コンテンツ作成、広告営業、読者エンゲージメントなど、幅広い機能でAIの実用的な応用を実証しました。
- プログラムの次のフェーズでは、最も成功したプロジェクトを再利用可能なツールやリソースとして開発・共有することで、フェローシップを超えて、より多くのニュース組織に広範な影響をもたらすことを目指しています。
