# The Lenfest Institute grows landmark program with expanded OpenAI support

## Key Points
- OpenAIはLenfest AI共同プログラムとフェローシッププログラムを拡大し、$500万の資金提供に加え、最大$500万のソフトウェアクレジットとエンジニアリングサポートを約束しました。
- このプログラムは、2024年の開始以来、AIエンジニアを主要な米国のニュース組織に配置し、地方ニュースのイノベーション加速、事業の持続可能性強化、新技術の責任ある採用に成功していることが実証されました。
- AIエンジニアリングフェローは、ニュースルームのリーダーや製品チームなどと協力し、組織固有の課題を特定し、読者エンゲージメント、調査報道、広告運営などのための実用的なAIソリューションを構築しています。
- 成功の鍵は、技術そのものよりも信頼、コラボレーション、組織のニーズの明確な理解にあり、フェローはローカルに雇用され、組織文化に根差したソリューションを提供しました。
- Lenfest Instituteは今後、より幅広いニュース組織をプログラムに招待し、優れたフェローシッププロジェクトを再利用可能なツールやリソースに転換することで、地方ジャーナリズムへの影響を拡大する予定です。
