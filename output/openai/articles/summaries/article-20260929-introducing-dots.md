# Introducing dots

## Key Points
- OpenAIは、GPT-6 Astraを搭載したプロアクティブなAIアシスタント「dots」を発表しました。これらは、独自のクラウドコンピューターとブラウザを持ち、4,000以上のアプリと連携して、複雑なプロジェクトや日常業務を自律的に処理できます。
- Dotsは、ChatGPT、Slack、Teams、およびモバイルアプリを通じて利用可能で、ユーザーのフィードバックから学習し、個人の好みや思考パターンに適応しながら、24時間体制で目標達成を支援します。
- 開発者向けのバグ修正、製品ローンチ資料の改訂、科学者向けデータ分析の更新、営業提案の修正、コンテンツ作成の自動化など、多岐にわたる専門的な業務を効率化します。
- Dotsは、ユーザーが常にコントロールできるよう設計されており、ChatGPTの保護機能に加え、追加の安全・プライバシー対策が組み込まれています。ユーザーはアクセス許可、カスタムルール、活動監視を通じて、ドットの行動を管理できます。
- Dotsは、2026年9月29日より対象市場のPro、Business Premium、Enterpriseプランで提供が開始されており、組織内で特定の責任を担うスペシャリストドットのプレビューも提供され、Microsoft Agent 365との統合も計画されています。
