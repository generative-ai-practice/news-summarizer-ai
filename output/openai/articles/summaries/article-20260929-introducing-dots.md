# Introducing dots

## Key Points
- OpenAIは、複雑なプロジェクトや日常業務を自律的に処理する能動的なAIアシスタント「dots」を発表しました。GPT-6 Astraを搭載し、ユーザーの目標や基準を学習して24時間365日稼働します。
- dotsは独自のクラウドコンピューターとブラウザを持ち、4,000以上のアプリとの連携が可能です。これにより、顧客フィードバックに基づくバグ修正や、製品発表資料の改訂など、多様なタスクを実行できます。
- ChatGPT（デスクトップ、ウェブ、モバイル）、Slack、Teamsでdotsと連携でき、複数のチャネルを横断して文脈を保持します。これにより、シームレスなコミュニケーションと作業継続が可能です。
- dotsには、ChatGPTの保護機能に加え、追加の安全性とプライバシー保護策が組み込まれており、ユーザーはアクセス許可やカスタムルールを通じて常に制御できます。機密性の高いタスクはユーザーの承認が必要です。
- dotsはPro、Business Premium、Enterpriseプランの対象市場で展開を開始しており、将来的には組織内で特定の責任を担う「スペシャリストドット」やMicrosoft Agent 365との統合も予定されています。
