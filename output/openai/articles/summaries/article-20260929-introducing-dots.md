# Introducing dots

## Key Points
- OpenAIの「Dots」は、GPT-6 Astraを搭載した、常時稼働のAIエージェントであり、独自のクラウドコンピューターとブラウザ、4,000以上のアプリとの連携を通じて、あらゆるタスクを24時間365日処理できます。
- Dotsは、ユーザーの好みや考え方を学習し、バグ修正や資料改訂、データ分析、コンテンツ作成といった複雑なプロジェクトを自律的に遂行することで、ユーザーの負担を軽減します。
- ChatGPT、Slack、Teamsといった複数のプラットフォームでドットと対話可能で、すべてのチャネルでコンテキストが共有されるため、どこからでもシームレスに作業を継続できます。
- 安全性、プライバシー、制御が重視されており、ドットは独自のクラウドコンピューターで動作し、ユーザーはアクセス許可、カスタムルール、アクションの承認を通じてその活動を管理できます。
- 企業向けには、組織内で特定の責任を担う「スペシャリストドット」が提供され、Microsoft Agent 365との統合により、既存の企業ツールを通じた管理も可能になります。
