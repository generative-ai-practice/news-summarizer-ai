# Introducing dots

## Key Points
- DotsはOpenAIによって開発された、GPT-6 Astraを搭載した常時稼働のAIエージェントで、複雑なプロジェクトから日常業務まで、ユーザーの目標達成のために広範なタスクを自律的に処理します。
- 独自のクラウドコンピューターとブラウザを持ち、4,000以上のアプリと連携可能です。ChatGPT、Slack、Teamsといったプラットフォームで利用でき、メッセージや音声通話を通じてユーザーの好みや思考を学習し、よりパーソナライズされたアシスタンスを提供します。
- ユーザーは常にDotsの作業進捗を監視し、必要な決定に関与できます。組み込まれた安全対策、アクセス許可管理、およびアクションの自動レビュー・承認機能により、ユーザーはAIの動作を完全にコントロールできます。
- Dotsは現在、ChatGPTのProおよびBusiness Premiumユーザー向けに展開されており、Enterpriseユーザーにはベータ版が提供されています。組織内で特定の責任を担う「専門ドット」もプレビュー中で、Microsoft Agent 365との連携も計画されています。
