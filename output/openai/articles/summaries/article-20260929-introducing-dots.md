# Introducing dots

## Key Points
- OpenAIが発表した「Dots」は、GPT-6 Astraを搭載した常に稼働する自律型エージェントです。個人の目標を学習し、複雑なプロジェクトから日常業務までを代行することで、ユーザーの時間を節約します。
- Dotsは独自のクラウドコンピュータ、ブラウザ、そして4,000以上のアプリとの連携を通じて、顧客フィードバックへの対応、ローンチ資料の改訂、データ分析の更新、コンテンツ制作の自動化など多岐にわたるタスクを実行します。
- ユーザーはChatGPT、Slack、Teamsなどを介してDotsと会話形式で連携でき、Dotsはフィードバックからユーザーの好みや思考を学習し、よりパーソナライズされた方法で作業を進めます。
- Dotsには、ChatGPTの保護に加え、独自のクラウドコンピュータでの作業、読み取り専用の「プロアクティブ調査」、厳格なアクセス権限、悪意のある指示からの防御など、追加の安全およびプライバシー保護対策が組み込まれています。重要な決定や機密性の高いタスクにはユーザーの承認が必要です。
- Dotsは本日、対象市場のProおよびBusiness Premiumユーザー向けにChatGPTでロールアウトを開始し、Enterpriseユーザーはベータ版を試用可能です。将来的には組織向けの専門DotsやMicrosoft Agent 365との統合も計画されています。
