# Introducing dots

## Key Points
- DotsはGPT-6 Astraを搭載した、常に稼働するプロアクティブなエージェントであり、複雑なプロジェクトから日常業務まで、ユーザーに代わって作業を処理します。
- 独自のクラウドコンピューターとブラウザを持ち、4,000以上のアプリと連携することで、幅広いタスクを実行し、ユーザーからのフィードバックを通じて学習し続けます。
- ChatGPT、Slack、Teamsなどのチャネルからアクセス可能で、チャネル間で文脈を引き継ぎ、ユーザーがどこからでも一貫して作業を継続できるようにします。
- ChatGPTの保護に加え、追加の安全およびプライバシー保護機能が組み込まれており、ユーザーはアクセス許可やアクション承認を通じて常にDotの制御を維持できます。
- 組織向けには、特定の責任を担う「専門ドット」が導入され、Microsoft Agent 365との統合により、企業は既存のツールを通じてドットを管理できるようになります。
