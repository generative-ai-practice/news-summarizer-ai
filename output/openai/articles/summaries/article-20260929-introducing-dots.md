# Introducing dots

## Key Points
- OpenAIの「Dots」は、GPT-6 Astraを搭載した常時稼働のAIエージェントであり、複雑なプロジェクトや日常業務を自律的に処理し、最大4,000のアプリと連携可能です。
- ChatGPT、Slack、Teamsなど様々なチャネルからアクセスでき、ユーザーの好みや思考を学習し、先回りして作業を実行することで、ユーザーはより重要な業務に集中できます。
- Dotの活動は厳重な安全およびプライバシー保護対策が施され、ユーザーはアクセス許可やカスタムルールを設定し、進行状況を監視することで常に完全に制御できます。
- 個人向けのDotに加え、企業内での特定の責任を担う「スペシャリストDot」も導入され、Microsoft Agent 365との連携も計画されています。
- Dotsは2026年9月29日より、ChatGPT ProおよびBusiness Premiumユーザーに展開が開始され、Enterpriseプランのベータ版も提供されています。
