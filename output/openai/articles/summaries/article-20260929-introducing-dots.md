# Introducing dots

## Key Points
- OpenAIが発表した「Dots」は、GPT-6 Astraを搭載した、複雑なプロジェクトや日常業務をこなす常時稼働型のAIアシスタントです。ユーザーの好みや思考を学習し、24時間体制で目標達成をサポートします。
- Dotsは独自のクラウドコンピューターとブラウザを持ち、4,000以上のアプリと連携できます。ChatGPT、Slack、Teamsといったプラットフォームで利用可能で、テキストや音声で対話できます。
- ユーザーは自分専用のDotに名前を付け、アプリへのアクセス許可を設定し、カスタムルールを通じて独立した行動や承認が必要な行動を管理できます。
- Dotsにはマルウェア対策や有害な行動の監視など、ChatGPTの保護に加えて追加の安全性・プライバシー保護機能が組み込まれています。重要な作業については常にレビューが推奨されています。
- 現在、Dotsは対象市場のChatGPT ProおよびBusiness Premiumプランユーザーに展開中で、Enterpriseユーザーはベータ版を試用できます。将来的には、組織内で特定の責任を担う「専門Dot」も提供され、Microsoft Agent 365との連携も進められる予定です。
