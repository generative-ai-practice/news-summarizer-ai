# Introducing dots

## Key Points
- Dotsは、GPT-6 Astraを搭載した常時稼働のプロアクティブなAIエージェントで、独自のクラウドコンピューターとブラウザを持ち、4,000以上のアプリと連携して複雑なプロジェクトや日常業務を自律的に処理します。
- ユーザーの目標や基準を学習し、開発、マーケティング、科学、コンテンツ制作など、多様な分野でユーザーの思考や好みに合わせた作業を、指示なしに実行できます。
- ChatGPT（デスクトップ、ウェブ、モバイル）、Slack、Teamsでメッセージや音声通話を通じてDotsと連携でき、あらゆるチャネルでコンテキストが引き継がれ、シームレスな作業をサポートします。
- Dotsは、独自のクラウドコンピューターでの作業、読み取り専用の事前調査、アクセス許可のユーザー管理、アクションの自動レビューと承認プロセスといった追加の安全・プライバシー保護機能を備え、ユーザーは常に作業をコントロールできます。
- 2026年9月29日よりChatGPTのProおよびBusiness Premiumプランで提供が開始され、Enterpriseユーザーもベータ版を試用可能。将来的には、組織内で特定の責任を担うスペシャリストドットの導入やMicrosoft Agent 365との統合も計画されています。
