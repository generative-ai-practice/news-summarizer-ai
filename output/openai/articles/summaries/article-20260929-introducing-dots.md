# Introducing dots

## Key Points
- OpenAIの「dots」は、GPT-6 Astraを搭載した常時稼働のAIエージェントで、複雑なプロジェクトや日常業務を自律的に処理し、ユーザーの時間と注意力を解放します。
- dotsはユーザーの目標や基準を学習し、ChatGPT、Slack、Teamsなど複数のプラットフォームで連携可能で、テキストや音声通話を通じて質問やフィードバックを提供できます。
- 安全性を重視し、各dotは専用のクラウドコンピューター上で動作し、ユーザーはアプリのアクセス許可、カスタムルール、およびアクション承認を通じて常に制御を維持できます。
- 「specialist dots」は組織内で特定の責任を担い、独自のID、資格情報、システムアクセスを持ち、調達やメールマーケティングなどの業務に特化して機能します。Microsoft Agent 365との統合も進められています。
- dotsは2026年9月29日より、対象市場のChatGPT ProおよびBusiness Premiumユーザーに展開されており、最初のdotは追加費用なしで利用でき、将来的にはより多くのユーザーへの拡大が予定されています。
