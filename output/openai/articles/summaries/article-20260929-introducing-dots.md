# Introducing dots

## Key Points
- Dotsは、GPT-6 Astraを搭載した、常に稼働するプロアクティブなAIエージェントで、複雑なプロジェクトから日常業務までを処理し、ユーザーの時間と注意力を解放します。
- 4,000以上のアプリに接続可能で、ChatGPT、Slack、Teamsといったプラットフォームを通じて利用でき、ユーザーの好みや目標を学習しながら24時間365日稼働します。
- 組み込みの安全対策、アクセス許可、アクションレビューおよび承認機能により、ユーザーは常にDotsの作業を管理下に置くことができ、機密性の高いタスクはユーザー自身が実行します。
- 組織向けには、特定の責任を担う「Specialist dots」が導入されており、Microsoft Agent 365との統合も進められています。
- Dotsは2026年9月29日より、ProおよびBusiness Premiumプランの対象市場で提供開始され、Enterpriseユーザーはベータ版を試用可能です。最初のドットは追加費用なしで提供されます。
