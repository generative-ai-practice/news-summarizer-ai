# Introducing dots

## Key Points
- OpenAIは、GPT-6 Astraを搭載した、常に稼働するプロアクティブなAIアシスタント「dots」を発表しました。これは、ユーザーの目標や好みを学習し、複雑なプロジェクトから日常業務まで多岐にわたるタスクを自律的に処理します。
- dotsは、自身のクラウドコンピューターとブラウザを持ち、4,000以上のアプリと連携可能です。ChatGPT、Slack、Teamsなどのプラットフォームでメッセージや音声通話を通じてシームレスに操作でき、各チャネル間でコンテキストを維持します。
- dotsは強化された安全・プライバシー対策を備え、ユーザーはアプリへのアクセス許可、カスタムルールの設定、プロアクティブな調査の制限、および行動の自動レビュー・承認を通じて常にコントロールを維持できます。
- 個人のdotに加え、組織内で特定の責任を持つ「スペシャリストdots」も導入されます。これらは独自のIDとシステムアクセスを持ち、調達、請求書処理、顧客サポートなどの企業タスクを専門的に処理し、Microsoft Agent 365との統合も計画されています。
- dotsは2026年9月29日より、ChatGPTのProおよびBusiness Premiumプランユーザーに提供され、Enterpriseプランユーザーはベータ版を試用可能です。最初のdotは追加費用なしでプランに含まれ、将来的に機能拡張や追加ドットのオプションも検討されています。
