# Introducing dots

## Key Points
- OpenAIは、複雑なプロジェクトや日常業務を自律的に処理する、常時稼働のAIエージェント「dots」を発表しました。これはGPT-6 Astraを搭載し、クラウドコンピューター、ブラウザ、および4,000以上のアプリとの連携能力を備えています。
- dotsは、ユーザーの目標や好みを学習し、開発者のバグ修正、ローンチ資料の改訂、分析の更新、コンテンツ制作の自動化など、多岐にわたる業務を支援します。ChatGPT、Slack、Teamsを通じて利用でき、チャネル間で作業のコンテキストを保持します。
- セキュリティとプライバシーを重視し、追加の安全対策が講じられています。ユーザーはアクセス権限、カスタムルールを設定し、進行中の作業を監視することで常に制御を維持でき、機密性の高いアクションには承認が必要です。
- 組織内で特定の役割を担う「Specialist dots」も導入され、企業は独自のIDとシステムアクセスを設定できます。これはMicrosoft Agent 365との統合も進められており、企業は既存のMicrosoftツールでdotsを管理可能になります。
- dotsは、2026年9月29日よりChatGPTのProおよびBusiness Premiumプランユーザーに提供が開始され、Enterpriseプランユーザーはベータ版を試用できます。最初のdotは追加費用なしで提供され、会話はChatGPTの利用制限にはカウントされません。
