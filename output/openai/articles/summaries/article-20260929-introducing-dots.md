# Introducing dots

## Key Points
- OpenAIの「dots」は、GPT-6 Astraを搭載した常時稼働のAIエージェントであり、ユーザーの目標達成に向けて24時間体制でタスクを処理します。4,000以上のアプリに接続し、幅広い業務に対応可能です。
- dotsは、顧客フィードバックに基づくバグ修正、製品ローンチ資料の改訂、科学的分析の更新、コンテンツ制作の自動化など、ユーザーの好みや基準を学習して多岐にわたる専門的なタスクを代行します。
- ChatGPT、Slack、Teamsなどのプラットフォームを通じて会話形式でdotsと連携でき、複数のチャネル間で作業の文脈が維持されるため、場所を選ばずにシームレスに作業を継続できます。
- dotsは独自のクラウドコンピューターで動作し、読み取り専用の「プロアクティブな調査」機能や、悪意ある指示からの保護、ユーザーによるアクセス権限管理、承認が必要なアクションの「自動レビュー」など、厳重な安全対策とプライバシー保護機能を備えています。
- 組織内で特定の責任を担う「専門ドット」も導入されており、Microsoft Agent 365との統合も予定されています。dotsは2026年9月29日より、ChatGPTのProおよびBusiness Premiumプランユーザーに順次展開され、Enterpriseプランのユーザーもベータ版を利用可能です。
