# Introducing dots

## Key Points
- OpenAIの「Dots」は、GPT-6 Astraを搭載した常時稼働のAIエージェントで、独自のクラウドコンピューターと4,000以上のアプリとの連携により、多岐にわたるタスクを自律的に処理します。
- ChatGPT、Slack、Teamsを通じてアクセス可能で、ユーザーの好みや思考を学習し、依頼する前にユーザーが望む方法で作業を先回りして実行することで、個人を拡張する存在となります。
- ChatGPTの保護に加え、安全性とプライバシーの追加保護が組み込まれており、ユーザーはアクセス権限や動作ルールを設定し、進捗を監視することで常にドットの活動をコントロールできます。
- 組織内で特定の責任を担う「スペシャリストDots」も導入され、Microsoft Agent 365との統合も進められており、企業はドットを既存のツールを通じて管理できるようになります。
- 2026年9月29日より、適格な市場のProおよびBusiness Premiumユーザーに提供が開始され、最初のドットは追加費用なしで利用可能です。
