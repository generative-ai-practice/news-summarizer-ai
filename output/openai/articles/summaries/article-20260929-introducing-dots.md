# Introducing dots

## Key Points
- OpenAIのDotsは、GPT-6 Astraを搭載した常に稼働するAIアシスタントで、独自のクラウドコンピューターとブラウザを持ち、4,000以上のアプリと連携して複雑なプロジェクトや日常業務を代行します。これにより、ユーザーはより重要なタスクに集中できるようになります。
- ユーザーはChatGPT、Slack、Teamsを通じてDotsと会話や音声でやり取りでき、Dotsはフィードバックからユーザーの好みや思考、目標を学習し、開発、製品ローンチ、科学分析、コンテンツ制作などの多様な業務を自律的に進めます。
- DotsはChatGPTの保護に加え、追加の安全およびプライバシー保護対策を備えています。各Dotは独立したクラウドコンピューター上で動作し、ユーザーはアクセス許可やカスタムルールを設定でき、パスワード変更などの機密性の高いタスクはユーザー自身が実行します。
- 2026年9月29日より、対象市場のChatGPT ProおよびBusiness Premiumユーザーに提供が開始され、エンタープライズユーザーはベータ版を試用可能です。将来的には、組織内で特定の責任を担う「専門家dot」の導入や、Microsoft Agent 365との統合が計画されています。
- 最初のdotはProまたはBusiness Premiumプランに無料で含まれており、ChatGPTデスクトップアプリまたはブラウザで作成後、ChatGPTモバイルアプリからも利用できます。Dotsとの会話はChatGPTの利用制限にはカウントされません。
