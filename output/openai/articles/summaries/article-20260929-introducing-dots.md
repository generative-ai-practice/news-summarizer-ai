# Introducing dots

## Key Points
- DotsはGPT-6 Astraを搭載した常時稼働のAIエージェントで、独自のクラウドコンピューターとブラウザ、4,000以上のアプリ連携により、複雑なプロジェクトから日常業務まで自律的に処理します。
- ChatGPT、Slack、Teamsを通じて対話でき、ユーザーとの協働を通じて好みや思考を学習し、ユーザーが意図する通りにタスクを完了させることが可能です。
- 各ドットは独立したクラウド環境で動作し、アクセス権限はユーザーが管理できます。悪意のある指示や有害な振る舞いに対する組み込みの安全対策と自動レビュー機能が備わっています。
- 組織内で特定の責任を担う「スペシャリストドット」のプレビューも開始されており、Microsoft Agent 365との統合も進められています。
- Dotsは2026年9月29日より、ChatGPTのProおよびBusiness Premiumプランの対象市場ユーザーに提供が開始され、Enterpriseユーザーもベータ版を利用可能です。
