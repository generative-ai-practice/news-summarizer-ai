# Introducing dots

## Key Points
- OpenAIは、GPT-6 Astraを搭載した自律型AIエージェント「dots」を発表しました。これらは、ユーザーの目標に向けて24時間365日稼働し、複雑なプロジェクトから日常業務までを代行します。
- dotsは独自のクラウドコンピューターとブラウザを持ち、4,000以上のアプリと連携して多様なタスクに対応できます。ChatGPT、Slack、Teamsからメッセージや通話でアクセス可能で、コンテキストを共有しながら作業を進めます。
- 安全性とプライバシー保護が強化されており、各dotは自身のクラウドコンピューターで動作し、ユーザーのデバイスとは分離されます。ユーザーはアクセス許可やカスタムルールを設定し、進行状況を「Activity View」で監視することで常に制御できます。
- 組織向けには、特定の責任を担う「スペシャリストdots」が導入され、独自のIDとアクセス権限を持ちます。Microsoft Agent 365との統合も進められ、企業が既存のツールでdotsを管理できるようになる予定です。
- dotsは、2026年9月29日より、ChatGPTのProおよびBusiness Premiumプランの対象市場ユーザーに提供が開始されています。Enterpriseユーザーもベータ版を利用でき、最初のdotは追加費用なしで提供されます。
