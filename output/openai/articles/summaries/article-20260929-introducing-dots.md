# Introducing dots

## Key Points
- DotsはGPT-6 Astraを搭載した常に稼働するAIエージェントで、独自のクラウドコンピューターと4,000以上のアプリへのプラグイン接続を通じて、複雑なプロジェクトや日常業務を自律的に処理します。
- ChatGPT、Slack、Teamsなど複数のチャネルで利用可能であり、ユーザーの目標やフィードバックから学習し、個人の好みや思考パターンに合わせてパーソナライズされます。
- 安全性確保のため、各Dotは独立したクラウドコンピューターで動作し、ユーザーはアプリへのアクセス許可、行動ルール、承認プロセスを通じて常に制御を維持できます。
- 企業向けには、組織内で特定の責任を担う「スペシャリストDots」が導入され、Microsoft Agent 365との統合も計画されています。
- Dotsは2026年9月29日よりChatGPTのProおよびBusiness Premiumプランで提供が開始され、Enterpriseプランのユーザーはワークスペース管理者が有効にすることでベータ版を試用可能です。
