# Disrupting AI-enabled “false front” operations

## Key Points
- OpenAIは、AIを悪用して偽装ジャーナリストやシンクタンクを介して地政学的なメッセージを広めていた、ロシアとイラン発の2つの影響工作活動を阻止しました。
- これらの作戦はAIをコンテンツ生成、内部報告書作成、偽文書・音声スクリプト作成、およびソーシャルメディアコメントの生成に利用し、従来の工作手法とAIを組み合わせた多次元的なアプローチを採用していました。
- ロシア発の作戦「Dark Clark」はラテンアメリカを標的にし「カテゴリー5」と評価され、イラン発の作戦「Bogus Bylines」は7つの偽ジャーナリストペルソナを使用し「カテゴリー4」と評価されました。
- 両作戦とも、コンテンツの一部が主流メディアに掲載されるなど、高い潜在的リーチと影響力を持っていましたが、その効果を誇張するために欺瞞的な評価方法を用いていました。
- これらの偽装工作活動は、責任ある情報開示によって活動が停止される脆弱性も示しており、OpenAIはこれらの報告を通じてさらなる調査と阻止を促しています。
