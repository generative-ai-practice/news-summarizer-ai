# How Oracle turns days of work into minutes with ChatGPT and Codex

## Key Points
- OracleはChatGPT WorkとCodexを活用し、採用、エンジニアリング、運用といった多様な分野で、専門家による数日間の作業を数分で完了するワークフローへと変革しています。
- タレント獲得チームはChatGPT Workを用いて市場インテリジェンスツールを構築し、求人調査にかかる時間を98%削減し、従来2～4日かかっていた作業を15～20分で完了できるようになりました。
- Oracle Applications LabのビジネスユーザーはCodexにより、自然言語での質問を信頼性の高いSQLクエリに変換し、レポートや分析をほぼ即座に取得できるようになり、インシデント解決時間も数分に短縮されました。
- Oracleには13万人以上のアクティブなChatGPTユーザーと9.5万人以上のアクティブなCodexユーザーがおり、AIが社内の多様な業務タスクで活用されています。
- AIツールを利用する上では、適切なガードレールの設定、仕様の代わりにプロトタイプを提供すること、そして生成されたコードに対する人間の責任と所有権を持つことがリーダーシップの教訓として挙げられています。
