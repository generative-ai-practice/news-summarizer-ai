# How Oracle turns days of work into minutes with ChatGPT and Codex

## Key Points
- OracleはChatGPT WorkとCodexを導入し、人材獲得、エンジニアリング、運用などの専門的な作業にかかる時間を数日から数分へと劇的に短縮しています。
- 採用チームはChatGPT Workを活用したタレント市場インテリジェンスツールを構築し、市場調査にかかる時間を98%削減、2〜4日かかっていた作業を15〜20分で完了できるようになりました。
- Oracle Applications LabチームはCodexを使って平易なビジネス質問から信頼性の高いSQLクエリを生成し、ビジネスユーザーが必要な情報やレポートを迅速に得られるようにしています。
- サイト信頼性エンジニアはCodexを用いてインシデントのコンテキストを収集し、適切な対応手順を自動的に引き出すことで、単純なインシデントの解決時間を数分に短縮しました。
- AIツール導入における教訓として、適切なシステム設計とセキュリティの確保、仕様書ではなくプロトタイプによるアイデア表現、生成されたコードの保守性への責任が挙げられています。
