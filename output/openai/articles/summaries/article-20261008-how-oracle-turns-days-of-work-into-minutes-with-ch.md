# How Oracle turns days of work into minutes with ChatGPT and Codex

## Key Points
- OracleはChatGPT WorkとCodexを導入し、採用、エンジニアリング、運用といった分野で専門知識を活用したワークフローを数日から数分に短縮している。
- 人材獲得チームはChatGPT Workでタレントマーケットインテリジェンスツールを構築し、市場調査にかかる時間を98%削減、2〜4日かかっていた作業を15〜20分で完了できるようにした。
- Oracle Applications LabチームはCodexを用いて自然言語のビジネス質問をSQLクエリに変換し、必要なレポートや分析を迅速に取得可能にし、SREはインシデント解決時間を数分に短縮した。
- Oracleでは130K人以上のアクティブなChatGPTユーザーと95K人以上のアクティブなCodexユーザーがおり、AIは業務のさまざまな場面で活用されている。
- AI活用におけるリーダーシップの教訓として、適切なガードレールの設定、仕様書ではなくプロトタイプでの提示、生成されたコードへの所有権を持つことが挙げられている。
