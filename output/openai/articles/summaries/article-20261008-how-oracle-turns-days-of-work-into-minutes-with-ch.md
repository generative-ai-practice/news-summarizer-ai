# How Oracle turns days of work into minutes with ChatGPT and Codex

## Key Points
- OracleはChatGPT WorkとCodexを導入し、採用、エンジニアリング、運用などの業務において、専門知識を迅速かつ反復可能なワークフローに変換することで、作業時間を大幅に短縮しています。
- 人材獲得チームはChatGPT Workを活用したタレント市場インテリジェンスツールにより、市場調査時間を98%削減し、以前は2〜4日かかっていた作業を15〜20分で完了可能にしました。
- Oracle Applications LabチームはCodexを使って自然言語のビジネス質問を信頼性の高いSQLクエリに変換し、ビジネスユーザーが求める分析やレポートを即座に提供しています。
- サイト信頼性エンジニアはCodexを用いてインシデントの文脈を収集し、適切なプレイブックを自動で引き出すことで、通常1時間かかる解決時間を数分に短縮しました。
- AIツール導入の成功には、適切なシステム設計とセキュリティのガードレール、仕様書よりもプロトタイプでのアイデア具現化、生成されたコードの保守責任が重要であると述べられています。
