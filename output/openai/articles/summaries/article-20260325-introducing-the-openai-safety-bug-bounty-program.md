# Introducing the OpenAI Safety Bug Bounty program

## Key Points
- OpenAIは、AIの悪用や安全上のリスクを特定するため、新たなSafety Bug Bountyプログラムを2026年3月25日に開始しました。
- このプログラムは、従来のセキュリティ脆弱性だけでなく、AI固有の濫用や安全上の重大なリスクに対処し、既存のSecurity Bug Bountyプログラムを補完します。
- 対象となるAI固有の安全シナリオには、第三者によるプロンプトインジェクション、データ抜き取り、Agenticな製品による不許可なアクションの実行、OpenAIの専有情報漏洩、アカウントやプラットフォームの整合性に関する脆弱性が含まれます。
- モデルが不適切な言葉を使用する、または容易に検索可能な情報を返すような一般的なコンテンツポリシーのバイパスや「ジェイルブレイク」は、本プログラムの対象外です。
- 興味のある研究者は、OpenAI Safety Bug Bountyプログラムを通じて参加申請し、安全なAIエコシステムの実現に協力できます。
