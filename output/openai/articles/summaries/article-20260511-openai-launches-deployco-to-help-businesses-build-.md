# OpenAI launches the OpenAI Deployment Company to help businesses build around intelligence

## Key Points
- OpenAIは、企業がAIシステムを日常業務に導入し、測定可能なビジネス効果を生み出すのを支援する新会社「OpenAI Deployment Company」（DeployCo）を立ち上げました。
- DeployCoの立ち上げに伴い、OpenAIはAIコンサルティングおよびエンジニアリング会社であるTomoroを買収することに合意し、約150名の経験豊富なForward Deployed Engineers（FDEs）が初期から参加します。
- DeployCoは、TPGが主導し、Advent、Bain Capital、Brookfieldなどを含む19の主要なグローバル投資会社やコンサルタントとのパートナーシップです。
- DeployCoは40億ドル以上の初期投資で事業を開始し、オペレーションを拡大し、人工一般知能が全人類に利益をもたらすというOpenAIの使命を加速させる企業を買収する予定です。
- DeployCoはOpenAIの研究・製品チームと密接に連携し、顧客が将来のフロンティアAI能力を見据えた持続可能なシステムを迅速に構築できるよう支援します。
