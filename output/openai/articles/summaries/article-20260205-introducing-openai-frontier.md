# Introducing OpenAI Frontier

## Key Points
- OpenAI Frontierは、企業が共有コンテキスト、オンボーディング、権限、ガバナンスを備えたAIエージェントを構築、展開、管理するための新しいプラットフォームです。
- このプラットフォームは、AIが個別のユースケースを超え、企業全体の「AIコワーカー」として実質的な作業を行えるように設計されています。
- AIコワーカーの成功には、システム間の作業理解、データとツールを活用した問題解決、フィードバックによる継続的な品質改善、および信頼できるID・権限・境界線が重要です。
- Frontierは、既存のクラウドやデータプラットフォームとオープンスタンダードで連携し、ChatGPTや既存のビジネスアプリケーションなど、あらゆるインターフェースを通じてAIコワーカーにアクセスできます。
- OpenAIのForward Deployed Engineers (FDEs) が顧客チームと密接に連携し、AIエージェントの実装とモデル改善のためのベストプラクティスを提供します。
