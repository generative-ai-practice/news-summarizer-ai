# How ChatGPT learns about the world while protecting privacy

## Key Points
- ChatGPTは、公開情報、パートナーシップによる情報、ユーザー生成データなど、多様な情報源を利用してモデルを学習し、広範な世界の知識を構築しています。
- トレーニングプロセスでは、個人情報を特定しマスクする「OpenAI Privacy Filter」などの高度な技術を用いて、データセット内の個人情報の処理を削減しています。
- ユーザーは「Improve the model for everyone」設定のオン/オフ、一時チャット、メモリ機能を通じて、自身のChatGPT会話がモデルの改善に利用されるか、または記憶されるかを管理できます。
- ChatGPTは個人の機密情報に関する要求を拒否するよう設計されており、誤って個人情報が出力された場合は、プライバシーリクエストポータルを通じて修正または削除を要求できます。
- OpenAIは、ChatGPTが個人の生活に深く関わる利用が増える中で、プライバシー保護を真剣な責任と捉え、セキュリティ対策とユーザーのデータ管理権限の明確化を継続的に強化しています。
