# Helping build shared standards for advanced AI

## Key Points
- OpenAIは、高度なAIのための共通基準構築を支援するため、Linux Foundationが運営するAppia Foundationの設立を支援しました。Appiaは、国際標準を実用的な評価基準に変換するオープンな仕様を開発します。
- Appiaの取り組みは、第三者機関がモデルやインフラの基準適合性を検証する信頼層を構築し、組織間や管轄区域を越えて共通の技術的理解を可能にすることを目的としています。
- OpenAIは、フロンティアAIの民主的ガバナンスの青写真や、信頼できる第三者評価のためのプレイブックを提供し、米国CAISIや英国AISIとの協力を含む評価実践を通じてシステムの安全性を強化しています。
- 内部的には、OpenAIは高度なAIのリスク管理のためのPreparedness Frameworkと、リスク評価、モデル報告、セキュリティ管理、インシデント対応に焦点を当てたFrontier Governance Frameworkを運用しています。
- OpenAIは、ISO/IECのAI合同技術委員会、NISTのAIコンソーシアム、Frontier Model Forumなど、幅広い標準化活動に貢献しており、フロンティア開発の教訓をオープンな実践に変換することを目指しています。
