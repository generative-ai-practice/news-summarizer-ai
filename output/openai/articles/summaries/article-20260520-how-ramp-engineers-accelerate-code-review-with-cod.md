# How Ramp engineers accelerate code review with Codex

## Key Points
- Rampのエンジニアは、CodexとGPT-5.5を活用してコードレビューを劇的に加速し、以前は数時間かかっていた実質的なフィードバックを数分で得られるようになりました。
- Codexは、コードベースに対する深い推論能力により、人間のレビューアでは見落としがちな点も徹底的に捕捉し、業界のゴールドスタンダードとして評価されています。
- オンコール対応の負担を軽減する社内エージェントツール「On-Call Assistant」の開発にもCodexが利用されており、その複雑なビジネスロジックへの対応力が開発を加速させています。
- CodexはCLIとアプリの両方でエンジニアのワークフローに合わせた体験を提供し、開発者の生産性向上とコード品質の改善に貢献しています。
- AIツールの導入により、エンジニアの役割はコードを直接書くことからAIツールを指揮する「オーケストレーター」へと進化しており、リーダーは実践的な経験とフィードバックループへの投資を通じてエンジニアを導くことが重要です。
