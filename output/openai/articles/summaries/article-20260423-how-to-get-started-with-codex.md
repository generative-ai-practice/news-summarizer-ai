# How to get started with Codex

## Key Points
- Codexデスクトップアプリをダウンロードし、ChatGPTアカウントでサインインして利用を開始します。Codexでは、タスクを実行するために「スレッド」と呼ばれる対話スペースを使用します。
- 作業は通常、コンピュータ上の特定のフォルダに接続された「プロジェクト」内で行います。管理を容易にするために、「Codex」という親フォルダ内に各プロジェクト用のサブフォルダを作成することが推奨されます。
- 最初は、メモの整理や小規模なデータセットのクリーンアップなど、シンプルで実用的なタスクから始めるのが良いでしょう。これにより、Codexの機能に慣れ、信頼を築くことができます。
- デフォルト推奨のCodexモデルから始め、より複雑なタスクには推論設定を高くします。ローカル環境での作業時はデフォルトの権限設定を維持し、Codexが自動的にコンピュータ全体にアクセスすることはありません。
- より高度なタスクで完全な権限が必要な場合は、Codexの動作を理解し、管理者の承認を得てから使用してください。推奨される最初のプロンプトは「このフォルダを検査し、何が見えるかを教えてください。その後、安全に完了できる小さなタスクを1つ提案してください。変更を加える前に私の承認を待ってください。」です。
