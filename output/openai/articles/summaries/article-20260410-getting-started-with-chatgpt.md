# Getting started with ChatGPT

## Key Points
- ChatGPTは、自然言語を理解し人間のような応答をリアルタイムで生成することで、思考、執筆、問題解決を支援する会話型AIアシスタントです。大規模言語モデルを基盤としています。
- 最初の会話は、ChatGPTを開き、テキスト、画像、音声、ファイル形式の「プロンプト」を入力することから始まります。応答を基にフォローアップの質問で会話を深めることができます。
- ChatGPTの有用なユースケースは、ドラフト作成、アイデア出し、要約、メモ整理など、チャット形式で行う既存の作業から見つけることができ、繰り返しの多い作業にはProjectsやカスタムGPTが役立ちます。
- 音声機能を使うと、タイピングよりも迅速かつ自然な対話が可能です。リアルタイムの双方向会話「Voice Mode」や音声入力「Dictation」を利用できます。
- 音声チャットの音声およびビデオクリップは、テキスト変換と共にチャット履歴に保存され、履歴が残る限りアクセス可能です。
