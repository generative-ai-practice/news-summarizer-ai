# Getting started with ChatGPT

## Key Points
- ChatGPTは、自然言語を理解し人間のような応答をリアルタイムで生成することで、思考、執筆、問題解決を支援する会話型AIアシスタントです。
- 会話はプロンプト（テキスト、画像、音声、ファイルなど）を入力することから始まり、モデルはこれに基づいて応答を生成します。
- 優れたユースケースを見つけるには、ドラフト作成、アイデア出し、要約など、既存のチャット形式の作業から試すのが効果的です。
- 音声機能を使うことで、タイピングよりも高速で自然なハンズフリーの対話が可能となり、ボイスモード（双方向会話）とディクテーション（音声からテキスト）が利用できます。
