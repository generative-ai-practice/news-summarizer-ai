# Getting started with ChatGPT

## Key Points
- ChatGPTは、自然言語を理解し、人間のような応答を生成することで、思考、執筆、問題解決を支援する会話型AIアシスタントです。
- 会話を開始するには、chatgpt.comでプロンプト（テキスト、画像、音声、ファイルなど）を入力します。開始に役立つテンプレートプロンプトも紹介されています。
- 有用なChatGPTの利用事例は、ドラフト作成、ブレインストーミング、要約、問題検討など、日常的に行うチャット形式の作業から見つけることができます。
- 繰り返しの多いタスクや複数のステップを伴うタスクには、ProjectsやカスタムGPTなどのツールを活用することで、より構造化された効率的なワークフローを構築できます。
- ChatGPTは音声モード（リアルタイムの双方向会話）とディクテーション（音声のテキスト変換）を提供し、より迅速で自然なハンズフリー操作を可能にします。
