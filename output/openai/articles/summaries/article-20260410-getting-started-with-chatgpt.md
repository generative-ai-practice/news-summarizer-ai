# Getting started with ChatGPT

## Key Points
- ChatGPTは、自然言語を理解し人間のような応答を生成することで、思考、執筆、問題解決を支援する対話型AIアシスタントです。大規模言語モデルに基づいて構築されています。
- 会話を開始するには、テキスト、画像、音声、ファイルなどの形式で「プロンプト」を入力します。明確なプロンプトは、AIが適切な応答を生成するための鍵となります。
- ChatGPTの有効な使用例としては、下書き作成、アイデア出し、情報の要約、メモの整理、問題の考察など、日頃行っているチャット形式の作業から始めるのが適しています。
- 音声機能は、Voice Mode（双方向会話）とDictation（音声入力）を提供し、より迅速で自然なハンズフリー操作を可能にします。これにより、移動中のブレインストーミングなど新しいワークフローが実現します。
