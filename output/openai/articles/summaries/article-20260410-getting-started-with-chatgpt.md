# Getting started with ChatGPT

## Key Points
- ChatGPTは、自然言語を理解し人間のような応答をリアルタイムで生成する会話型AIアシスタントで、思考、執筆、問題解決を支援します。
- 利用を開始するには、テキスト、画像、音声、ファイルなど多様な形式で「プロンプト」（質問や指示）を入力するだけで、モデルはそれに基づいて応答を生成します。
- 効果的なユースケースは、ドラフト作成、アイデア出し、要約、メモの整理など、チャット形式で行う既存の作業から見つけるのが良いとされています。
- 音声機能では、リアルタイムで会話する「ボイスモード」や、話した言葉をテキストに変換する「ディクテーション」が選択でき、より自然でハンズフリーな対話が可能です。
- 高度なユースケースには、Projects、カスタムGPT、Skillsなどのツールを活用し、繰り返しの作業や時間的コンテキストが必要なタスクを効率化できます。
