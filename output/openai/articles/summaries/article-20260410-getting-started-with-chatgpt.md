# Getting started with ChatGPT

## Key Points
- ChatGPTは、自然言語を理解し、人間のような応答をリアルタイムで生成することで、思考、執筆、問題解決を支援する会話型AIアシスタントです。
- 最初の会話は、質問や指示（プロンプト）を入力することから始まります。プロンプトはテキストだけでなく、画像、音声、ファイルも使用できます。
- 有用なChatGPTの利用事例を見つけるには、ドラフト作成、ブレインストーミング、要約など、普段行っているチャット形式の作業から試すことが有効です。
- 音声機能は、リアルタイムの双方向会話が可能な「Voice Mode」と、話した言葉をテキストに変換する「Dictation」があり、より自然でハンズフリーな操作を実現します。
- 音声チャットのオーディオやビデオクリップは、チャット履歴にトランスクリプションとともに保存され、チャットが履歴に残っている限り保持されます。
