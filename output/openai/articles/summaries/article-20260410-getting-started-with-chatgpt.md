# Getting started with ChatGPT

## Key Points
- ChatGPTは、自然言語を理解し人間のような応答をリアルタイムで生成することで、思考、執筆、問題解決を支援する会話型AIアシスタントです。
- 会話を始めるには、テキストだけでなく画像、音声、ファイルも可能な「プロンプト」を入力し、応答後にフォローアップや詳細追加で対話を洗練させます。
- ChatGPTの有用な利用例を見つけるには、下書き作成、アイデアのブレインストーミング、長文の要約など、既にチャット形式で行っている作業から試すのが効果的です。
- 音声機能を使用すると、タイピングよりも高速で自然な対話が可能になり、「Voice Mode」（リアルタイム会話）と「Dictation」（音声のテキスト化）を選択して利用できます。
