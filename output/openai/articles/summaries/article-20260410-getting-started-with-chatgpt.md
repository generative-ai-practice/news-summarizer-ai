# Getting started with ChatGPT

## Key Points
- ChatGPTは、自然言語を理解し、リアルタイムで人間のような応答を生成することで、思考、執筆、問題解決を支援する会話型AIアシスタントです。
- 会話を始めるには、ChatGPTを開いてプロンプト（質問や指示）を入力します。プロンプトはテキストだけでなく、画像、音声、ファイルも利用可能です。
- ChatGPTの有用な活用法を見つけるには、ドラフト作成、アイデア出し、要約など、すでにチャット形式で行っている作業から始めると良いでしょう。繰り返し行う作業には、ProjectsやカスタムGPTsなどのツールが役立ちます。
- 音声機能を使うことで、タイピングよりも迅速で自然な対話が可能です。「音声モード」でリアルタイムの双方向会話をするか、「ディクテーション」で話した言葉をテキストに変換できます。
