# Getting started with ChatGPT

## Key Points
- ChatGPTは自然言語を理解し、人間のような応答をリアルタイムで生成することで、思考、執筆、問題解決を支援する会話型AIアシスタントです。大規模言語モデルに基づいて構築されています。
- 会話を始めるには、ChatGPTを開いて「プロンプト」を入力します。プロンプトはテキストだけでなく、画像、音声、ファイルでも可能です。
- 効果的なユースケースを見つけるには、下書き作成、アイデア出し、要約、問題検討など、普段チャット形式で行う作業から始めるのが良いでしょう。繰り返し行うタスクには、ProjectsやカスタムGPTなどのツールを活用すると効率的です。
- ChatGPTには音声機能があり、リアルタイムの双方向会話が可能な「ボイスモード」と、話した言葉をテキストに変換する「ディクテーション」が利用できます。これにより、ハンズフリーでの作業や移動中のブレインストーミングなどが可能です。
