# OpenAI named a Leader in enterprise coding agents by Gartner

## Key Points
- OpenAIは、2026年のGartner® Magic Quadrant™ for Enterprise AI Coding Agentsにおいてリーダーとして認定されました。
- この評価は、毎週400万人以上のユーザーや、Cisco、Datadog、Dell Technologies、NVIDIAなどの企業で利用されているCodexの企業規模の導入における進展を反映しています。
- Gartnerは、エージェント型ソフトウェア開発、エンタープライズガバナンス、サンドボックス、および柔軟なデプロイメントオプションにおけるCodexの強みを評価しました。
- Codexは、GPT‑5.5の導入、より強力なツール利用、高速なパフォーマンス、エンタープライズソフトウェア開発ワークフローの深いサポートなど、継続的に改善されています。
- 6月12日まで、対象となる企業アカウントは新規ユーザー向けに2ヶ月間のCodex無料利用をリクエストでき、企業全体での導入を促進しています。
