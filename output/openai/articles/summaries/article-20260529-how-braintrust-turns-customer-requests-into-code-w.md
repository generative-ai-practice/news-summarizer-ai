# How Braintrust turns customer requests into code with Codex

## Key Points
- BraintrustはCodexとGPT-5.5を活用し、顧客からの機能リクエストを数分でプレビューブランチに変え、エンジニアリング実験の範囲を拡大しています。
- Codexの高速性により、Braintrustチームは顧客の機能リクエストにリアルタイムで対応し、開発ワークフローに迅速なイテレーションを組み込むことが可能になりました。
- 創設者兼CEOのAnkur Goyalは、Codexの最大の利点はその速度であり、他のモデルではできない「遅くならずに多くのテキストを出力できる」点を強調しています。
- Codexのスピードは、エンジニアが問題を定義し、サンドボックス環境でCodexを動作させることで、より広範な実験と自律的な問題解決を可能にします。
- 1ヶ月でBraintrustチームの50%がCodexに移行し、Ankur Goyal氏は「最大の利益はスピードだ」と述べています。
