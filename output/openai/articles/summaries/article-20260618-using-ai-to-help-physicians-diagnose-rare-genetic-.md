# Using AI to help physicians diagnose rare genetic diseases affecting children

## Key Points
- OpenAI o3 Deep Research推論モデルが、ボストン小児病院、ハーバード大学、OpenAIの共同研究で、以前未解決だった376件の小児希少遺伝性疾患症例の再分析に利用されました。
- このモデルは、未解決症例のうち18件で診断の手がかりを特定し、専門家によるレビューと臨床確認を経て、4.8%の追加診断率を実現しました。
- AIモデルは、臨床的特徴、遺伝パターン、バリアントの証拠、科学文献を統合して、人間が検証すべき仮説を生成する役割を担い、診断自体は医師が行いました。
- モデルは、入力データにないゲノム構造的イベントの推論（例：DiGeorge症候群に関連する22q11.2欠失）や、複数の遺伝子（例：*LAMA2*と*FOXP1*、*TTN*と*SRPK3*）が関与する複雑な病態の解明など、柔軟な推論能力を示しました。
- 本研究は、専門家主導のAI支援再分析が未解決のケースに新たな答えをもたらす可能性を示唆していますが、AIモデルを診断や医療判断に直接使用することは推奨されておらず、プライバシーやセキュリティへの配慮が今後の臨床導入には不可欠です。
