# How Axios uses AI to help deliver high-impact local journalism

## Key Points
- Axios LocalはAIを記事作成、編集、配信のワークフロー全体で活用し、持続可能で高品質な地域ジャーナリズムの提供を目指しています。
- カスタムGPT「Axiomizer」は、記者が作成した記事の質を高めるための見出しや要点（Why it matters, What's nextなど）の改善提案を行い、効率化に貢献しています。
- AIの活用により、編集者は基本的な修正作業から解放され、より人間の判断を要する質の高いジャーナリズムに集中できる時間を確保しています。
- AIは、市議会や教育委員会の記録など、これまでアクセス困難だった大量の公開データを迅速に要約し、記者がより多くの情報をカバーし、新たなストーリーを発見する手助けをします。
- AIは、ニュースレターのキュレーションや読者アンケート分析を効率化し、地元の声とのつながりを保ちつつ、より迅速に地域コミュニティに役立つ情報を提供するのに貢献します。
