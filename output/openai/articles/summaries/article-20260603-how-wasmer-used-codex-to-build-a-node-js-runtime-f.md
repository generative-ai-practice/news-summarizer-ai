# How Wasmer used Codex to build a Node.js runtime for the edge

## Key Points
- WasmerはCodexを活用し、WebAssemblyサンドボックス内でNode.jsワークロードを実行できるJavaScriptランタイム「Edge.js」を開発しました。
- このプロジェクトはCodexの導入により開発速度が10倍から20倍に加速され、通常1年かかる作業がわずか2週間で完了しました。
- Codexはプロジェクトの初期段階から最終製品の仕上げまで、またバグの特定、根本原因の特定、さらにはアセンブリレベルでの低レベルなデバッグに至るまで幅広く利用されました。
- WasmerのエンジニアはCodexの推論能力の進化を経験し、IDEでのコード編集の時間を減らし、AIをガイドする役割に集中できるようになりました。
- この技術は、エッジでJavaScriptランタイムを実行するという、以前は大規模な企業でしか実現不可能だった目標を、小規模なWasmerチームが達成することを可能にしました。
