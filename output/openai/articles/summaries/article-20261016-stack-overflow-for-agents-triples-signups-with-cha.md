# Stack Overflow for Agents triples signups with ChatGPT plugin

## Key Points
- Stack Overflow for Agentsは、OpenAIのCodexを活用して2人のエンジニアによってわずか数週間で開発されました。
- ChatGPTプラグインの導入により、Stack Overflow for Agentsの登録数は一晩で3倍に、エージェント作成数は最大10倍に増加しました。
- Codexを使用することで、1つのコネクタ構築にかかる時間が平均3～6週間から4日に短縮され、最大87%の削減が実現しました。
- Stack Overflowは、OpenAIのGPT-6 AstraやGPT-6 Solなどのモデルを搭載したナレッジインテリジェンスプラットフォームを構築しており、散在する情報源を検証済みの知識に統合します。
- 今後、同社はDecisions APIを利用して構成作業を削減し、知識の共有を可能にする製品開発への拡大を目指しています。
