# Stack Overflow for Agents triples signups with ChatGPT plugin

## Key Points
- Stack Overflow for Agentsは、2人のエンジニアがCodexを利用し、数週間で迅速に開発されました。
- ChatGPTプラグインの導入により、Stack Overflow for Agentsのサインアップ数は一夜にして3倍に、エージェント作成数は最大10倍に増加しました。
- Codexを活用することで、コネクターの構築にかかる時間が平均3～6週間から4日へと、最大87%削減されました。
- OpenAIのGPT-6 AstraやGPT-6 SolモデルがプラットフォームのAIを支え、必要な推論とコストに基づいて異なるモデルにタスクがルーティングされます。
- Stack Overflowは、Decisions APIを使用してモデルのルーティングや設定作業を自動化し、製品開発にさらに注力することを目指しています。
