# OpenAI joins PORTS-Pike project

## Key Points
- OpenAIは、SB Energy、NVIDIA、米国エネルギー省と協力し、オハイオ州パイク郡のPORTS-Pike Technology Campusで約8ギガワットのIT容量を確保する契約を締結しました。
- このプロジェクトは、2032年までの6年間で35,000人の建設雇用と2,500人の長期運営雇用を創出し、OpenAIは地域社会助成基金に4,000万ドルを追加投資します。
- オハイオ州の約844,000人の大学生（18歳以上）に、2026年から2027年の学年度にCodexの8,400万ドル相当のクレジットが提供されます。
- データセンターは閉ループの空冷システムを採用し、水を効率的に再循環させることで、過去のプラントに比べて水使用量を大幅に削減します。
- NVIDIAはSB Energyに15億ドルを投資し、OpenAIと共同でデータセンターの設計、テスト、コミッショニングを行い、将来のスーパーコンピューター設計のモデルとなる技術を共有します。
