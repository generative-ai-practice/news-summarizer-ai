# Dreaming: Better memory for a more helpful ChatGPT

## Key Points
- ChatGPTは、ユーザーの好みや制約を学習し、会話全体で文脈を新鮮かつ関連性のあるものに保つ、より高性能でスケーラブルな記憶システム「Dreaming」の展開を開始しました。これにより、よりパーソナルで役立つ応答が可能になります。
- 記憶機能は2024年4月の「保存された記憶」から進化し、2025年4月にチャット履歴から自動的に記憶をキュレートする「Dreaming V0」が導入され、現在はさらに高性能で計算効率の高い「Dreaming V3」アーキテクチャが展開されています。
- この進歩により、関連事実の想起（例：ユーザーのカメラ設定の記憶による互換製品の推奨）、好みの順守（例：旅行計画における個人の興味や宿泊地の好みの考慮）、および時間経過に伴う記憶の自動更新（例：旅行期間に応じた場所情報の更新）の能力が大幅に改善されました。
- DreamingはPlusおよびProユーザーに提供されており、最近の改善により計算要件が約5分の1に削減されたため、今後数週間でFreeユーザーにも展開され、全ユーザーにとってよりスケーラブルな基盤を提供します。
- ユーザーは記憶概要ページを通じて、ChatGPTが記憶している内容を確認、情報追加・更新、または特定のトピックに関する指示提供を行うことができ、記憶を管理できます。
