# The next evolution of the Agents SDK

## Key Points
- Agents SDKが更新され、ネイティブサンドボックス実行とモデルネイティブハーネスを導入し、開発者がファイルやツールを横断して安全かつ長期間実行されるエージェントを構築できるようになります。
- 強化されたハーネスは、設定可能なメモリ、サンドボックス対応のオーケストレーション、Codexライクなファイルシステムツール、およびフロンティアエージェントシステムで一般的なプリミティブとの統合を提供します。
- ネイティブサンドボックス実行は、エージェントがファイルやツール、依存関係を持つ制御されたコンピューター環境で安全に動作するための実行レイヤーを提供し、複数のプロバイダーに対応します。
- ハーネスと計算環境を分離することで、セキュリティが向上し、エージェントの状態の外部化による実行の耐久性が確保され、スケーラビリティも高まります。
- これらの新機能は2026年4月15日にAPIを通じて一般提供され、標準のAPI料金が適用されます。将来的にはTypeScriptサポートや追加のエージェント機能が計画されています。
