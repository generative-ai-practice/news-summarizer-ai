# Introducing Advanced Account Security

## Key Points
- 高度なアカウントセキュリティは、ChatGPTおよびCodexアカウントへの不正アクセスを防ぐためのオプトイン設定で、デジタル攻撃のリスクが高いユーザーや、強力な保護を求めるユーザー向けに設計されています。
- この機能は、パスキーや物理セキュリティキーを必須としパスワードログインを無効化することでサインインを強化し、メールやSMSに代わるバックアップパスキーなどによるリカバリのみを許可します。
- サインインセッションの短縮、アカウントログイン時のアラートによるセッション管理の強化、およびアカウントからの会話データのモデルトレーニング自動除外により、セキュリティとプライバシーが向上します。
- Yubicoとの提携により物理セキュリティキーへのアクセスを容易にし、2026年6月1日からはTrusted Access for Cyberのメンバーにこの機能の有効化が義務付けられます。
