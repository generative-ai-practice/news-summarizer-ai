# Advancing computer use with Ironclad

## Key Points
- OpenAIは、AIエージェントが専門ソフトウェアを利用して複雑なビジネス問題を解決する能力を向上させるため、AI契約のリーダーであるIroncladと研究協力を行っています。
- この協力では、契約設定、承認、再利用可能な法的条項の構成など、法務、商業、調達にわたる11の複雑なタスクをAIエージェントの訓練・評価課題として開発しました。
- 最新のフロンティアモデルであるGPT-6 Astraは、Ironcladのタスクにおいて、GPT-5.6 Solと比較して平均スコアが32%向上し、試行あたりの推定時間は48%短縮されました。
- このコラボレーションにより、AIは契約プロセスにおける例外処理やビジネスルールの維持といった現実世界の課題に対応できるようになり、基盤モデル開発に顧客のニーズを直接反映できます。
- OpenAIは、今日のAIエージェントがまだ信頼性高く完了できない重要な専門業務について、他のソフトウェア企業との研究協力を募集しています。
