# Advancing computer use with Ironclad

## Key Points
- OpenAIは、AIエージェントが専門ソフトウェアを効率的に使用し、複雑なビジネス問題に対応できるようにするため、AI契約のリーダーであるIroncladと提携しました。
- この共同研究では、契約ワークフローにおける課題を訓練タスクに変換し、NDA設定や調達承認プロセス作成など11の複雑なタスクを特定しました。
- GPT-6 Astraは、研究評価においてGPT-5.6 Solと比較して平均スコアが32%高く（55.0%対41.6%）、試行あたりの推定時間は48%短縮（19.2分対37.0分）されました。
- このコラボレーションは、AIが契約ライフサイクル全体を理解し、ビジネスルールを維持しながら例外を処理することの重要性を浮き彫りにし、人間の監督の必要性を強調しています。
- OpenAIは、AIエージェントがまだ信頼性高く完了できない重要な専門タスクについて、研究協力を行うソフトウェア企業を募集しています。
