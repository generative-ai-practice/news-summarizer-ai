# Advancing computer use with Ironclad

## Key Points
- OpenAIとIroncladは提携し、AIエージェントを複雑な契約ワークフローで訓練・評価することで、プロフェッショナルなコンピュータ利用を推進しています。
- この研究において、GPT-6 AstraはGPT-5.6 Solと比較して、平均スコアが32%向上し、推定平均試行時間は48%短縮されました。
- 契約ワークフローは、非開示契約の作成や調達承認プロセスの設定など11のタスクに変換され、8〜50の基準で詳細に評価されました。
- この協力は、AIエージェントが例外処理やビジネスルールを維持しつつ、複雑な契約業務に対応できるようになることで、Ironcladの製品開発に貢献します。
- OpenAIは、AIエージェントがまだ完全に解決できない専門的なタスクについて、他のソフトウェア企業との研究協業を呼びかけています。
