# Advancing computer use with Ironclad

## Key Points
- OpenAIはAI契約のリーダーであるIroncladと協力し、AIエージェントの専門業務におけるコンピュータ利用能力の向上を目指しています。
- この研究では、契約書設定、承認プロセス作成、法的条項更新など、11の複雑な契約ワークフローをAIエージェントのトレーニング課題としています。
- 最新モデルであるGPT-6 Astraは、これらのIroncladタスクにおいて、GPT-5.6 Solと比較して平均スコアが32%向上し（55.0% vs 41.6%）、推定試行時間も48%短縮されました（19.2分 vs 37.0分）。
- この連携により、AIエージェントは企業固有のビジネスルールを理解し、複数ステップのワークフローを実行し、その作業が当初の要件を満たしているかを検証する能力を向上させています。
- OpenAIは、AIエージェントがまだ確実には完了できない重要な専門業務について、研究協力を希望するソフトウェア企業を募集しています。
