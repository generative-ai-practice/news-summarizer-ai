# Advancing computer use with Ironclad

## Key Points
- OpenAIは、契約のAIリーダーであるIroncladとの協業を通じて、AIエージェントを複雑な契約ワークフローで訓練・評価し、専門的なコンピューター利用の進歩を目指しています。
- GPT-6 Astraは、Ironcladタスクにおける研究評価で、GPT-5.6 Solと比較して平均スコアが32%高く、1回の試行あたりの推定時間も48%短縮され、モデルの能力と効率が大幅に向上しました。
- このトレーニングは、守秘義務契約の設定、調達承認プロセスの作成、法的条項の更新など、法律、商業、調達分野の11種類の現実的なタスクに基づいて行われ、各タスクは8から50の基準で評価されました。
- この協業により、AIエージェントは企業のビジネスルールを理解し、多段階のワークフローを実行し、その作業が元の要件を満たしていることを検証する能力が向上しました。
- Ironcladは、モデルの能力向上に伴い、AIを自社製品により広く活用する機会を見出しており、OpenAIは今後も同様の研究協業をソフトウェア企業に呼びかけています。
