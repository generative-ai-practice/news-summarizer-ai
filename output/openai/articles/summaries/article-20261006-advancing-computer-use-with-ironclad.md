# Advancing computer use with Ironclad

## Key Points
- OpenAIは、AIエージェントを複雑な契約ワークフローで訓練・評価するため、AI契約のリーダーであるIroncladと提携しました。
- GPT-6 Astraは、IroncladタスクにおいてGPT-5.6 Solよりも平均スコアが32%高く、試行あたりの推定時間は48%短縮されました。
- この研究では、契約書の設定、承認プロセスの作成、法的条項の更新など、経験豊富なユーザーが平均30〜40分を要する11の複雑なタスクが訓練・評価に用いられました。
- Ironcladの専門知識は、成功の定義と実際の顧客ニーズをモデル開発に反映させる上で不可欠であり、エージェントがビジネスルールを理解し、多段階のワークフローを実行する能力の向上を目指しています。
- この協業により、Ironcladは将来的にAIを自社製品にさらに統合し、法務・ビジネスチームが複雑な契約業務でAIの力を活用しつつ、必要な管理を維持できる機会を探っています。
