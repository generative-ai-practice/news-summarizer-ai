# Advancing computer use with Ironclad

## Key Points
- OpenAIは、専門ソフトウェアにおけるAIエージェントの能力向上を目指し、AI契約のリーダー企業であるIroncladと研究協力を行っています。
- このコラボレーションでは、契約の構成、承認、再利用可能な法的条件の更新など、複雑な契約ワークフローに関する11のタスクがAIエージェントのトレーニングおよび評価に使用されています。
- GPT-6 Astraは、これらの研究タスクにおいて、GPT-5.6 Solと比較して平均スコアが32%向上（55.0%対41.6%）、試行あたりの推定時間は48%短縮（37.0分対19.2分）しました。
- Ironcladとの協力は、AIエージェントがビジネスルールを維持しつつ例外を処理する契約プロセスの課題をモデル開発に組み込む上で重要であり、Ironcladは将来的にAIを自社製品により広く活用する機会を見出しています。
- OpenAIは現在、AIエージェントがまだ完全に解決できない複雑な専門タスクについて、少数のソフトウェア企業とのさらなる研究協力を募集しています。
