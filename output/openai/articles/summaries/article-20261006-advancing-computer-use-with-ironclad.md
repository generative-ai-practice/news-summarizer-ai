# Advancing computer use with Ironclad

## Key Points
- OpenAIとAI契約分野のリーダーであるIroncladは、複雑な契約ワークフローにおけるAIエージェントの訓練と評価で協力しています。この提携は、モデルの能力を向上させ、現実世界のビジネス課題に適用することを目指しています。
- 最新のフロンティアモデルであるGPT-6 Astraは、Ironcladのタスクにおいて、GPT-5.6 Solと比較して平均スコアが32%向上し、推定所要時間は48%短縮されました。
- 法務、商取引、調達に関する11の複雑なタスクが、AIエージェントの訓練課題として特定されました。これには、秘密保持契約の設定や調達承認プロセスの作成などが含まれ、熟練ユーザーであれば平均30〜40分かかる作業です。
- AIエージェントの能力が向上しても、ビジネスルールを維持し、例外を処理するためには、人間の監視と包括的な契約プラットフォームが引き続き不可欠です。
- OpenAIは、今日のAIエージェントがまだ確実に完了できない重要な専門業務について、ソフトウェア企業との研究コラボレーションを募集しています。
