# Advancing computer use with Ironclad

## Key Points
- OpenAIとIroncladは、AIエージェントが専門業務でコンピューターをより効果的に利用できるよう、複雑な契約ワークフローにおけるAIエージェントのトレーニングと評価で協業しています。
- この研究協力では、秘密保持契約の作成や調達承認プロセスの設定など11の契約タスクを特定し、モデルの練習のためにIroncladのソフトウェア環境を使用しました。
- 新モデルGPT-6 Astraは、IroncladタスクにおいてGPT-5.6 Solと比較して平均スコアが32%向上し（55.0% vs 41.6%）、試行あたりの推定平均時間も48%短縮（19.2分 vs 37.0分）されました。
- このコラボレーションは、AIエージェントがビジネスルールを理解し、複雑な契約タスクにおいて例外処理を行いつつも、チームが依拠するコントロールを維持することの重要性を強調しています。
- OpenAIは、AIエージェントがまだ信頼性高く完了できない重要な専門業務について、他のソフトウェア企業との研究協力を募集しており、具体的な課題や評価基準、安全なデータを提供できるパートナーを求めています。
