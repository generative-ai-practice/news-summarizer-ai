# Advancing computer use with Ironclad

## Key Points
- OpenAIはAI契約のリーダーであるIroncladと提携し、AIエージェントを複雑な契約ワークフローで訓練・評価する研究を進めています。
- この研究では、NDA設定や調達承認プロセスなど、Ironcladの実際の業務に基づく11のタスクがモデル訓練の課題として用いられました。
- GPT-6 Astraは、これらの研究タスクにおいてGPT-5.6 Solと比較して平均スコアが32%高く、試行あたりの推定時間も48%短縮されました。
- この協業は、AIエージェントがビジネスルールを理解し、人間の監視下で複雑な契約業務の自動化を進める可能性を示しています。
- OpenAIは、専門的なコンピュータ利用をさらに発展させるため、今日のAIエージェントではまだ信頼性の低い複雑なプロフェッショナルタスクに関する研究協力パートナーを募集しています。
