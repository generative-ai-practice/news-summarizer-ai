# Advancing computer use with Ironclad

## Key Points
- OpenAIはIroncladとの研究協力を通じて、AIエージェントを複雑な契約ワークフローで訓練・評価し、専門業務におけるコンピュータ利用の進歩を目指しています。
- この協力により、AIエージェントはNDA設定、調達承認プロセス作成、法的条項更新など11のタスクで訓練され、成功の基準はIroncladの専門知識に基づいて定義されました。
- GPT-6 Astraは、これらのIroncladタスクにおいて、GPT-5.6 Solと比較して平均スコアが32%向上し、試行あたりの推定時間は48%削減され、モデルの能力向上を示しました。
- IroncladのCTOは、AIが契約の複雑な領域で真に役立つためには、ビジネスワークフローを理解し、チームが依拠する統制を維持する必要があると述べています。
- OpenAIは、今日のAIエージェントでは信頼性高く完了できない重要な専門タスクについて、ソフトウェア企業との研究コラボレーションを募集しています。
