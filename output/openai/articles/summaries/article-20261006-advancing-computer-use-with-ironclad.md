# Advancing computer use with Ironclad

## Key Points
- OpenAIは、AIエージェントが専門的な作業でコンピューターをより効率的に使用できるよう、AI契約のリーダーであるIroncladと提携し、複雑な契約ワークフローのトレーニングおよび評価に取り組んでいます。
- GPT-6 Astraは、Ironcladタスクに関する研究評価において、GPT-5.6 Solと比較して平均スコアが32%向上し、試行あたりの推定時間が48%短縮されました。
- この共同研究では、秘密保持契約の作成、調達承認プロセスの設定、法的条項の更新など、法務・商業・調達分野の11の複雑なタスクをAIエージェントのトレーニング課題として活用しています。
- AIエージェントの能力が向上しても、ビジネスルールや統制の維持には人間の監視が依然として重要であり、これはIroncladの顧客が直面する課題を反映しています。
- OpenAIは、今日のAIエージェントでは確実に完了できない重要な専門タスクに取り組むソフトウェア企業との研究協力を募集しており、実際の課題を通じてモデルを改善することを目指しています。
