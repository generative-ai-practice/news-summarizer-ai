# Advancing computer use with Ironclad

## Key Points
- OpenAIは、専門ソフトウェアを使用した複雑なビジネス問題解決において、AIエージェントの能力と効率を向上させることを目指している。
- 契約管理ソフトウェアのIroncladと提携し、契約業務のワークフローをAIエージェントのトレーニングおよび評価タスクに変換している。
- GPT-6 Astraは、研究評価においてGPT-5.6 Solより平均スコアが32%高く、試行あたりの推定時間は48%短縮された。
- このコラボレーションは、AIが契約プロセスにおける例外処理やビジネスルールの維持といった現実世界の課題に取り組む上で、基盤となるモデル開発に顧客ニーズを反映させている。
- OpenAIは、複雑な専門業務におけるAIの進歩のため、重要な専門タスクに取り組む少数のソフトウェア企業との研究コラボレーションを求めている。
