# Rakuten fixes issues twice as fast with Codex

## Key Points
- 楽天はOpenAIのコーディングエージェント「Codex」を活用し、ソフトウェアをより迅速かつ安全に出荷することで、MTTR（平均復旧時間）を50%削減しました。
- Codexは、KQLベースの監視と診断を含む運用ワークフローでインシデント対応を圧縮し、根本原因の特定と修復を加速させることで、復旧時間を約50%短縮しました。
- CI/CDパイプラインにCodexを統合し、自動的なコードレビューと脆弱性チェックを実施することで、社内標準に準拠した安全なソフトウェアの迅速なリリースを可能にしました。
- Codexは、完全には定義されていない要件からでもフルスタックビルド（Python/FastAPIバックエンドとSwift/SwiftUI iOSアプリなど）を実行でき、四半期単位のプロジェクトを数週間に短縮しました。
- エンジニアリングの役割は、コードの記述から、より明確な仕様の作成と、Codexによる出力の検証へとシフトしています。
