# Using skills

## Key Points
- スキルは、ChatGPTが特定のタスクを一貫して実行できるよう導く、再利用可能で共有可能なワークフローです。これにより、タスクの手順や形式の再説明が不要になり、高品質な出力を効率的に得られます。
- スキルは、名前・説明、SKILL.mdファイルに記述されたステップバイステップの指示、および関連するテンプレートやガイドラインなどのリソースを含みます。
- SKILL.mdファイルはMarkdown形式のプレーンテキストで、スキルの手順書として機能し、持ち運び可能であり、他のAIアプリケーションでも再利用できるオープンスタンダードです。
- スキルは、特に複数ステップや特定の形式が必要なタスクにおいて、出力の一貫性を高め、ベストプラクティスを組み込み、チームの知識共有を促進し、異なる場面での再利用を可能にします。
- スキルの作成は、繰り返されるタスクの特定から始まり、明確な指示を与えてChatGPTにドラフトを生成させ、それをレビューしてインストールし、日常業務で活用します。
