# Using skills

## Key Points
- スキルはChatGPTに特定のタスクの実行方法を指示する再利用可能で共有可能なワークフローで、一貫性のある高品質な出力を保証し、繰り返し行う作業の効率化を図ります。
- スキルは名前と説明、SKILL.mdファイルによる詳細なワークフロー指示、およびテンプレートやガイドラインなどの補助リソースで構成され、タスクの一貫性、ベストプラクティスの組み込み、知識共有、広範な再利用を促進します。
- SKILL.mdファイルはMarkdown形式のプレーンテキスト指示書であり、スキルのプレイブックとして機能し、その移植性とオープンスタンダードとしての設計により、様々なAIアプリやプラットフォームでの共有や再利用が可能です。
- スキルの構築と利用は、反復可能なタスクの特定、詳細な指示の記述、ドラフトのレビューとインストール、日常業務での活用、そしてワークスペース内での共有という5つのステップで行われます。
- スキルは特定のタスクのワークフローを教える一方で、GPTsは目的志向のカスタムChatGPTを提供し、プロジェクトはチームが共通の目標に向かって作業するためのコンテキストを提供することで、それぞれ異なるが補完的な役割を果たします。
