# Using skills

## Key Points
- スキルは、ChatGPTが特定のタスクを一貫して実行するための、再利用可能で共有可能なワークフローです。これにより、繰り返しの手順やフォーマットの説明にかかる時間を削減し、高品質な成果を得られます。
- SKILL.mdファイルは、Markdown形式で書かれたスキルの手順書であり、タスクの実行方法をChatGPTに指示するポータブルなオープン標準として設計されています。
- スキルを利用することで、出力の一貫性、専門家によるベストプラクスの組み込み、チーム内での知識共有、および様々な用途での幅広い再利用が可能になります。
- スキルの構築は、繰り返しのタスクを特定し、入力・出力・制約を定めた上で、ステップバイステップの指示を記述することから始まります。作成されたスキルはChatGPTにインストールして日常業務で活用し、必要に応じてワークスペース内で共有できます。
