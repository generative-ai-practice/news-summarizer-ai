# Using skills

## Key Points
- スキルは、ChatGPTに特定のタスクを反復的かつ一貫して実行させるための、再利用可能で共有可能なワークフローです。これにより、手順の再説明やフォーマットの調整にかかる時間を削減し、高品質な出力を効率的に得られます。
- スキルは、名前、説明、SKILL.mdファイル（Markdown形式のステップバイステップの指示書）、およびテンプレートやツールアクセスなどのリソースで構成されます。
- スキルを構築するには、まず自動化したい繰り返しの多いタスクを特定し、その入力、出力、手順、および品質チェックを明確に定義してChatGPTに指示します。
- 作成されたスキルはChatGPTにインストールされ、ワークスペースで有効にすることで自動的に、または@メンションにより明示的に利用可能となり、必要に応じて組織内で共有できます。
- スキル、GPT、プロジェクトはそれぞれ異なる役割を持ち、スキルは特定のタスクのワークフロー、GPTはカスタムのChatGPT、プロジェクトはチームの共同作業を支援し、互いに補完して機能します。
