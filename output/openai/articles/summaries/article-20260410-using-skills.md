# Using skills

## Key Points
- スキルとは、ChatGPTに特定のタスクの実行方法を教える、再利用可能で共有可能なワークフローです。これには名前、説明、ステップバイステップの指示（SKILL.mdファイル）、およびテンプレートやガイドラインなどのリソースが含まれます。
- SKILL.mdファイルは、Markdown形式で記述されたプレーンテキストの指示書であり、ChatGPTがワークフローを一貫して実行するためのプレイブックとして機能します。これは持ち運び可能で、オープンスタンダードとして設計されています。
- スキルは、複数ステップのタスクや特定の要件において、一貫性の確保、ベストプラクティスの組み込み、チーム内での知識共有、および様々なチャットやユースケースでの再利用を可能にします。
- スキルの作成は、繰り返し可能なタスクの特定、明確な指示の記述、ChatGPTでのドラフト生成とインストールを通じて行われます。インストール後は、ChatGPTが関連するスキルを自動的に使用するか、ユーザーが明示的に選択して利用できます。
- スキル、GPT、およびプロジェクトは、異なるが補完的な目的を持つツールです。スキルは特定のタスクのワークフローを教え、GPTはチームの専門知識を拡張するカスタムChatGPTであり、プロジェクトはチームが共通の目標に向かって協力するためのコンテキストを提供します。
