# Using skills

## Key Points
- スキルは、ChatGPTに特定のタスクを指示するための、再利用可能で共有可能なワークフローです。名前、説明、SKILL.mdファイルに記述された手順、および関連リソースを含みます。
- スキルを活用することで、ChatGPTの出力の一貫性を高め、ベストプラクティスを組み込み、チーム内で標準化されたプロセスを共有し、多様なチャットやユースケースで再利用できます。
- SKILL.mdファイルはMarkdown形式のプレーンテキスト指示書であり、スキルの機能、必要な入力・出力形式、ステップバイステップの指示、最終チェックを定義し、移植性と再利用性に優れています。
- スキルは、繰り返しのタスクを特定し、ChatGPTに指示を与えて作成・インストールし、日常業務で活用・共有することで、効果的に構築・利用できます。
- スキル、GPT、プロジェクトはそれぞれ異なるが相互補完的なツールであり、スキルは特定のタスクのワークフローを、GPTはカスタム版ChatGPTを、プロジェクトはチームの協業コンテキストを提供します。
