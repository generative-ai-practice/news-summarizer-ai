# Using skills

## Key Points
- スキルは、ChatGPTに繰り返しのタスクを一貫して実行させるための、再利用可能で共有可能なワークフローです。これにより、手順や要件を再説明する時間を減らし、質の高い結果に集中できます。
- スキルは通常、その目的をChatGPTが認識するための名前と説明、SKILL.mdファイルに書かれた具体的なワークフロー指示、およびテンプレートやガイドラインなどの関連リソースで構成されます。
- SKILL.mdファイルはMarkdown形式のプレーンテキストで、スキルの実行手順（必要な入力、ステップ、出力形式、最終チェックなど）を記述します。移植性が高く、様々なツールで共有・再利用が可能です。
- スキルを活用することで、タスク処理の一貫性を高め、承認されたベストプラクティスを組み込み、チーム内で標準化されたプロセスを共有し、異なるチャットや用途でワークフローを再利用できます。
- スキルは、ChatGPTを特定の目的に特化させたGPTsや、チームで共通の目標に向かって作業するプロジェクトと連携し、それぞれが補完的な役割を果たします。
