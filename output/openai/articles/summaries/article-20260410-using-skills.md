# Using skills

## Key Points
- スキルは、ChatGPTに特定のタスクを実行させるための再利用可能で共有可能なワークフローであり、反復的なタスクを自動化し、一貫した高品質な出力を確保することを目的としています。
- スキルは通常、その関連性を認識させる「名前と説明」、ワークフローのステップバイステップのガイダンスを記述する「SKILL.mdファイル」、およびテンプレートやツールアクセスなどの「リソース」で構成されます。
- スキルを使用することで、出力の一貫性の向上、専門家によって承認されたベストプラクティスの組み込み、チーム全体での知識共有、および異なる用途でのワークフローの再利用が可能になります。
- SKILL.mdファイルは、Markdownで書かれたプレーンテキストの指示書であり、スキルの実行方法を一貫して指示するプレイブックとして機能し、移植性の高いオープンスタンダードです。
- スキル、GPT、プロジェクトは補完的なツールであり、スキルは特定のタスクのワークフローを定義し、GPTはチームの専門知識を拡張するカスタムChatGPTであり、プロジェクトはチームが共通の目標に向かって作業するためのコンテキストを提供します。
