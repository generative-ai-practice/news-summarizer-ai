# Using skills

## Key Points
- スキルは、ChatGPTが特定のタスクを一貫して実行するための、再利用可能で共有可能なワークフローです。これにより、手順の再説明を減らし、高品質な成果物を確実に得ることができます。
- スキルの「プレイブック」はMarkdown形式の「SKILL.md」ファイルで記述され、タスクの名称・説明、ステップバイステップの指示、必要な入力、出力形式、完了前の最終チェックなどを含みます。
- スキルは、繰り返し可能なタスクを特定し、ChatGPTに指示を作成させるかファイルをアップロードして構築します。ワークスペースにインストール後、関連スキルは自動的に使用されるか、@メンションで明示的に選択して日々の業務で活用・共有できます。
- スキルはGPTs（カスタムChatGPT）やプロジェクト（チームでの協業）と連携して機能し、マーケティング、営業、財務、エンジニアリングなど、様々な部門の業務で具体的な活用事例が示されています。
