# Using skills

## Key Points
- スキルは、ChatGPTに特定のタスクの実行方法を教える、再利用可能で共有可能なワークフローです。これにより、繰り返しの説明を減らし、一貫した質の高い出力を確保します。
- SKILL.mdファイルはMarkdown形式で記述され、スキルの手順書として機能します。タスクの内容、必要な入力、ステップバイステップの指示、出力形式、最終チェックを定義し、移植性とオープンスタンダード性を持ちます。
- スキルは、タスクの一貫性を保ち、専門家のベストプラクティスを組み込み、チーム内で標準化されたプロセスを共有し、異なる場面で再利用できるという利点があります。
- スキルの構築は、繰り返し可能なタスクの特定、具体的な指示の記述（ChatGPTによる生成またはアップロード）、スキルの確認とインストール、そして日常業務での活用と共有というステップで行われます。
- スキルは特定のタスクのワークフローを定義し、GPTsは目標指向のChatGPTカスタムバージョン、プロジェクトはチームの共通目標達成に向けたコンテキストや会話の共有を可能にし、それぞれが補完的に機能します。
