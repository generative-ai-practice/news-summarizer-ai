# Using skills

## Key Points
- スキルは、ChatGPTに特定のタスクを実行させるための再利用可能で共有可能なワークフローで、プロセスを一度定義すれば、タスクが発生するたびに確実に適用できます。
- 複数ステップ、構造化された形式、または特定の要件を伴う反復可能なタスクに特に有効で、一貫性、ベストプラクティス、チーム内での知識共有を促進します。
- SKILL.mdファイルは、スキルの手順をMarkdownで記述したプレーンテキストのプレイブックであり、ポータブルなオープンスタンダードとして設計されています。
- スキルは、反復可能なタスクを特定し、手順を記述し、ChatGPTでレビュー・インストールし、日常業務で使用し、必要に応じて共有することで作成・利用できます。
- スキルは、ChatGPTのカスタムバージョンであるGPTsや、チームが共通の目標に取り組むためのプロジェクトと連携して、異なるが補完的な目的を果たします。
