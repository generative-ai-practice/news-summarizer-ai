# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や重点分野に特化した専用スペースであり、チャット、ファイル、指示、関連コンテキストを1か所にまとめることで、継続的な作業を効率化します。
- プロジェクトの作成は、左側メニューから行い、名前を付けた後、ファイルや指示を追加したり、既存のチャットを移動したりできます。プランによっては共同編集者の招待も可能です。
- プロジェクトを使用することで、関連資料が整理され、安定した作業コンテキストが維持されるため、中断した場所から容易に再開でき、時間の経過とともに一貫した成果を得やすくなります。
- 長期的なリサーチ、複数ドラフトの執筆、定期的な計画、共通の目標を持つファイルや会話の管理、複数人での共同作業など、継続的なコンテキストを持つ作業に最適です。
- プロジェクト作成時に「プロジェクト専用メモリ」を選択すると、チャットのコンテキストをそのプロジェクト内に限定し、作業範囲を明確に保つことができます。対応プランでは、他のユーザーとプロジェクトを共有し、リアルタイムでの共同作業が可能です。
