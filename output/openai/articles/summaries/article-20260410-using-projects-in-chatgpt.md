# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、チャット、ファイル、指示、関連するコンテキストを一箇所に集約するための専用スペースであり、繰り返し背景を説明する手間を省きます。
- 長期にわたる作業に特に有用で、関連する資料を分散させずに一元的に管理し、作業を中断しても同じコンテキストで簡単に再開できます。
- プロジェクトは左メニューの「Projects」から作成でき、ファイルや指示の追加、既存のチャットの移動、および対応プランでは共同編集者の招待が可能です。
- 「project-only memory」設定を選択することで、チャットのコンテキストをそのプロジェクト内のみに限定し、異なる作業間の明確な境界を保つことができます。
- 共有プロジェクトは対応プランで利用可能で、共同作業者が同じファイル、指示、会話履歴にリアルタイムでアクセスでき、作業の重複を減らすのに役立ちます。
