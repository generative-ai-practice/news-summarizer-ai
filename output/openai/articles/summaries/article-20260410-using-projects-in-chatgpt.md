# Using projects in ChatGPT

## Key Points
- プロジェクトは、ChatGPT内で特定の作業や焦点領域のために、チャット、ファイル、指示、関連コンテキストを一つにまとめる専用スペースです。
- プロジェクトの作成は、左メニューから「Projects」を開き、新しいプロジェクトに名前を付けて、ファイルや指示を追加し、必要に応じて共同作業者を招待する手順で行います。
- プロジェクトは、継続的な作業においてコンテキストが散逸するのを防ぎ、ファイルの再アップロードや指示の繰り返しなしに、より安定した作業環境と一貫した結果を促進します。
- 「プロジェクト専用メモリ」を設定することで、チャットのコンテキストをそのプロジェクト内に限定し、他の会話とは独立させることで作業の境界を明確に保つことができます。
- サポートされるプランでは、プロジェクトを他のユーザーと共有でき、共同作業者が同じファイル、指示、会話履歴にリアルタイムでアクセスし、共同作業の効率を高めます。
