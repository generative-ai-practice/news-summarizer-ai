# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や重点領域のためにチャット、ファイル、指示、関連コンテキストを一元管理できる専用スペースです。これにより、長期的な作業の整理と効率化が図れます。
- プロジェクトは左メニューの「Projects」から作成し、ファイルを添付したり、プロジェクト指示を設定したり、既存のチャットを移動させたりできます。対応するプランでは共同作業者も招待可能です。
- プロジェクトを活用することで、コンテキストが散乱しやすい継続的な作業において、関連資料をまとめて管理し、作業の再開や一貫した結果の生成が容易になります。
- 継続的な調査、複数のドラフトを含む執筆、繰り返し行う計画プロセス、共同作業など、進行中のコンテキストを持つ作業にプロジェクトを使用することが推奨されます。
- 「プロジェクトのみのメモリ」機能により、チャットのコンテキストをプロジェクト内に限定して作業領域を分離できます。また、対応プランの共有プロジェクトは、共同作業者がリアルタイムで同じ情報にアクセスし、効率的なコラボレーションを可能にします。
