# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や焦点領域のための専用スペースで、チャット、ファイル、指示、関連コンテキストを一箇所にまとめて管理します。
- プロジェクトを作成するには、左メニューから「Projects」を開き、新しいプロジェクトの名前を付けます。その後、ファイルや指示の追加、既存チャットの移動、共同作業者の招待が可能です。
- 長期的な調査、複数草稿の執筆、定期的な計画など、継続的なコンテキストを持つ作業に特に有用です。これにより、コンテキストが散らばるのを防ぎ、一貫した結果を維持しやすくなります。
- 「プロジェクト専用メモリ」を設定すると、チャットのコンテキストがそのプロジェクト内に限定され、作業領域間の明確な境界を保つことができます。
- 対応プランでは、プロジェクトを他のユーザーと共有でき、共同作業者が同じファイル、指示、会話履歴にリアルタイムでアクセスし、効率的なコラボレーションが可能です。
