# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクト機能は、チャット、ファイル、指示、および関連するコンテキストを1か所にまとめて管理できる専用スペースです。これにより、同じ背景情報を繰り返し入力する手間を省き、作業を効率化します。
- 長期にわたる作業や継続的なコンテキストが必要なタスクに特に有用で、過去のチャットや資料が散逸するのを防ぎ、中断したところからスムーズに作業を再開できます。
- プロジェクトは左メニューから新規作成し、名前を付けた後、ファイルや指示を追加したり、既存のチャットを移動させたりしてセットアップできます。
- 「プロジェクト限定メモリ」設定を有効にすると、そのプロジェクト内のチャットコンテキストがプロジェクトに限定され、他の会話からの影響を受けずに作業領域の明確な境界を維持できます。
- 対応プランでは、プロジェクトを他のユーザーと共有することで、共同作業者が同じファイル、指示、会話履歴にリアルタイムでアクセスし、協力体制を強化することが可能です。
