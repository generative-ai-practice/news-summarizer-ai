# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や重点分野のための専用スペースであり、チャット、ファイル、指示、関連するコンテキストを一元管理できます。
- これにより、過去の作業に簡単に戻り、同じ背景情報を再入力することなく、継続的な作業や時間のかかるプロジェクトを効率的に進めることができます。
- プロジェクトを作成するには、左メニューから「プロジェクト」を開き、新しいプロジェクト名を設定し、ファイルや指示を追加したり、既存のチャットを移動させたりします。
- プロジェクト固有のメモリ設定により、チャットのコンテキストをそのプロジェクト内に限定し、他のプロジェクトとの混同を防ぐことが可能です。
- 対応するプランでは、プロジェクトを他のユーザーと共有でき、共同作業者が同じファイル、指示、会話履歴にリアルタイムでアクセスして連携作業を進めることができます。
