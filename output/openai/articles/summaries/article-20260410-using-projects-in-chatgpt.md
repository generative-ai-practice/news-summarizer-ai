# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や焦点領域のためにチャット、ファイル、指示、関連コンテキストを一元管理できる専用スペースです。同じ背景情報を繰り返し入力する手間を省きます。
- 長期間にわたる作業に特に有用で、関連する資料を1か所に集約することで、中断した作業の再開や、より一貫した成果の生成を容易にします。
- プロジェクトは左メニューから新規作成し、ファイルやプロジェクト指示を設定したり、既存のチャットを移動させたりできます。一部のプランでは、共同作業者を招待し、リアルタイムで共有された資料と会話履歴で協業が可能です。
- プロジェクトの利用は、継続的なコンテキストを必要とする作業に最適です。例えば、長期調査、複数ドラフトの執筆、定期的な計画、特定の目標に関連するファイルや会話の管理、または複数人での協同作業などが挙げられます。
- 「プロジェクト限定メモリ」機能を選択すると、そのプロジェクト内のチャットコンテキストがプロジェクト内のみに限定され、外部の会話を参照しないため、作業領域の分離と境界の明確化に役立ちます。
