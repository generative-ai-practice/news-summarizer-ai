# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や焦点領域のための専用スペースであり、チャット、ファイル、指示、関連するコンテキストを1か所に集約し、継続的な作業やコラボレーションに役立ちます。
- プロジェクトは左メニューから作成でき、ファイルや指示の追加、既存チャットの移動が可能です。プランによっては共同編集者を招待することもできます。
- 継続的なコンテキストを持つ作業に特に有用で、関連する資料を一元管理することでコンテキストの散逸を防ぎ、より一貫した結果を生み出すことができます。
- 進行中のリサーチ、執筆、計画、学習、個人整理、共有コラボレーションなど、多岐にわたるユースケースで活用が推奨されます。
- 「プロジェクト固有のメモリ」設定により、プロジェクト内のチャットコンテキストを制限し、外部との分離を保つことができます。また、対応プランでは複数人でのリアルタイム共同作業も可能です。
