# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や注力分野のための専用スペースであり、チャット、ファイル、指示、および関連するコンテキストを1か所にまとめて保持できます。
- プロジェクトは長期にわたる作業に特に有用で、関連する資料を一元管理し、中断した場所から容易に作業を再開できるよう設計されています。
- プロジェクト作成時には「プロジェクトのみのメモリ」を選択でき、チャットのコンテキストをそのプロジェクト内に限定することで、作業範囲を明確に保つことができます。
- 対応プランではプロジェクトを他のユーザーと共有でき、共同作業者は同じファイル、指示、会話履歴にリアルタイムでアクセスし、作業の重複を減らすことが可能です。
- プロジェクトは、継続的な調査、執筆・編集、計画、学習、個人整理、共同作業など、多様なユースケースで効果的に活用できます。
