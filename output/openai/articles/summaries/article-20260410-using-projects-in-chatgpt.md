# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や注力分野のための専用スペースであり、チャット、ファイル、指示、関連コンテキストを一元管理できます。
- 長期にわたる作業に特に有用で、関連するすべての資料を1か所にまとめ、必要な時に同じコンテキストに戻って作業を再開できます。
- プロジェクトは、左メニューから新規作成し、ファイル追加、指示設定、既存チャットの移動、共同作業者の招待（プランによる）が可能です。
- 「プロジェクト専用メモリ」を設定すると、チャットのコンテキストがそのプロジェクト内に限定され、他の作業との明確な境界を保つことができます。
- 対応プランではプロジェクトを他のユーザーと共有でき、共同作業者は同じファイル、指示、会話履歴にリアルタイムでアクセスして効率的に協業できます。
