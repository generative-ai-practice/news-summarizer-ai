# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、チャット、ファイル、指示、関連するコンテキストを1か所にまとめる専用スペースを提供し、特定の作業や焦点領域において繰り返し背景情報を伝える手間を省き、一貫した結果を促進します。
- プロジェクトは左メニューから作成でき、ファイルやプロジェクト固有の指示を設定したり、既存のチャットを移動させたりすることが可能です。ChatGPT Enterpriseのお客様は、ワークスペースレベルで共有プロジェクトを管理し、ロールベースのアクセス制御を使用できます。
- プロジェクトは、長期間にわたる調査、複数のドラフトを含む執筆作業、定期的な計画、特定の目標に関連するファイルや会話のコレクション、または複数人での共同作業など、継続的なコンテキストを持つ作業に特に有用です。
- プロジェクトを作成する際に選択できる「プロジェクト限定メモリ」機能により、チャットのコンテキストはそのプロジェクト内に限定され、作業領域を分離し、プロジェクト間の明確な境界を維持するのに役立ちます。
- 対応プランでは、プロジェクトを他のユーザーと共有して共同作業を行うことができます。これにより、共同作業者全員が同じファイル、指示、会話履歴にリアルタイムでアクセスでき、個別の作業コピーを管理する必要がなくなります。
