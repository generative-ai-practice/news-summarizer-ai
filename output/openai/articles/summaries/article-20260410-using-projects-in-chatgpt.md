# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や焦点領域のための専用スペースです。チャット、ファイル、指示、関連するコンテキストを1か所に集約し、毎回背景を再説明する必要がなくなります。
- 継続的な作業や複数のドラフト、繰り返しの計画、共同作業に適しており、関連資料をまとめておくことで、より安定した作業コンテキストを確立し、一貫した結果を促進します。
- プロジェクトは左メニューから作成でき、ファイルや指示の追加、既存チャットの移動、共同編集者の招待（プランによる）が可能です。
- 「プロジェクト限定メモリ」機能により、チャットのコンテキストをプロジェクト内に閉じ込め、外部の会話から分離できます。
- サポートされているプランでは、共有プロジェクト機能を利用して、チームメンバーが同じ資料や会話履歴にアクセスし、リアルタイムで共同作業を行えます。
