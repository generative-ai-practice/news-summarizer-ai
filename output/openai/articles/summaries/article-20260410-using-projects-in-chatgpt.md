# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や焦点のための専用スペースで、チャット、ファイル、指示、関連コンテキストを一元的に管理できます。これにより、継続的な作業や共同作業が効率化されます。
- プロジェクトは左メニューから簡単に作成でき、ファイルや指示を追加したり、既存のチャットを移動させたりすることが可能です。プランによっては共同作業者の招待もできます。
- プロジェクトを利用することで、関連する全ての資料を一つの場所に集め、作業コンテキストの散逸を防ぎ、繰り返し情報の入力や検索をする手間を省き、一貫した成果を生み出すのに役立ちます。
- 長期的な研究、複数ドラフトの執筆、定期的な計画、共通の目標を持つファイル群、複数のメンバーによる共同作業など、継続的なコンテキストが必要な場合にプロジェクトが特に適しています。
- 「プロジェクト専用メモリ」はチャットのコンテキストをプロジェクト内に限定し、作業間の独立性を保ちます。共有プロジェクト機能（対応プランのみ）は、共同作業者全員が同じ情報にリアルタイムでアクセスできるため、作業の重複を減らします。
