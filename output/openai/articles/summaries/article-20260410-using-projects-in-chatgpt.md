# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や領域に特化した専用スペースで、チャット、ファイル、指示、関連コンテキストを一元管理し、継続的な作業効率を向上させます。
- プロジェクトは、左メニューの「Projects」から新規作成し、名前を付けてからファイルや指示を追加したり、既存のチャットを移動させたりできます。
- 複数日にわたるトピックの再訪、段階的なドラフトの洗練、繰り返し行う計画など、進行中のコンテキストを必要とする作業に特に有用です。
- 「プロジェクト専用メモリ」を設定すると、そのプロジェクト内のチャットコンテキストが完結し、他の会話とは明確な境界を保つことができます。
- 対応プランでは、プロジェクトを他のユーザーと共有でき、共同作業者が同じファイル、指示、会話履歴にリアルタイムでアクセスして連携を強化できます。
