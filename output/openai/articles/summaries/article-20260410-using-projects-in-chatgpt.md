# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や焦点領域のための専用スペースであり、チャット、ファイル、指示、関連コンテキストを1か所にまとめることで、繰り返し背景を説明する手間を省きます。
- 時間をかけて継続する作業に特に有用で、関連する資料を一元管理し、中断したところから容易に作業を再開でき、時間とともに一貫した結果を生み出しやすくなります。
- プロジェクトは、左メニューから「Projects」を開き、新規作成して名前を付けることで開始できます。その後、ファイルやプロジェクト指示の追加、既存チャットの移動、そして対応プランでは共同作業者の招待が可能です。
- 使用の目安としては、長期的なリサーチ、複数ドラフトを含む執筆作業、定期的な計画プロセス、または複数の関係者がアクセスする必要がある共有作業など、継続的なコンテキストを伴う作業に適しています。
- プロジェクト作成時には「プロジェクト限定の記憶」を選択でき、チャットのコンテキストをプロジェクト内に限定します。また、対応プランではプロジェクトを共有し、協力者が同じファイル、指示、会話履歴をリアルタイムで利用できます。
