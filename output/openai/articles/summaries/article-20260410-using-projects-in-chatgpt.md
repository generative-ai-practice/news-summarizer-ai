# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や焦点領域のためにチャット、ファイル、指示、関連コンテキストを一元的に整理できる専用スペースです。
- 時間をかけて継続する作業に特に有用で、コンテキストが散逸するのを防ぎ、作業の中断からの再開を容易にし、より一貫した結果を促進します。
- プロジェクトは左側のメニューから簡単に作成でき、ファイルや指示の追加、既存チャットの移動が可能で、プランによっては共同編集者を招待できます。
- 「プロジェクト専用メモリ」を設定することで、チャットのコンテキストをそのプロジェクト内に限定し、作業領域間の明確な境界を維持できます。
- 対応するプランでは共有プロジェクト機能が利用でき、共同編集者が同じファイル、指示、会話履歴にリアルタイムでアクセスし、共同作業の効率を高めます。
