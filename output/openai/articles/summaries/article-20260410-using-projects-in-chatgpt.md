# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、チャット、ファイル、指示、関連コンテキストを専用スペースに集約し、継続的な作業やコラボレーションを効率化する機能です。これにより、毎回同じ背景情報を繰り返す必要がなくなります。
- 新しいプロジェクトは左側のメニューから作成でき、ファイルや指示を追加したり、既存のチャットを移動したりできます。Enterpriseプランでは、管理者が共有プロジェクトを管理し、ロールベースでアクセスを制御できます。
- プロジェクトは、長期的な調査、複数のドラフトを含む執筆、定期的な計画、特定の目標に紐づく資料の収集、複数人での共同作業など、継続的なコンテキストを持つ作業に特に役立ちます。
- 「プロジェクトのみの記憶」設定を選択すると、チャットのコンテキストがそのプロジェクト内に限定され、他の会話との境界を明確に保ちながら作業を進めることができます。
- 対応プランでは、プロジェクトを他のユーザーと共有でき、共同作業者はリアルタイムで同じファイル、指示、会話履歴にアクセスし、効率的な共同作業が可能です。
