# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、チャット、ファイル、指示、関連コンテキストを1か所にまとめる専用の作業空間です。
- プロジェクトは、長期にわたる作業や共同作業のために特に有用で、コンテキストを安定させ、中断からの再開や一貫した結果の生成を容易にします。
- プロジェクトの作成は左メニューから簡単に行え、ファイルや指示の追加、既存チャットの移動、そして対応プランによっては共同作業者の招待も可能です。
- 「プロジェクトのみの記憶」設定を選択することで、チャットのコンテキストをそのプロジェクト内に限定し、他の会話から作業領域を分離できます。
- 対応プランでは共有プロジェクトを利用でき、共同作業者が同じファイル、指示、会話履歴にリアルタイムでアクセスし、効率的に共同作業を進めることができます。
