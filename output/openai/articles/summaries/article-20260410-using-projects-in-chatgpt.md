# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や焦点領域のための専用スペースで、チャット、ファイル、指示、関連するコンテキストを一箇所にまとめて管理できます。
- プロジェクトは、長期にわたる作業や段階的な作業において、過去の文脈を再入力する手間を省き、作業の継続性や一貫した結果を促進します。
- プロジェクトの作成は、左メニューから「Projects」を選択し、名前を付けて行うことができ、ファイル追加、指示設定、既存チャットの移動が可能です。
- 継続的なコンテキストを持つ作業（長期的な調査、複数ドラフトの執筆、繰り返しの計画、共同作業など）にプロジェクトの使用が推奨されます。
- 「プロジェクト専用メモリ」を設定すると、チャットのコンテキストがそのプロジェクト内に限定され、対応するプランではリアルタイムで共同作業者とプロジェクトを共有できます。
