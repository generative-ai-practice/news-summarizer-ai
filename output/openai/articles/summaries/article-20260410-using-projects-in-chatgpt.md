# Using projects in ChatGPT

## Key Points
- ChatGPTのプロジェクトは、特定の作業や焦点のための専用スペースであり、チャット、ファイル、指示、関連コンテキストを一元管理できます。これにより、同じ背景情報を繰り返し入力する手間を省き、長期にわたる作業に特に有効です。
- プロジェクトは左側のメニューから作成でき、名前を付けてからファイルや指示を追加したり、既存のチャットを移動させたりできます。一部のプランでは、共同作業者を招待してコラボレーションを行うことも可能です。
- プロジェクトは、単一の会話を超えて継続する作業においてコンテキストが散らばるのを防ぎます。関連する全ての資料を一箇所にまとめることで、作業の再開が容易になり、一貫した結果を継続的に生み出すことができます。
- 継続的な調査、複数ドラフトの執筆、定期的な計画プロセス、単一の目標に紐づくファイル群、または複数人での共有作業など、進行中のコンテキストがある場合にプロジェクトの使用が推奨されます。
- プロジェクト作成時に「プロジェクト専用メモリ」を選択すると、チャットのコンテキストをそのプロジェクト内に限定し、他の会話とは独立させることができます。また、対応プランではプロジェクトを共有することで、共同作業者が同じファイル、指示、会話履歴にリアルタイムでアクセスし、効率的な連携が可能になります。
