# Introducing the Agents API

## Key Points
- OpenAIは、Codexハーネスを基盤とし、オーケストレーション、長時間セッション、ツール使用を管理するAgents APIをパブリックベータ版で提供開始しました。
- 開発者は、モデル、ツール、環境を指定する単一のAPI呼び出しで、本番環境対応のクラウドエージェントを構築・実行できます。
- エージェントの計算環境として、OpenAIホストのサンドボックス、自身のインフラ、またはBlaxel、Cloudflareなどのパートナーの提供する環境から選択可能です。
- Agents APIは、進化するCodexハーネスを通じて、長時間セッションにわたるコンテキスト管理、効率的なツール利用、およびサブエージェントによる並列作業をサポートします。
- 本APIはオープンソースのCodexハーネスによって動作し、追加料金なしで利用可能であり、エージェントが使用するトークンとツールに対してのみ課金されます。
