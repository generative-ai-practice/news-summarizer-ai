# OpenAI models, Codex, and Managed Agents come to AWS

## Key Points
- OpenAIとAWSは戦略的パートナーシップを拡大し、企業がAWS環境内でOpenAIのモデル、エージェント、ツールを利用できるようにします。
- OpenAIのフロンティアモデルGPT-5.5を含むOpenAIモデルがAmazon Bedrockで提供開始され、顧客は既存のAWSサービス、セキュリティ、IDシステム、調達プロセス内で構築できます。
- OpenAIのコーディングスイートであるCodexがAWS上で利用可能になり、Amazon Bedrockから直接提供されるOpenAIモデルで、ソフトウェア開発ライフサイクル全体の生産性を加速します。
- OpenAIを搭載したAmazon Bedrock Managed Agentsが開始され、企業はコンテキストを維持し、多段階のワークフローを実行し、複雑なビジネスプロセス全体でアクションを実行できる高度なエージェントをデプロイできます。
- これらの機能は、企業が既存のAWSインフラ、セキュリティ、ガバナンス、調達ワークフローを維持しながら、AIをビジネス全体でより迅速かつ安全に活用できる道を提供します。
