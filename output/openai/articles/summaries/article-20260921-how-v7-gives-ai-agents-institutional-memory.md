# How V7 gives AI agents institutional memory

## Key Points
- V7 Goは、企業内の散在したファイルからビジネスコンテキストを抽出し、エージェントが活用できる「Context Graph」として組織化するAIエージェントプラットフォームです。これにより、モデルは企業の履歴を毎回再学習することなく利用できます。
- Context GraphはGPT-5.6 Lunaを利用してエンティティ、関係性、引用元情報を整理し、複雑な多段階ワークフローの基盤となります。GPT-6 Astraは最も困難なグラフクエリで89%の精度を達成しています。
- V7 Goの導入により、資産管理の取引スクリーニングが21倍高速化され、金融サービスチームの文書レビューコストが12,000ドル削減されるなど、顧客は大幅な業務効率向上を実現しています。
- OpenAIモデルの活用は、GPT-5.6 Solがツール呼び出しエラー率を2.7%から0.2%に、GPT-5.6 Lunaが文書あたりのコストをGPT-5.4 miniと比較して78%削減するなど、V7 Goの複雑なワークフローを円滑に進める上で重要な役割を果たしています。
- V7の長期目標は、Context Graphの変更をトリガーとしてワークフローを自動化し、企業がよりプロアクティブに情報を活用できる共有メモリを構築することです。
