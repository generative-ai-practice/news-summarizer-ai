# Introducing ChatGPT Images 2.0

## Key Points
- ChatGPT Images 2.0は、改善されたテキストレンダリング、多言語サポート、高度な視覚的推論を備えた最先端の画像生成モデルです。
- 本モデルは、詳細な指示への高い追従性、オブジェクトの正確な配置、高密度なテキストのレンダリングが可能で、幅広いアスペクト比に対応します。
- 特に日本語、韓国語、中国語など非ラテン文字言語のテキスト生成能力が大幅に向上し、グローバルでの利用がより実用的になりました。
- Thinkingモデルを選択した場合、リアルタイム情報のウェブ検索、一つのプロンプトからの複数画像生成、出力の自己検証などの高度な機能を備え、複雑な視覚タスクに対応します。
- ChatGPT Images 2.0はChatGPTおよびCodexの全ユーザーに提供され、Thinkingモードの高度な機能はChatGPT Plus、Pro、Businessユーザーが利用可能です。
