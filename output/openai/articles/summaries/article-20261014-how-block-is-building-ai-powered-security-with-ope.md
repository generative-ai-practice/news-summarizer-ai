# How Block is building AI-powered security with OpenAI technology

## Key Points
- BlockはOpenAI Daybreakを含むAIシステムを活用し、脆弱性の発見、検出、対応といったセキュリティ業務を人間が対応できない規模で自動化しています。
- AIの導入により、提案された検出変更を7ヶ月間のテレメトリで再実行する時間が1時間未満に短縮され、高レベルの脆弱性に対する自動パッチ提案まで18分で可能になりました。
- 誤検知のトリアージにかかるアナリスト時間を四半期あたり約600時間削減し、調査活動に約1,100アナリスト時間を充てることで、トリアージのスループットが50%向上しました。
- Daybreakは攻撃パターンを仮説化し、一連の攻撃を連鎖させて、長年見過ごされてきた脆弱性を特定するのに貢献しています。
- AIは技術的な能力を提供する一方で、人間のセキュリティチームが結果の検証、組織の文脈と戦略の提供、コード変更のデプロイを行うことで、責任あるAI運用を確保しています。
