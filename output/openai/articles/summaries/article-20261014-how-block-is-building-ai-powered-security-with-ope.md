# How Block is building AI-powered security with OpenAI technology

## Key Points
- BlockはOpenAI Daybreakを含むAIシステムを導入し、脆弱性の発見、検出、対応の時間を大幅に短縮しています。これにより、セキュリティチームは戦略的な業務に注力できるようになりました。
- 検出変更の検証は7ヶ月分のテレメトリに対し1時間未満で完了し、高レベルの脆弱性提出から自動パッチ提案までは18分に短縮されました。
- AIによる自動トリアージシステムの結果、誤検知のトリアージにかかるアナリストの時間は四半期あたり約600時間削減されました。
- 情報収集と調査能力は50%向上し、四半期あたり約1,100アナリスト時間の調査が完了するようになり、新たな自律的ハンティング機能も確立されました。
- このAI技術は、高度なセキュリティ能力を幅広い組織が利用可能にし、防御側が攻撃者に対して優位に立つ機会を提供しています。
