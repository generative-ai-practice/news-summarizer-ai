# How Block is building AI-powered security with OpenAI technology

## Key Points
- Block社はOpenAI Daybreakを含むAIシステムを活用した「OpenAI Defense Factory」を導入し、脆弱性発見、検出、対応を大規模に自動化しています。
- 従来の数週間かかる作業が数時間に短縮され、例えば検出変更の再検証が1時間未満、高レベルの脆弱性に対する自動パッチ提案が18分で可能になりました。
- 誤検知のトリアージで四半期あたり約600アナリスト時間を節約し、これにより四半期あたり約1,100アナリスト時間の詳細な調査を可能にしています。
- AIは単一の脆弱性だけでなく、攻撃パターンを仮説化し、複数の攻撃を連鎖させてエンドツーエンドの侵害経路を特定することで、より複雑な脅威への対応を強化します。
- AIシステムは人間の検証と監督の下で運用され、AIの判断が実証されるにつれて、より機密性の高いシステムへの適用を段階的に進めることで、セキュリティチームは予防的な戦略的作業に集中できます。
