# How Block is building AI-powered security with OpenAI technology

## Key Points
- BlockはOpenAI DaybreakなどのAIシステムを導入し、脆弱性の発見、検出、対応をAI主導で行うことで、人間のチームでは対応しきれない規模のセキュリティ運用を可能にしています。
- AIの活用により、セキュリティチームは以前は数週間かかっていた作業を数時間に短縮し、脆弱性修正の時間を大幅に圧縮して戦略的な業務に注力できるようになりました。
- 具体的な成果として、提案された検出変更を7ヶ月間のテレメトリーデータで検証するのに1時間未満、高レベルの脆弱性から自動でパッチが提案されるまで18分という迅速化が実現しています。
- また、四半期あたり約600アナリスト時間の誤検知トリアージ作業が削減され、調査能力は約1,100アナリスト時間に相当する増加を見せています。
- AIは単一の脆弱性だけでなく、攻撃パターンを仮説立て、複数の攻撃を連鎖させて完全な侵害経路を特定するなど、防御側が高度な脅威に対抗するための新しい能力を提供しています。
