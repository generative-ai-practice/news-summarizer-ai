# How Block is building AI-powered security with OpenAI technology

## Key Points
- BlockはOpenAIのAIシステム（Daybreakなど）を活用し、脆弱性の発見、検出、対応を大幅に加速させ、セキュリティチームが戦略的業務に集中できる時間を生み出しています。
- 検出チューニングでは、7ヶ月分のテレメトリーに対する検出変更の再現が1時間未満に短縮され、これまでの手作業による数週間かかる作業が劇的に改善されました。
- 高レベルの脆弱性の提出から自動提案パッチの生成まで、わずか18分で完了するようになり、対応時間を大幅に圧縮しています。
- 誤検知のトリアージにかかるアナリストの作業時間は四半期あたり約600時間削減され、トリアージスループットと情報収集・調査能力がそれぞれ50%向上しました。
- AIは単一の脆弱性から攻撃パターンを仮説化し、複雑な攻撃経路を特定する能力を持ち、四半期あたり約1,100アナリスト時間の調査を自律的に実施します。
