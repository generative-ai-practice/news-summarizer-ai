# Introducing the Admin plugin for ChatGPT Work and Codex

## Key Points
- ChatGPT WorkとCodex向けにAdminプラグインが導入され、ワークスペース情報の分析、設定更新、リクエストへの対応を一つの会話で迅速かつ容易に行えるようになりました。
- 管理者は、プラグインを使って利用状況の把握、メンバーとグループの管理、アクセスと権限の管理、利用制限や支出リクエストの調整といった日常業務を直接実行できます。
- カスタム開発なしで、定期的な管理ワークフローや大量のリクエスト処理を自動化することが可能となり、手動監視の削減とポリシーの一貫した適用に貢献します。
- Adminプラグインは各ユーザーの既存のロールと権限内で動作し、より広範なアクセス権を付与することなく、ワークスペースのポリシーと承認要件を遵守します。
- OpenAIのITチームは、このプラグインを活用してデータ分析やレポート生成を行い、Slack連携によりITリクエストの約45%を自動的に解決し、運用効率を向上させています。
