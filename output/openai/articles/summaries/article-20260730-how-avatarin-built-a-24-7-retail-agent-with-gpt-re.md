# How avatarin built a 24/7 retail agent with GPT-Realtime

## Key Points
- avatarinはOpenAIのGPT-Realtimeを活用し、ヤマダデンキ向けに24時間年中無休の多言語対応AIショッピングエージェントを開発しました。
- このAIエージェントは音声、テキスト、視覚理解を統合し、低遅延で自然な会話を実現し、顧客の真のニーズを理解するために積極的な質問を行います。
- 2週間の公開キャンペーンで約30,000人がエージェントを利用し、使用後アンケートでは92%が肯定的な回答を示しました。
- このサービスは、店舗営業時間外のサポートを可能にし、顧客が製品選びで何を重視し、なぜためらうかといった貴重な洞察を会話から得られるようにしました。
- avatarinは、1つのAIが企業ブランドを体現し、Web、電話、実店舗などあらゆるインターフェースで一貫した顧客体験を提供する「One Intelligence. One Brand. Every interface.」のビジョンを掲げています。
