# How engineers at Nextdoor use Codex to build without limits

## Key Points
- NextdoorのエンジニアはCodexとGPT-5.5を活用し、構築方法よりも達成すべき成果に焦点を当てる「成果エンジニアリング」へとシフトしました。
- Codexにより、モバイル、フロントエンド、バックエンドといった複数のプラットフォームにまたがる機能を、一人のエンジニアがエンドツーエンドで開発できるようになり、製品開発が加速しました。
- 再現が難しいバグのデバッグ、Kubernetesの問題調査、データ分析のトレンド特定など、複雑な技術的問題の根本原因究明にCodexが貢献しています。
- GPT-5.4および5.5のアップグレードによりCodexの性能が向上し、特にFast Modeは迅速なフィードバックループを提供し、エンジニアにとって爽快な開発体験をもたらしています。
- エンジニアリングの生産性が大幅に向上した結果、ボトルネックは技術的な実装から、次に何を構築すべきかという戦略的な意思決定へと変化しています。
