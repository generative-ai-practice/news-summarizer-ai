# Workspace agents

## Key Points
- Workspace agentsは、ChatGPT内で反復可能なワークフローを自動化し、ツールを連携させ、チームの運用を効率化するために設計されています。これらは、単発タスクではなく日常業務に深く組み込まれるAI活用を目的としています。
- エージェントは、トリガー（開始点）、プロセスとスキル（タスク実行手順）、ツールとシステム（情報収集やアクション実行のための承認済み統合）の3つの主要な構成要素で成り立っています。
- エージェントは、反復可能で構造化された出力を持つ、時間ベースまたはイベント駆動型でツールを利用する作業に最も有用であり、モデルが文脈を解釈し、意思決定を行う「確率的」な特性を持っています。
- エージェントの構築は、エージェントビルダーチャットでタスクを記述し、必要なツール、トリガー、ガードレールを設定するプロセスです。テストを通じて問題点を特定し、指示の直接更新または自然言語でのコーチングにより繰り返し改善します。
- チームでエージェントを共有する際は、その目的、必要な入力、期待される出力、使用タイミングを明確に伝えることが重要です。また、SlackやGmailなどのシステムと連携するために、適切なアクセス権限が必要となる場合があります。
