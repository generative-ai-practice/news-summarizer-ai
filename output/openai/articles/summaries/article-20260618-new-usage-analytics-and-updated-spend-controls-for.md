# New usage analytics and updated spend controls for enterprises

## Key Points
- OpenAIは2026年6月18日、ChatGPT Enterprise向けに、AI展開のコスト管理と規模拡大を支援する新しい使用状況分析と更新された利用額管理機能を導入しました。
- グローバル管理コンソールで提供される新しいクレジット使用状況分析機能により、管理者はユーザー、製品、モデルごとのクレジット消費の詳細な内訳を把握できます。
- 管理者は、使用状況とクレジットのトレンドの追跡、主要ユーザーや新たなクレジット使用パターンの特定、統一されたCost APIを通じたデータアクセスが可能です。
- 利用額管理機能が更新され、ワークスペース全体のデフォルト制限、特定のグループの制限、および個別のオーバーライドを設定できるようになりました。
- 従業員は自身のクレジット使用状況を確認し、必要に応じて追加クレジットを申請でき、管理者は情報に基づいた承認を行うことが可能です。
