# Helping developers build safer AI experiences for teens

## Key Points
- OpenAIは、gpt-oss-safeguardと連携するプロンプトベースの10代向けAI安全ポリシーをリリースしました。これは、開発者が年齢に応じた保護機能を構築するのを支援します。
- これらのポリシーは、グラフィックな暴力的・性的コンテンツ、有害な身体的理想、危険な活動、ロマンチックまたは暴力的なロールプレイ、年齢制限のある商品・サービスといった10代特有のリスクを対象としています。
- Common Sense Mediaやeveryone.aiなどの外部組織の専門家からの意見を取り入れて開発され、安全要件を実用的なシステムに一貫して適用できるようにすることを目的としています。
- 本ポリシーは、多層的な安全アプローチの出発点であり、開発者が自社の製品やAIの統合における固有のリスクに基づいて適応・拡張することが推奨されています。
- これらのポリシーはROOST Model Communityを通じてオープンソースとして公開されており、さらなる協力と反復を通じてAIシステムの安全性基盤を強化することを目指しています。
