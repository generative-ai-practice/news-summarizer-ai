# Enterprises power agentic workflows in Cloudflare Agent Cloud with OpenAI

## Key Points
- Cloudflareは、OpenAIのフロンティアモデル（GPT-5.4やCodexを含む）へのアクセスをAgent Cloud内で拡大し、何百万もの企業が利用できるようにしました。
- 企業はCloudflare Agent CloudとOpenAIを組み合わせることで、GPT-5.4などのモデルを活用したAIエージェントをデプロイし、顧客対応やシステム更新などの実務を自動化できます。
- Agent CloudはCloudflare Workers AI上で稼働し、AIアプリケーションやエージェントをグローバル規模で高速かつリアルタイムに構築・展開することを可能にします。
- OpenAIのCodexハーネスは、現在Cloudflare Sandboxesで一般提供されており、今後Workers AIでも利用可能になる予定です。
