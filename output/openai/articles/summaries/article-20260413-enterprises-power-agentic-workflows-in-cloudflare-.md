# Enterprises power agentic workflows in Cloudflare Agent Cloud with OpenAI

## Key Points
- Cloudflare Agent Cloud内で、数百万の企業がOpenAIのフロンティアモデルに直接アクセスできるようになりました。
- 企業はCloudflareのAgent Cloudを利用し、GPT-5.4などのOpenAIモデルを搭載したAIエージェントをデプロイして、顧客対応やレポート作成などの実務を自動化できます。
- Codexハーネスで構築されたエージェントはCloudflareに展開可能となり、開発ワークフローを効率化し、AIアプリケーションを大規模にデプロイできます。
- Agent CloudはCloudflare Workers AI上で動作し、企業が高速かつグローバル規模でAIアプリケーションやエージェントを構築・展開することを容易にします。
