# How to use ChatGPT Work for everyday tasks

## Key Points
- ChatGPT Workは、既存の業務データ（カレンダー、メッセージ、ドキュメント、スプレッドシートなど）を基に、レビュー可能な業務成果物（日報、週次報告、計画書など）を生成する際に最も効果的です。
- 白紙の状態から始める代わりに、チームが既に持っている資料をAIに与えることで、実用的な成果物の初版を効率的に作成できます。
- 生成された成果物は、チームが根拠を確認し、判断を洗練させ、未解決の疑問を解決し、次に何をすべきかを決定するための出発点となります。
- 本記事で紹介されているワークフローは以前のCodex体験を参照していますが、現在はChatGPT Work（chatgpt.comまたはデスクトップアプリ）で同様に実行できます。
