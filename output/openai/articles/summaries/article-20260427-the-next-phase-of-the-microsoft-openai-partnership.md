# The next phase of the Microsoft OpenAI partnership

## Key Points
- OpenAIとMicrosoftは、柔軟性、確実性、そして広範なAI提供に重点を置き、パートナーシップを簡素化し長期的な明確性を追加する修正合意を発表しました。
- Microsoftは引き続きOpenAIの主要なクラウドパートナーであり、OpenAIの製品はAzureで最初に提供されますが、OpenAIはあらゆるクラウドプロバイダーを通じて製品を顧客に提供できるようになります。
- Microsoftは2032年までOpenAIのIP（モデルおよび製品）に対する非独占的なライセンスを継続し、MicrosoftからOpenAIへの収益分配は停止されます。
- OpenAIからMicrosoftへの収益分配は、OpenAIの技術進捗とは無関係に2030年まで同じ割合で継続されますが、総額に上限が設けられます。
- Microsoftは主要な株主として、OpenAIの成長に引き続き直接参加します。
