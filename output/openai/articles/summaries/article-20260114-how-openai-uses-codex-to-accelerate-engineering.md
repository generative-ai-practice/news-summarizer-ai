# How OpenAI Uses Codex to Accelerate Engineering

## Key Points
- OpenAIのCodexは、セキュリティ、製品エンジニアリング、フロントエンド、API、インフラ、パフォーマンスエンジニアリングなど、多様な技術チームで日常的に使用され、エンジニアリングタスクを加速しています。
- コード理解を支援し、慣れないコードベースでの迅速な立ち上げ、機能のコアロジックの特定、サービス間の関係マッピングを可能にします。
- リファクタリングや移行作業に利用され、多数のファイルにわたる一貫した変更適用や、大規模モジュールの分割、古いパターンの置き換えによるコードクリーンアップに役立ちます。
- パフォーマンスボトルネックの特定と対処、非効率なコードパスの分析と最適化、テストカバレッジの改善によるテスト作成の高速化に貢献しています。
- 「Ask Mode」から計画を立て、「AGENTS.md」でコンテキストを提供し、「Best of N」を活用して複数の解決策を比較検討することが、Codexの出力を最大化するためのベストプラクティスです。
