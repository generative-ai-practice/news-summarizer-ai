# How OpenAI Uses Codex to Accelerate Engineering

## Key Points
- OpenAIのCodexは、セキュリティ、製品エンジニアリング、インフラなど、多くの技術チームで日常的に活用され、広範なエンジニアリングタスクを加速させています。
- 主な利用事例には、コードの理解、大規模なコードベースのリファクタリング、システムパフォーマンスの最適化、テストカバレッジの向上、開発速度の加速が含まれます。
- Codexは、馴染みのないコードベースの迅速な理解、複数ファイルにわたる変更の整合性維持、非効率なコードパスの特定と最適化、テストの高速作成に役立ちます。
- 新機能のボイラープレートの足場作りや、バグのトリアージ、デプロイスクリプトの生成など、開発サイクルの開始から終了までを加速させ、厳しい納期への対応を支援します。
- Codexを最大限に活用するには、質問モードで計画を立て、開発環境を反復的に改善し、GitHub Issueのようにプロンプトを構成し、AGENTS.mdで永続的なコンテキストを提供するなどのベストプラクティスがあります。
