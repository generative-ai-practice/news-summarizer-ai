# How OpenAI Uses Codex to Accelerate Engineering

## Key Points
- Codexは、OpenAIのセキュリティ、製品エンジニアリング、フロントエンド、API、インフラ、パフォーマンスエンジニアリングなど、多数の技術チームで日常的に利用されています。
- コードの理解、システムの改善（リファクタリングや移行）、パフォーマンス最適化、テストカバレッジの向上、開発速度の加速、集中力の維持、探求とアイデア出しといった幅広いエンジニアリングタスクを支援します。
- 例えば、不慣れなコードベースでの素早い立ち上げ、複雑なシステムのロジック特定、複数ファイルにわたる変更の一貫した適用、非効率なコードパスの特定などに役立っています。
- 効果的な活用のためには、まず「Askモード」で計画を立て、Codexの開発環境を継続的に改善し、GitHub Issueのようにプロンプトを構造化することが推奨されています。
- また、Codexのタスクキューを軽量バックログとして利用し、AGENTS.mdファイルで永続的なコンテキストを提供し、「Best of N」機能で出力を改善するなどのベストプラクティスがあります。
