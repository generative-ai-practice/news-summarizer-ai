# Apple is getting this wrong

## Key Points
- Appleは当初、OpenAIが連絡に応じなかったと主張したが、後に自社の弁護士が誤った相手にメールを送信したことを認め、訴訟の具体的な内容に関する事前協議もなかったと修正した。
- AppleはChang Liu氏が退職後に機密情報にアクセスしたと非難したが、実際にはApple従業員が彼に情報探索を依頼しており、OpenAIはApple側のシステムアクセス管理の不備が原因だと主張している。
- AppleはTang Tan氏が企業秘密を利用しようとしたと主張しているが、Tang氏はOpenAIチームに対し、他社の機密情報を一切使用しないよう明確に指示していた。
- OpenAIは、訴訟が提起される前にAppleが問題を提起していれば、喜んで明確化し、解決に向けて協力する用意があったと述べている。
- Appleの暫定的差し止め請求は誤った情報に基づき、OpenAIがAppleの企業秘密を所有せず、また欲していないため、全く不必要であるとOpenAIは反論している。
