# How GPT-5.6 Sol helps run quantum computing experiments

## Key Points
- 2026年9月8日、MITの研究者Beatriz Yankelevich氏は、GPT-5.6 SolとCodexを利用して量子コンピューティング実験のワークフローを効率化しました。AIはラボソフトウェアに接続され、測定の実行、結果の分析、次のステップの決定を自律的に行います。
- このシステムにより、ルーチン的な測定作業が自動化され、Yankelevich氏は実験結果の分析、実験設計、およびより高レベルの研究計画に集中できるようになりました。
- GPT-5.6 Solは明確に定義された実験ワークフローにおいて標準的な測定シーケンスを自律的に完了できますが、信号が弱い、またはノイズが多い状況では、測定パラメータの特定に時間がかかり、人間の介入が必要となる場合があります。
- このAIエージェントの活用により、研究者は継続的な監視なしに夜間や他の作業時間中も測定を実行させることが可能になり、研究時間の節約に貢献しています。
