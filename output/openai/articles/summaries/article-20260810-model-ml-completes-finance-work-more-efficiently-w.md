# Model ML completes finance work more efficiently with GPT-5.6 Sol

## Key Points
- Model MLはGPT-5.6 Solを活用し、調査・分析から編集可能なPowerPointデッキやExcelワークブック作成までの金融業務ワークフローを効率化しています。
- GPT-5.6 Solは、PowerPointデッキあたりのトークン数をFable 5と比較して21%削減し、Excelワークブックあたりのトークン数をOpus 5と比較して36%削減しました。
- PowerPointワークフローにおいて、GPT-5.6 Solはテストケースの100%で完了し、専門的なレビュー準備完了率でOpus 5を16.6パーセントポイント上回りました。
- カスタムのティアーシート作成にかかる時間を、以前の約1時間から約5分へと大幅に短縮しました。
- Model MLのプラットフォームは、AIの進化により金融業務における知識作業の作成方法が変化しているという考えに基づき、モデルとソース資料に接続されたブラウザベースのインタラクティブな出力を生成できます。
