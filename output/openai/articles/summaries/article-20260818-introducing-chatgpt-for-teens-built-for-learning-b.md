# Introducing ChatGPT for Teens: Built for learning, backed by protections

## Key Points
- 2026年8月18日、13歳から17歳のティーン向けに、学習、批判的思考、AI活用を支援するChatGPTが導入されました。
- 本サービスは、有害または発達上不適切なコンテンツへの露出を軽減するための、年齢に応じた強力な安全保護機能をデフォルトで提供します。
- 学習を支援するため、「Study Mode」、責任ある宿題リマインダー、クイズ、学習の可視化、保護者が設定できる「Study Hours」などの機能が搭載されています。
- 保護者は、連携されたティーンアカウントの「Quiet Hours」の設定、特定の設定管理、および摂食障害に関連する追加の通知を含む高リスク状況での安全通知を受け取ることができます。
- OpenAIはCodeAIとの提携を通じて、学生や教育者がAIの仕組みを理解し、質問し、活用し、創造性を育むためのツールとリソースを提供します。
