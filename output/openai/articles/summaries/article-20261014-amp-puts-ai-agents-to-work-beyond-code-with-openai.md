# Amp puts AI agents to work beyond code with OpenAI models

## Key Points
- Ampは、開発者がアイデアをソフトウェアに変換するのを助けるフロンティアAIエージェントを開発しており、OpenAIモデルはその中核を成しています。
- 「Sign in with ChatGPT」との連携により、ユーザーはトークンコストを気にすることなく、より大規模なタスクをAIエージェントに任せられるようになりました。
- GPT-6 Astraは、マーケティング資料の作成、ページデザイン、さらには個人の3Dモデリングといった創造的な作業において、Ampの高い基準を満たす品質を提供しています。
- GPT-Live-1を搭載した会話型AIアシスタント「Puck」により、ユーザーはリアルタイムでエージェントと対話し、バグ調査や複数のエージェントの調整などのタスクを管理できます。
- UltrafastモードでのGPT-6 Astraのテストは、エージェントの応答速度を飛躍的に向上させ、ユーザーがより少ないエージェントで効率的に作業を進める可能性を示しています。
