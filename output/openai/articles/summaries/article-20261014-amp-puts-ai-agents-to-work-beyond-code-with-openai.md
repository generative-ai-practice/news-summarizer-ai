# Amp puts AI agents to work beyond code with OpenAI models

## Key Points
- Ampは、OpenAIのGPT-6 Astra、Ultrafast、GPT-Live-1、およびSign in with ChatGPTモデルを活用し、開発者がアイデアをソフトウェアに変換するのを支援するフロンティアAIエージェントを構築しています。
- 「Sign in with ChatGPT」の統合により、ユーザーはトークンコストを気にせずにGPT-6 Astraを含むOpenAIモデルへアクセスでき、エージェントに計画立案や開発後の作業など、より大きなタスクを委任できるようになりました。
- GPT-6 Astraは、高品質な文書作成やページの設計に貢献しており、Ampのマーケティング活動や個人の創造的なプロジェクトにも活用されています。
- 会話型AIアシスタント「Puck」はGPT-Live-1によって強化され、ユーザーはリアルタイムの音声対話を通じて、コンピューターから離れていてもエージェントにバグ調査や複数のエージェント調整などの指示を出せます。
- GPT-6 AstraのUltrafastモードはエージェントの応答速度を大幅に向上させ、ユーザーは同時に扱うエージェントの数を減らしたり、エージェントが自身の作業を確認する時間を増やしたりできるようになります。
