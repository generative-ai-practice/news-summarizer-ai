# Amp puts AI agents to work beyond code with OpenAI models

## Key Points
- Ampは、開発者がアイデアをソフトウェアに変えるのを助けるフロンティアAIエージェントを構築しており、コードを超えた広範なタスクにAIを活用することを目指しています。
- Ampは、OpenAIのGPT-6 Astra、Ultrafast、GPT-Live-1、および「Sign in with ChatGPT」などのモデルを主要なトークン消費源として利用し、開発のコストと制約を軽減しています。
- 「Sign in with ChatGPT」の統合により、ユーザーはトークンを気にせずエージェントに大きなタスクを任せられるようになり、計画や設計、出荷後の作業にも利用されています。
- GPT-6 Astraは、高品質なドキュメント作成やページデザインに貢献し、3Dモデル作成といった個人的な用途にも応用され、その多様な能力を示しています。
- GPT-Live-1を搭載した会話型AIアシスタント「Puck」は、リアルタイムでエージェントを起動・管理できる機能を持ち、Ultrafastモードはエージェントのワークフローを加速させ、効率的な利用を可能にします。
