# Amp puts AI agents to work beyond code with OpenAI models

## Key Points
- AmpはOpenAIモデルを活用し、AIエージェントをコード作成だけでなく、より広範な業務に展開しています。
- 「Sign in with ChatGPT」の統合により、ユーザーはトークンコストを気にせずGPT-6 Astraを含むOpenAIモデルを大規模に利用し、エージェントによる計画立案や製品開発、出荷後作業を行えます。
- GPT-6 Astraは、Ampチームがマーケティング活動を含む製品開発において、独自の基準を満たす高品質な文章作成やデザインページの生成を可能にしています。
- GPT-Live-1を搭載した会話型AIアシスタント「Puck」により、ユーザーはリアルタイムでエージェントと対話し、PCから離れた場所でも作業指示や管理が可能です。
- GPT-6 AstraのUltrafastモードは、エージェントの応答速度を劇的に向上させ、ユーザーが複数のエージェントタスクをより効率的に管理したり、エージェントが自己チェックする時間を増やしたりする可能性を秘めています。
