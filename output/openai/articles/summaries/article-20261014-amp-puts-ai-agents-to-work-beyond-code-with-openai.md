# Amp puts AI agents to work beyond code with OpenAI models

## Key Points
- AmpはOpenAIモデル（GPT-6 Astra、Ultrafast、GPT-Live-1など）を活用し、開発者がアイデアをソフトウェアに変えるのを支援する最先端のAIエージェントを構築しています。
- 「Sign in with ChatGPT」との統合により、ユーザーはより多くのトークンとOpenAIモデルにアクセスできるようになり、エージェントに大きなタスクを任せる意欲が高まります。
- GPT-6 Astraは、Ampチームがマーケティングを含む製品開発において、高い品質のライティングとデザイン（ドキュメント作成やページデザイン）を実現するのに役立っています。
- GPT-Live-1を搭載した会話型AIアシスタント「Puck」により、ユーザーはリアルタイムでエージェントと対話し、コンピュータから離れている間も作業を継続させることが可能になります。
- UltrafastモードでのGPT-6 Astraのテストでは、応答速度の向上がエージェントの使用方法を変え、ユーザーが同時に扱うエージェントの数を減らしたり、エージェントが自己検証する時間を増やしたりする可能性が示されています。
