# OpenAI Codex and Figma launch seamless code-to-design experience

## Key Points
- 新しいCodexとFigmaの統合により、ユーザーはコードとデザインキャンバス間をシームレスに移動し、製品の迅速な反復と出荷を支援します。
- Figma MCPサーバーは、CodexをFigmaのデザインプラットフォームやFigma Make、FigJamなどのツールに直接接続します。
- この新しい統合は、ChatGPT内のFigmaアプリや最新のOpenAIモデルをFigmaプラットフォームにもたらすなど、両社のパートナーシップを拡大するものです。
