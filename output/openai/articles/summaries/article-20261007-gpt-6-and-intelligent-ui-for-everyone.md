# GPT-6 and Intelligent UI for everyone

## Key Points
- GPT-6と「Intelligent UI」がChatGPTに導入され、テキスト、ビジュアル、インタラクティブ要素を組み合わせて、より高速で視覚的に豊かな応答を提供します。
- Intelligent UIは、日常の質問に対する視覚的な回答、複雑なトピックの簡単な学習、および要求に応じて計算機やゲームなどのインタラクティブなツールをその場で作成する能力を提供します。
- GPT-6は、思考と回答を並行して行うことで応答速度が大幅に向上し、特にウェブ検索が必要な質問ではGPT-5.6と比較して回答開始が平均44%早くなりました。
- 安全性が強化されており、Astraの安全技術に基づいてモデルの誤用耐性、安全対策の遵守、および自身の能力の限界を認識する能力が向上しています。
- GPT-6 Intelligent UIは2026年10月7日よりChatGPTの有料プランで提供が開始され、翌日には無料プランにも拡大されます。
