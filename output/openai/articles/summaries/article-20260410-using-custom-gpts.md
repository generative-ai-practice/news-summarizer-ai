# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローのために設計されたChatGPTの特注バージョンであり、一貫した出力を自動化・生成できるAIアシスタントです。好みの形式やチームのコンテキストを活用し、説明の繰り返しやコピー＆ペーストの手間を削減します。
- 通常のチャットが単発の迅速なタスクに適しているのに対し、カスタムGPTは、定期的に繰り返すタスクの自動化、ツールや外部連携の追加、一貫したコンテキストの維持が必要な場合に特に有用です。
- カスタムGPTの構築には、まず具体的なユースケースを特定し、次にGPTビルダーで名前、説明、指示、知識、機能、カスタムアクションなどの詳細を設定します。指示の作成が最も重要で、ChatGPTにドラフトを依頼し、実例に基づいて改善することが推奨されます。
- 完成したGPTは、10〜15の質問と正解を用いた評価（evals）でパフォーマンスをテストし、必要に応じて指示や知識を調整します。変更を保存するために「Update」をクリックすることを忘れないでください。
- OpenAIチームが構築したカスタムGPTには、「ChatGPT Use Cases for Work」「Professional Writing Coach」「Data Analyst」「Coding Assistant」「Visual Designer」など、多様な目的に特化したアシスタントがあります。
