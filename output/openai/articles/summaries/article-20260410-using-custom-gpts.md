# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローのためにChatGPTをカスタマイズしたものであり、独自の指示、コンテキスト、一貫した出力を維持して繰り返し作業を効率化します。
- 通常のチャットは一時的なタスクに適していますが、カスタムGPTは繰り返される作業や一貫した結果が必要な場合に特に有用です。
- カスタムGPTの作成は、GPTビルダーで名前、説明、行動指示、知識（アップロードファイル）、機能（Web検索、データ分析、画像生成など）、および外部API連携のためのカスタムアクションを設定することで行われます。
- 構築後は、10〜15の質問とそれに対する正しい回答を使用して性能を評価し、期待通りの応答を生成するかを確認し、必要に応じて調整します。
- カスタムGPTを活用することで、同じプロンプトの再利用、ファイルの再アップロード、指示の再記述といった手間を削減し、より少ない労力で高品質な成果をチーム全体で迅速に得ることが可能になります。
