# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローに特化したChatGPTのカスタムバージョンで、一貫した出力を生成し、繰り返しの作業を効率化します。
- 通常のチャットが一時的なタスクに適しているのに対し、カスタムGPTは反復的で一貫性のある作業（例：定型メッセージ作成、会議要約、データ分析）に最適です。
- 同じプロンプトの繰り返し使用、ファイルの再アップロード、またはチームへの同じ指示の繰り返しが必要な場合は、カスタムGPTの構築を検討すべきです。
- カスタムGPTの構築には、反復的なニーズを持つユースケースの特定、GPTビルダーでの名前、説明、指示、知識、機能、カスタムアクションの設定が含まれます。
- 指示の記述は最も難しいステップですが、ChatGPTに最初のドラフトを作成させ、実際の例に基づいて調整することで効率的に進められます。
