# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローのために設計されたChatGPTの特注版であり、独自の指示、知識、ツールを活用して、一貫した出力を提供し、繰り返し作業を効率化します。
- 一度限りのタスクには通常のChatGPTが適していますが、繰り返しのタスクの自動化、ツールや統合の追加、一貫したコンテキストの維持が必要な場合はカスタムGPTがより適しています。
- カスタムGPTの構築は、まずシンプルで繰り返し可能なニーズに合った強力なユースケースを特定することから始まります。
- GPTビルダーの「Configure」タブで名前、説明、指示、会話スターター（任意）、知識（ファイルアップロード）、機能、カスタムアクションを定義します。
- GPTを共有する前に、10〜15の質問と正しい回答を含む評価（evals）を使ってパフォーマンスをテストし、必要に応じて指示や知識を調整することが推奨されます。
