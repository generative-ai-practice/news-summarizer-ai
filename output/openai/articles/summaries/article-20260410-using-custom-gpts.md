# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローに合わせて設計された目的別バージョンのChatGPTであり、繰り返しの作業を自動化し、一貫した出力を維持し、特定のコンテキストを利用するのに役立ちます。
- 通常のチャットが一時的なタスクに適しているのに対し、カスタムGPTは、頻繁に繰り返されるプロンプトの自動化、外部ツールや統合の追加、一貫したコンテキストの維持が必要な場合に適しています。
- カスタムGPTを構築するには、まず繰り返し発生するニーズを特定し、GPTビルダーの「Create」または「Configure」タブで、名前、説明、指示、知識、機能、カスタムアクションなどを設定します。
- 構築後、10〜15の質問と正しい回答を含む評価セットを使用してGPTのパフォーマンスをテストし、結果に基づいて指示や知識を調整することで、期待される出力を確保します。
- OpenAIチームは、ChatGPT Use Cases for Work、Professional Writing Coach、Data Analyst、Coding Assistant、Visual Designerなど、様々な目的を持つカスタムGPTを提供しています。
