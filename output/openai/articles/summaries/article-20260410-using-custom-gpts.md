# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローのために設計された、目的に特化したChatGPTのバージョンです。毎回白紙の状態から始めることなく、好みの形式に従い、チームのコンテキストを活用し、より一貫した出力を生成できます。
- 通常のChatGPTが一度限りの素早いタスクに適しているのに対し、カスタムGPTは、反復作業の自動化、ツールの統合、一貫したコンテキストの維持といった、繰り返し利用する場面でより適しています。
- カスタムGPTはGPTビルダーの「Create」または「Configure」タブから作成可能で、「Configure」タブでは名前、説明、指示、知識（アップロードファイル）、機能（画像生成、データ分析など）、およびカスタムアクションを設定できます。
- 効果的な指示を作成するには、目標を明確で実行可能なガイダンスに変換することが重要であり、ChatGPTに最初のドラフトを作成させ、実際の例に基づいて調整することが推奨されます。
- GPTを共有する前に、評価（evals）を使用してパフォーマンスをテストし、10〜15の質問と正解で応答の正確性と信頼性を確認し、必要に応じて指示や知識を調整する必要があります。
