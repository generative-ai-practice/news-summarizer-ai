# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローのためにカスタマイズされたChatGPTであり、指示に従い、コンテキストを利用し、反復作業を効率化する目的で構築されます。
- 通常のチャットが一時的なタスクに適しているのに対し、カスタムGPTは、同じプロンプトやファイルを繰り返し使用する、定型的かつ一貫した出力が必要な場合に特に有効です。
- 構築プロセスは、「強力なユースケースの特定」「GPTの作成（GPT Builderで名前、説明、指示、知識、機能、カスタムアクションを設定）」「GPTのパフォーマンスのテスト」の3つの主要なステップから構成されます。
- GPTの指示を記述することは最も難しいステップの一つですが、ChatGPTに下書きを依頼し、実際の例に基づいて調整することで効率的に進められます。
- 共有する前に、10～15個の質問と正確な回答を用いてパフォーマンスを評価し、必要に応じて指示や知識を調整し、必ず「Update」をクリックして変更を保存することが推奨されます。
