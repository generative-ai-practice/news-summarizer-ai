# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローのために設計された特化型ChatGPTアシスタントであり、指示、コンテキスト、一貫した出力により繰り返しの作業を効率化します。
- 一般的なチャットが一時的なタスクに適しているのに対し、カスタムGPTは繰り返しのタスクの自動化、ツールや統合の追加、一貫したコンテキストの維持に優れています。
- OpenAIチームは、仕事でのChatGPTのユースケース、プロのライティングコーチ、データアナリスト、コーディングアシスタント、ビジュアルデザイナーなどのカスタムGPTを提供しています。
- カスタムGPTの構築は、繰り返しのニーズを持つユースケースの特定から始まり、GPTビルダーで名前、説明、指示、知識、機能、カスタムアクションを設定します。
- 作成後は、10〜15の質問を含む評価でパフォーマンスをテストし、必要に応じて指示や知識を調整し、「Update」で変更を保存することが推奨されます。
