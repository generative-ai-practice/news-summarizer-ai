# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローのために設計されたChatGPTのバージョンであり、一貫した出力を生成し、反復作業を効率化します。
- 通常のチャットが一時的なタスクに適するのに対し、カスタムGPTは、頻繁に再利用されるプロンプト、ファイル、または指示がある場合に、再現性と一貫性を保つために適しています。
- カスタムGPTを構築するには、GPTビルダーの「Create」または「Configure」タブで、名前、説明、指示、会話スターター、知識、機能、カスタムアクションなどを定義します。
- 指示の作成は最も難しいステップであり、ChatGPTに最初のバージョンをドラフトさせ、実際の例に基づいて調整することで効率的に進められます。
- GPTの共有前には、10～15個の質問と正解を含む評価を実施し、そのパフォーマンスを確認し、必要に応じて指示や知識を修正することが重要です。
