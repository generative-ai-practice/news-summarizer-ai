# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローに特化したChatGPTのバージョンであり、一貫した出力、チームのコンテキスト活用、反復可能な作業の効率化を実現します。
- 一般的なチャットが一時的なタスクに適しているのに対し、カスタムGPTは反復的なタスクの自動化、ツールや連携機能の追加、一貫したコンテキストの維持に適しています。
- カスタムGPTの構築は、定期的でシンプルなニーズを持つユースケースを特定することから始まり、GPT Builderで詳細な指示、知識、機能、カスタムアクションなどを設定します。
- 構築後は、10〜15の質問でパフォーマンスを評価し、正確で信頼性の高い応答が得られるかを確認し、必要に応じて指示や知識を調整することが重要です。
- OpenAIチームが構築したカスタムGPTの例には、「ChatGPT Use Cases for Work」「Professional Writing Coach」「Data Analyst」「Coding Assistant」「Visual Designer」などがあります。
