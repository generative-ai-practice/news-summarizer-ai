# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローに特化したChatGPTのバージョンであり、繰り返し発生する作業の自動化、一貫した出力の維持、チームのコンテキストを活用したAIアシスタントの作成を可能にします。
- 通常のチャットが迅速な単発タスクに適しているのに対し、カスタムGPTは、頻繁に再利用するプロンプト、特定のツールや連携、一貫したコンテキストが必要な反復可能で一貫性のある作業に最適です。
- カスタムGPTの構築は、まず反復可能なニーズに基づく強力なユースケースを特定することから始まり、次にGPTビルダーで名前、説明、詳細な指示、知識ファイル、機能、およびカスタムアクションを設定します。
- 指示の作成は最も挑戦的なステップであり、ChatGPTに初稿を作成させて調整することが推奨されます。構築後は、10〜15の質問と正解を用いた評価でパフォーマンスをテストし、必要に応じて指示や知識を調整します。
- カスタムGPTは、カスタマイズされた指示、アップロードされた知識（ファイル）、およびウェブ検索、データ分析、画像生成、サードパーティAPIとの連携といったツールを活用して、その動作と出力を細かく調整できます。
