# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローに合わせてChatGPTをカスタマイズしたもので、指示に従い、特定のコンテキストを使用し、繰り返し可能な作業を効率化するように設計されています。
- 通常のチャットが一時的なタスクに適しているのに対し、カスタムGPTは繰り返しの作業や一貫した出力が求められる場合に適しており、プロンプトの保存、ツールや統合の追加、一貫したコンテキストの維持に役立ちます。
- カスタムGPTを構築するには、まず繰り返しのニーズがある明確なユースケースを特定し、次にGPTビルダーで名前、説明、指示、会話の開始、ナレッジ、機能、カスタムアクションを設定します。
- 指示の作成は、目標を明確で実行可能なガイドラインに変換する重要なステップであり、ChatGPTに下書きを作成させ、具体的な例に基づいて調整することが効果的です。
- 構築後には、10〜15の質問と正しい回答を含む評価セットを用いてGPTのパフォーマンスをテストし、必要に応じて指示やナレッジを調整することで、期待通りの応答が得られるように改善します。
