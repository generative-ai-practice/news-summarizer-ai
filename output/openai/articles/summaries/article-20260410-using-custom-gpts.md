# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローに特化したChatGPTのバージョンで、設定された指示やコンテキストに基づき一貫した出力を生成し、繰り返しの作業を効率化します。
- 通常のチャットが一時的なタスクに適しているのに対し、カスタムGPTは、頻繁なプロンプトの再利用、ツールや統合の追加、または一貫したコンテキストの維持が必要な反復作業に最適です。
- OpenAIチームによって作成されたカスタムGPTには、「ChatGPT Use Cases for Work」や「Data Analyst」などがあり、仕事のブレインストーミングやデータ分析などの目的で利用できます。
- カスタムGPTを構築するには、まず強力なユースケースを特定し、ChatGPTのGPTビルダーで名前、説明、詳細な指示、知識ファイル、および利用する機能（Web検索、データ分析、カスタムアクションなど）を設定します。
- 構築後は、10〜15の質問と正しい回答を含む評価セットを使用してGPTのパフォーマンスをテストし、必要に応じて指示や知識を調整して信頼性を確保することが重要です。
