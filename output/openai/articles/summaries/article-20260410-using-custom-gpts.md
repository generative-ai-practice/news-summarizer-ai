# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローのために設計されたChatGPTのカスタムバージョンであり、指定された指示、コンテキスト、ツールを使用して一貫した出力を生成し、反復作業を効率化します。
- 通常のチャットが一時的なタスクに適しているのに対し、カスタムGPTは、同じプロンプトの再利用、ファイルの再アップロード、またはチームへの指示の再伝達が必要な、反復可能で一貫性のある作業に適しています。
- カスタムGPTを構築するには、まず知識アシスタントやライティングアシスタントなどの明確なユースケースを特定し、次にGPTビルダーで名前、説明、指示、知識、機能、カスタムアクションを設定します。
- 構築後は、10〜15問の質問と正解でパフォーマンスを評価し、必要に応じて指示や知識を調整することで、期待通りの動作を確認することが重要です。
- OpenAIチームからは、仕事のユースケースのブレインストーミング、プロの文章作成、データ分析、コーディング支援、視覚デザインなど、様々な目的のカスタムGPTが提供されています。
