# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローに特化したChatGPTアシスタントであり、指示に従い、コンテキストを利用して一貫した出力を生成し、繰り返しの作業を効率化します。
- 汎用チャットが一度きりのタスクに適しているのに対し、カスタムGPTは繰り返しのタスク自動化、追加ツールやAPI連携、一貫したコンテキスト維持が必要な場合に特に有効です。
- 構築プロセスは、強力なユースケースの特定、GPTビルダーでの詳細設定（指示、知識、機能、カスタムアクションなど）、およびテストによるパフォーマンス検証の3つの主要ステップで構成されます。
- OpenAIチームは、ロール固有のChatGPT活用法、プロフェッショナルな文章校正、データ分析、コード生成・デバッグ、ビジュアルデザインなど、様々な目的のカスタムGPTを提供しています。
- 効果的なカスタムGPTを構築するには、まず繰り返しのニーズから始め、指示の明確化、テスト用質問によるパフォーマンス評価、そして必要に応じた調整を通じて精度を高めることが重要です。
