# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローに特化したChatGPTのバージョンで、設定された指示、コンテキスト、ツールを活用して、一貫した出力を生成し、繰り返しの作業を効率化します。
- 通常のチャットが一時的なタスク向けであるのに対し、カスタムGPTは、反復的なタスクの自動化、より深い回答のためのツール統合、および一貫したコンテキスト維持が必要な場合に適しています。
- カスタムGPTの構築は、「強力なユースケースの特定」、「GPTの作成」、そして「パフォーマンスのテスト」の3つの主要ステップで構成されます。
- GPT作成時には、名前、説明、指示、会話開始プロンプト、知識ファイル（アップロード）、機能（画像生成、データ分析など）、およびサードパーティAPIを呼び出すカスタムアクションを定義できます。
- 最後に、GPTが期待通りに機能するかを評価するために10〜15のテスト質問と正答を用いて検証し、必要に応じて指示や知識を調整・更新することが重要です。
