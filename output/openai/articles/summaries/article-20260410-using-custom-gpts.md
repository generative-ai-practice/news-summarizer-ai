# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフローのために設計された、ChatGPTの目的特化型バージョンで、ユーザーの指示、コンテキストに従い、一貫した出力を提供し、繰り返し作業を効率化します。
- 通常のチャットは一時的なタスクに適していますが、カスタムGPTは反復可能で一貫性のある作業（ワークフローの自動化、追加ツールや連携、一貫したコンテキスト維持など）に最適です。
- カスタムGPTの構築は、ChatGPTのサイドバーから「GPTs」を開き「Create」を選択して行います。GPT Builderとの対話を通じて、または「Configure」タブで名前、説明、指示、ナレッジ、機能、カスタムアクションなどを詳細に設定できます。
- 共有する前に、10〜15の質問と正しい回答を用いてGPTのパフォーマンスを評価し、必要に応じて指示やナレッジを調整することが重要です。変更を保存するには必ず「Update」をクリックする必要があります。
