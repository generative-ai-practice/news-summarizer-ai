# Using custom GPTs

## Key Points
- カスタムGPTsは、特定のタスクやワークフローのために設計されたChatGPTの目的別バージョンです。毎回ゼロから開始することなく、一貫した出力生成を可能にします。
- 通常のチャットが一度きりのタスクに適しているのに対し、カスタムGPTは繰り返しの作業の自動化、追加ツールや連携機能の活用、一貫したコンテキストの維持に優れています。
- カスタムGPTの構築は、繰り返されるニーズに基づいたユースケースの特定から始まります。次に、GPTビルダーで指示を詳細に設定し、知識ファイルや外部ツールとの連携を設定します。
- 構築後は、10〜15の質問と正しい回答を用いてパフォーマンスを評価し、必要に応じて指示や知識を調整することが重要です。変更は「Update」をクリックして保存します。
