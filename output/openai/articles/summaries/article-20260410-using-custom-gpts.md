# Using custom GPTs

## Key Points
- カスタムGPTは、特定のタスクやワークフロー向けにChatGPTをカスタマイズしたもので、指示、コンテキスト、および反復可能な作業の効率化に役立つ。
- 通常のチャットが単発タスクに適しているのに対し、カスタムGPTは反復的な作業や一貫した出力が求められる場合に特に有効である。
- OpenAIチーム製のカスタムGPTには、仕事のユースケース、プロのライティング、データ分析、コーディング、ビジュアルデザインなどのアシスタントが含まれる。
- カスタムGPTの構築は、適切なユースケースの特定から始まり、GPTビルダーで名前、説明、指示、知識、機能、カスタムアクションを設定するプロセスを伴う。
- GPTのパフォーマンスは、10～15問の質問と正解を用いた評価によってテストし、必要に応じて指示や知識を調整することで、その精度と信頼性を確保できる。
