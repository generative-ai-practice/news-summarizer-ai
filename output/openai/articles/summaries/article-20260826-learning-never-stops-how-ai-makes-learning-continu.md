# Learning never stops: How AI makes learning continuous

## Key Points
- OpenAIの新しいレポートは、学生と教育者がChatGPTを教室を超えた継続的な学習にどのように活用しているかを探る。
- AIは、いつでも利用可能な指導、フィードバック、練習を提供することで、学生が質問やサポートを待つ必要をなくし、学習方法を変革している。
- 毎週7000万件以上の学習関連のChatGPT会話が記録されており、学年期間中には週4億6000万件以上の課題関連メッセージが送信されるなど、AIの学習支援が広く活用されている。
- 継続的なAI学習は、学生への個別支援、教師の管理業務軽減、異言語家庭への学校連絡の理解向上など、多様な学習者と教育者をサポートする。
- AIは教師や保護者の役割を代替するものではないが、適切な指導の下で教育者が指導に専念し、個別サポートを広げる可能性を秘めている。
