# Asana cuts model costs 76x in browser tests with GPT-6.1 Sol

## Key Points
- AsanaはCodex内のGPT-6 Astraを活用し、ブラウザエージェントのワークフローをGPT-6.1 Sol向けに最適化しました。
- この最適化により、ブラウザエージェントのモデルコストは76倍削減され、実行速度は5倍向上しました。
- StackAIのCTOであるFrank Hidalgo氏によると、GPT-6 Astraによる作業は、手作業で1〜2ヶ月かかると推定される研究を約1週間で完了させました。
- 最適化されたGPT-6.1 Solワークフローは、モデルの推定コストを平均$0.47、実行時間を約4分に抑え、元のプロダクション設定より2.6倍安価になりました。
- 履歴キャッシングの拡張、テキスト保持量の増加、スクリーンショット削除ポリシーの改善が、コスト削減と速度向上に大きく貢献しました。
