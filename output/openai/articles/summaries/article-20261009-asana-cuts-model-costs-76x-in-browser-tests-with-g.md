# Asana cuts model costs 76x in browser tests with GPT-6.1 Sol

## Key Points
- AsanaはCodexのGPT-6 Astraを利用し、ブラウザエージェントのワークフローを最適化しました。これにより、GPT-6.1 Solでのテストでコストを76倍削減し、速度を5倍高速化することに成功しました。
- StackAIのCTOであるFrank Hidalgo氏によると、手作業で1〜2ヶ月かかると見積もられていた調査と改善作業が、GPT-6 Astraを活用することで約1週間で完了しました。
- 最適化されたGPT-6.1 Solワークフローの平均モデルコストは1実行あたり$0.47で、元のModel Bでの設定と比較して2.6倍安価になりました。
- 新しいキャッシュとスクリーンショットポリシーをより大きな履歴バジェットと組み合わせることで、GPT-6.1 Sol単体での実行コストを4倍削減し、実行時間も約4分に短縮されました。
- この最適化により、エージェントが正確な回答を生成できる実行数が向上し、顧客により高性能で高速なモデルを提供しながら運用コストを削減できるビジネス価値がもたらされます。
