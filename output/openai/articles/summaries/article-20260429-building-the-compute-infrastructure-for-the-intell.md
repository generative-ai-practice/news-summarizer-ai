# Building the compute infrastructure for the Intelligence Age

## Key Points
- OpenAIのStargateプロジェクトは、AGIの利点を世界に提供するための計算基盤を構築しており、増大するAI需要に対応するため、計算能力の拡張を加速しています。
- 2025年1月に設定した2029年までの米国での10GWのAIインフラ確保目標を1年強で達成し、直近90日間で3GW以上を追加するなど、計画を前倒しで進めています。
- 知能時代のインフラ構築には、地方コミュニティ、エネルギープロバイダー、チップメーカー、クラウドプロバイダーなど、エコシステム全体との連携を重視しています。
- AIインフラの構築は、地域社会に雇用、教育支援、新たな歳入、責任あるエネルギー・水管理など、明確な利益をもたらすことを目指しており、コミュニティエンゲージメントプログラムを通じて地域投資を行っています。
- テキサス州アビリーンにあるStargateサイトでは、Oracle Cloud InfrastructureとNVIDIA GB200システム上で最新のGPT-5.5モデルがトレーニングされ、より強力なAIシステムを実現し、AIの恩恵を広範に提供することを目指しています。
