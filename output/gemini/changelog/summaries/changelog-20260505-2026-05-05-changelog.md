# 2026年5月5日 変更履歴

- **ファイル検索**をマルチモーダル検索に対応するよう更新しました。現在、`gemini-embedding-2`モデルを使用して画像をネイティブに埋め込み、検索できるようになりました。グラウンディングメタデータには、視覚的な引用のための`media_id`と、情報が見つかる場所を示す`page_numbers`が含まれるようになりました。詳細については、[ファイル検索](https://ai.google.dev/gemini-api/docs/file-search)ガイドを参照してください。
