## Updates (translated)
# 2026-05-19 changelog

- `gemini-3.5-flash` をリリースしました。これは、一般提供 (GA) 版の
- [Gemini 3.5 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash) で、
- エージェントタスクやコーディングタスクにおいて、最先端のパフォーマンスを持続的に発揮する、当社の最もインテリジェントなモデルです。このモデルは現在、`gemini-flash-latest` の基盤となっています。
- **Gemini API のマネージドエージェント**を公開プレビューで提供開始しました。これにより、
- 開発者は、セキュアで隔離された Google ホストの Linux サンドボックス環境で実行される、
- 自律的なステートフルエージェントを構築・デプロイできます。詳細については、
- [エージェントの概要](https://ai.google.dev/gemini-api/docs/agents)ページと
- [クイックスタート](https://ai.google.dev/gemini-api/docs/managed-agents-quickstart)をご覧ください。
- 汎用的な**Antigravity Agent**マネージドエージェント、
- [`antigravity-preview-05-2026`](https://ai.google.dev/gemini-api/docs/models/antigravity-preview-05-2026) を公開プレビューでリリースしました。
- Antigravity エージェントは、サンドボックスコンテナ内で、自律的に計画、推論、コードの記述と実行、
- ファイルの管理、およびウェブの閲覧を行うことができます。コードサンプルと仕様については、
- [Antigravity Agent](https://ai.google.dev/gemini-api/docs/antigravity-agent) ガイドをご覧ください。
