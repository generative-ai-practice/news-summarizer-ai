# 2026-05-19 changelog

- `gemini-3.5-flash` をリリースしました。これは、[Gemini 3.5 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash) の一般提供 (GA) 版であり、エージェントタスクおよびコーディングタスクにおいて、持続的な最先端のパフォーマンスを発揮する、当社の最もインテリジェントなモデルです。
- **Gemini API のマネージド エージェント**をパブリックプレビューで開始しました。これにより、開発者は、Google がホストする安全で隔離された Linux サンドボックス環境で実行される、自律的でステートフルなエージェントを構築・デプロイできます。詳細については、[エージェントの概要](https://ai.google.dev/gemini-api/docs/agents) ページと[クイックスタート](https://ai.google.dev/gemini-api/docs/managed-agents-quickstart) を参照してください。
- 汎用 **Antigravity Agent** マネージドエージェント [`antigravity-preview-05-2026`](https://ai.google.dev/gemini-api/docs/models/antigravity-preview-05-2026) をパブリックプレビューでリリースしました。Antigravity エージェントは、サンドボックスコンテナ内で自律的に計画、推論、コードの記述と実行、ファイルの管理、ウェブの閲覧が可能です。[Antigravity Agent](https://ai.google.dev/gemini-api/docs/antigravity-agent) ガイドでコードサンプルと仕様を参照してください。
