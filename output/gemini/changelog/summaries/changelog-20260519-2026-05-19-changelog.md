# 2026-05-19 changelog

- `gemini-3.5-flash` をリリースしました。これは、エージェントタスクやコーディングタスクにおいて持続的な最先端パフォーマンスを発揮する、当社で最もインテリジェントなモデルである [Gemini 3.5 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash) の一般提供（GA）バージョンです。これは現在、`gemini-flash-latest` の背後にあるモデルです。
- Gemini API の **Managed Agents** をパブリックプレビューで開始しました。これにより、開発者はセキュアで隔離された Google ホストの Linux サンドボックス環境で実行される、自律的なステートフルエージェントを構築・デプロイできます。詳細については、[エージェントの概要](https://ai.google.dev/gemini-api/docs/agents)ページと[クイックスタート](https://ai.google.dev/gemini-api/docs/managed-agents-quickstart)をご覧ください。
- 汎用的な **Antigravity Agent** マネージドエージェントである [`antigravity-preview-05-2026`](https://ai.google.dev/gemini-api/docs/models/antigravity-preview-05-2026) をパブリックプレビューでリリースしました。Antigravity エージェントは、サンドボックスコンテナ内で自律的に計画、推論、コードの記述と実行、ファイルの管理、ウェブブラウジングを行うことができます。コードサンプルと仕様については、[Antigravity Agent](https://ai.google.dev/gemini-api/docs/antigravity-agent) ガイドをご覧ください。
