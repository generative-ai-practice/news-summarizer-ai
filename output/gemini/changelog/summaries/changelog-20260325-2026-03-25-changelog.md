# 2026年3月25日 変更履歴

- [Lyria 3](https://ai.google.dev/gemini-api/docs/music-generation) 音楽生成モデルをリリースしました：[`lyria-3-clip-preview`](https://ai.google.dev/gemini-api/docs/models/lyria-3-clip-preview) (30秒クリップ) および [`lyria-3-pro-preview`](https://ai.google.dev/gemini-api/docs/models/lyria-3-pro-preview) (フルレングスの楽曲)。両モデルはテキストと画像入力を受け付け、高品質な48kHzステレオオーディオを生成します。詳細は[音楽生成](https://ai.google.dev/gemini-api/docs/music-generation)ガイドおよびコードサンプルをご覧ください。
