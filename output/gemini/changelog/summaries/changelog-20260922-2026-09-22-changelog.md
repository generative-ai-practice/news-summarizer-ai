## Updates (translated)
# 2026-09-22 変更履歴

- **Gemini 3.8 Flash TTSとGemini 3.8 Flash-Lite TTSの一般提供開始（GA）** : 次世代のテキスト読み上げ（TTS）オーディオモデルとGemini API Voicesエンドポイント (`/v1beta/voices`) をリリースしました:
- **[Gemini 3.8 Flash TTS](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-tts) (`gemini-3.8-flash-tts`)**: スタジオ品質の音声忠実度、微妙な表現の演技、地方の方言、長文での複数ターン対話の安定性を実現するために設計された、主要なクリエイティブTTSモデルです。
- **[Gemini 3.8 Flash-Lite TTS](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-lite-tts) (`gemini-3.8-flash-lite-tts`)** : 高スループットのプロダクションおよびリアルタイムの音声エージェントカスケード向けに`gemini-3.1-flash-tts-preview`を置き換えるために構築された、高速で費用対効果の高いTTSモデルです。
- **[音声デザイン](https://ai.google.dev/gemini-api/docs/voice-design)、[音声複製](https://ai.google.dev/gemini-api/docs/voice-replication)、および[拡張音声ライブラリ](https://ai.google.dev/gemini-api/docs/speech-generation#voice-library)**: テキストプロンプトから永続的なカスタム音声ペルソナを作成し、同意確認付きで音声を複製し、150以上の事前構築済みおよびカスタムの音声を利用できます。
- 開始するには、[テキスト読み上げガイド](https://ai.google.dev/gemini-api/docs/speech-generation)をご覧ください。
