```markdown
# 2026-09-22 変更履歴

- **Gemini 3.8 Flash TTS および Gemini 3.8 Flash-Lite TTS 一般提供開始 (GA)** : 次世代のテキスト読み上げ (TTS) オーディオモデルと
  Gemini API Voices エンドポイント (`/v1beta/voices`) をリリースしました。
- **[Gemini 3.8 Flash TTS](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-tts)
  (`gemini-3.8-flash-tts`)**: スタジオグレードの音声忠実度、ニュアンスのある演技、地域の方言、および長文の複数ターンでの安定性のために設計された、旗艦となるクリエイティブなTTSモデルです。
- **[Gemini 3.8 Flash-Lite TTS](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-lite-tts)
  (`gemini-3.8-flash-lite-tts`)** : 高スループットのプロダクションおよびリアルタイムの音声エージェントカスケードのために`gemini-3.1-flash-tts-preview`を置き換えるように構築された、高速で費用対効果の高いTTSモデルです。
- **[音声デザイン](https://ai.google.dev/gemini-api/docs/voice-design)、
  [音声複製](https://ai.google.dev/gemini-api/docs/voice-replication)、および
  [拡張音声ライブラリ](https://ai.google.dev/gemini-api/docs/speech-generation#voice-library)**: テキストプロンプトから永続的なカスタム音声ペルソナを作成し、同意確認を伴う音声を複製し、150以上の事前構築済みおよびカスタム音声をクエリできます。
- 開始するには、[テキスト読み上げガイド](https://ai.google.dev/gemini-api/docs/speech-generation)を参照してください。
```
