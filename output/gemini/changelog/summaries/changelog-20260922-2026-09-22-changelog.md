## Updates (translated)
# 2026年9月22日 変更履歴

-   **Gemini 3.8 Flash TTS および Gemini 3.8 Flash-Lite TTS が一般提供開始 (GA)**: 次世代のテキスト読み上げ (TTS) オーディオモデルと Gemini API Voices エンドポイント (`/v1beta/voices`) をリリースしました:
    -   **[Gemini 3.8 Flash TTS](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-tts) (`gemini-3.8-flash-tts`)**: スタジオ品質の音声忠実度、ニュアンスのある演技、地域の方言、長尺の複数ターンの安定性のために設計された、フラッグシップのクリエイティブ TTS モデル。
    -   **[Gemini 3.8 Flash-Lite TTS](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-lite-tts) (`gemini-3.8-flash-lite-tts`)**: 高スループットのプロダクションとリアルタイム音声エージェントのカスケードにおいて、`gemini-3.1-flash-tts-preview` を置き換えるために構築された、高速かつ費用対効果の高い TTS モデル。
    -   **[音声デザイン](https://ai.google.dev/gemini-api/docs/voice-design)、[音声複製](https://ai.google.dev/gemini-api/docs/voice-replication)、および[拡張音声ライブラリ](https://ai.google.dev/gemini-api/docs/speech-generation#voice-library)**: テキストプロンプトから永続的なカスタム音声ペルソナを作成し、同意確認の上で音声を複製し、150以上の事前構築済みおよびカスタムの音声を照会します。
-   開始するには、[テキスト読み上げガイド](https://ai.google.dev/gemini-api/docs/speech-generation)をご覧ください。
