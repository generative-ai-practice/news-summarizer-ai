# 2026-09-15 changelog

- **Gemini 3.8 Live および Gemini 3.8 Live Extended Thinking が一般提供 (GA) 開始**: Live API を使用したリアルタイム音声アプリケーション向けに、2つの新しいオーディオからオーディオへのモデルをリリースしました。
- **Gemini 3.8 Live** ([`gemini-3.8-live`](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-live)): ほとんどの低遅延音声エージェント体験や、推論遅延のないリアルタイム対話におけるデフォルトのオプションです。インターリーブ推論、デフォルトの非同期関数呼び出し、およびフルセッションのクライアントコンテンツ更新を特徴とします。
- **Gemini 3.8 Live Extended Thinking** ([`gemini-3.8-live-extended-thinking`](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-live-extended-thinking)): ライブ音声インタラクション中にバックグラウンド推論をサポートする高推論オーディオからオーディオへのモデルで、より高度なバックグラウンド推論が必要な場合に推奨されます。
- 開始するには、[Live API ガイド](https://ai.google.dev/gemini-api/docs/live-api)、[機能ガイド](https://ai.google.dev/gemini-api/docs/live-api/capabilities)、および[思考ガイド](https://ai.google.dev/gemini-api/docs/live-api/thinking)を参照してください。
