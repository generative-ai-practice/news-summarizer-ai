## Updates (translated)
# 2026-09-15 変更履歴

- **Gemini 3.8 Live および Gemini 3.8 Live Extended Thinking の一般提供開始 (GA)**: Live API を使用したリアルタイム音声アプリケーション向けに、2つの新しいオーディオ・ツー・オーディオモデルをリリースしました。
    - **Gemini 3.8 Live** ([`gemini-3.8-live`](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-live)): ほとんどの低遅延音声エージェント体験や、推論の遅延なしでリアルタイム対話を行う場合のデフォルトオプションです。インターリーブ推論、デフォルトの非同期関数呼び出し、および完全なセッションクライアントコンテンツの更新が特徴です。
    - **Gemini 3.8 Live Extended Thinking** ([`gemini-3.8-live-extended-thinking`](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-live-extended-thinking)): ライブオーディオインタラクション中にバックグラウンド推論をサポートする高推論オーディオ・ツー・オーディオモデルで、より高度なバックグラウンド推論が必要な場合に推奨されます。
- 開始するには、[Live API ガイド](https://ai.google.dev/gemini-api/docs/live-api)、[機能ガイド](https://ai.google.dev/gemini-api/docs/live-api/capabilities)、および[思考ガイド](https://ai.google.dev/gemini-api/docs/live-api/thinking)を参照してください。
