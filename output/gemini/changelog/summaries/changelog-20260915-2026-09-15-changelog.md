## Updates (translated)
# 2026-09-15 変更履歴

- **Gemini 3.8 Live および Gemini 3.8 Live Extended Thinking が一般提供開始 (GA)**: Live API を使用したリアルタイム音声アプリケーション向けの2つの新しいオーディオ・トゥ・オーディオ モデルをリリースしました。
- **Gemini 3.8 Live** ([`gemini-3.8-live`](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-live)): ほとんどの低レイテンシー音声エージェント体験や、推論遅延のないリアルタイム対話のデフォルトオプションです。インターリーブされた推論、デフォルトの非同期関数呼び出し、およびセッション全体のクライアントコンテンツ更新が特徴です。
- **Gemini 3.8 Live Extended Thinking** ([`gemini-3.8-live-extended-thinking`](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-live-extended-thinking)): ライブ音声対話中にバックグラウンド推論をサポートする高推論オーディオ・トゥ・オーディオ モデルで、より高度なバックグラウンド推論が必要な場合に推奨されます。
- 使用を開始するには、[Live API ガイド](https://ai.google.dev/gemini-api/docs/live-api)、[機能ガイド](https://ai.google.dev/gemini-api/docs/live-api/capabilities)、および[思考ガイド](https://ai.google.dev/gemini-api/docs/live-api/thinking)を参照してください。
