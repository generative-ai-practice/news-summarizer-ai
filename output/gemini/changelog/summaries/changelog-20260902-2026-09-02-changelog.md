# 2026年9月2日 変更履歴

- **Gemini 3.8 Flash 一般提供 (GA)** : リリースされました
- `gemini-3.8-flash` は、当社の最もインテリジェントなFlashモデルであり、
- 長期的なソフトウェアエンジニアリング、自律エージェント、および複雑なエンタープライズ
- ワークフロー向けに設計されています。
- 利用を開始するには、
- [Gemini 3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash) モデルページと
- [Gemini 3.8 Flash ガイド](https://ai.google.dev/gemini-api/docs/whats-new-gemini-3.8) をご覧ください。
