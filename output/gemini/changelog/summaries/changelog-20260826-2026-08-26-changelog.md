# 2026年8月26日 変更履歴

- **Gemini 3.5 Transcribe 一般提供開始 (GA)**: 専用の2つの
- Geminiの音声理解に基づいた音声認識モデルをリリースしました:
- **Gemini 3.5 Transcribe** (`gemini-3.5-transcribe`): 85以上の言語に対応した発話ベースの言語検出、話者分離、単語レベルのタイムスタンプ、カスタム語彙バイアス（最大1,000語）を備えた、高精度で低遅延の非ストリーミング音声認識機能です。
- **Gemini 3.5 Transcribe Live** (`gemini-3.5-transcribe-live`): Live APIを使用したWebSocket経由での低遅延な双方向ストリーミング音声認識機能で、暫定および最終的な文字起こしイベント、スマート文字起こしモード、複数の音声活動検出（VAD）戦略をサポートしています。
- 開始するには、以下をご覧ください。
- [音声文字起こしガイド](https://ai.google.dev/gemini-api/docs/transcribe)、
- [ライブ文字起こしガイド](https://ai.google.dev/gemini-api/docs/live-api/live-transcribe)、および
- [Gemini 3.5 Transcribe モデルページ](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-transcribe)。
