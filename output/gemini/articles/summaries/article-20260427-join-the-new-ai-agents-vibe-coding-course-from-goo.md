# Join the new AI Agents Vibe Coding Course from Google and Kaggle

## Key Points
- GoogleとKaggleは、2026年6月15日から19日まで5日間の無料AI Agents Intensive Courseを再開します。
- このオンラインコースでは、自然言語を主なプログラミングインターフェースとする「vibe coding」を用いて、強力なAIエージェントを構築する方法を深く掘り下げます。
- プログラムには、最新のコンテンツ、新しい講演者、実践的なキャップストーンプロジェクトが含まれ、全て無料で提供されます。
- 受講者は、ツールやAPIを統合して「10xエージェント」を作成し、実稼働に対応した堅牢なエージェントシステムを設計、構築、展開するスキルを習得できます。
- コースの登録は現在ウェブサイトで受け付けています。
