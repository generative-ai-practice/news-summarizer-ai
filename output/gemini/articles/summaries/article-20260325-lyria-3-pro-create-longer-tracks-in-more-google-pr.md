# Lyria 3 Pro: Create longer tracks in more Google products

## Key Points
- 「Lyria 3 Pro」は、より多くのGoogle製品で、より長く、カスタマイズされた音楽トラックの作成を可能にします。
- Lyria 3 Proは、イントロ、バース、コーラス、ブリッジを含む最大3分間の楽曲を生成できます。
- 現在、Vertex AI、Google AI Studio、Gemini、Google VidsでLyria 3 Proを利用できます。
- Googleは、責任あるAI音楽ツールの開発のため、ミュージシャンと協力してLyria 3 Proを開発しています。
- Lyria 3 Proの出力にはウォーターマークが埋め込まれており、既存のアーティストの模倣を避けるように設計されています。
