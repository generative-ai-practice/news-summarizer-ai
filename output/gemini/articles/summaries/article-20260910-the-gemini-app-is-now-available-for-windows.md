# The Gemini app is now available for Windows

## Key Points
- GeminiアプリがWindows向けにリリースされ、お気に入りのツールや日常のアプリケーションと連携してデスクトップから直接AIアシスタンスを利用できるようになりました。
- Alt + Spaceショートカットを使ってGeminiを瞬時に開き、ドキュメントの事実確認やプレゼンテーションのタイトル案作成など、作業の流れを中断せずに支援を受けられます。
- アプリ内では、Gemini Sparkに多段階のタスクを委ねたり、GmailやGoogle Driveから情報を引き出してプロジェクトの概要を作成したりできます。
- Nano Bananaでカスタム画像を生成したり、Gemini Omniで高品質な動画を制作したりするなど、クリエイティブな作業もデスクトップから手軽に行えます。
- このアプリは軽量設計でPCの動作を遅くすることなく、Windows 10および11向けに2026年9月10日より全世界で利用可能になりました。
