# Have more fun at the state fair with these Google tools

## Key Points
- Googleツールを活用することで、州の祭典をより楽しく計画し、探索し、思い出を作ることができます。
- Geminiを使えば、コンサートや展示、休憩時間などを含む個別の旅程を数秒で作成し、効率的に回れます。
- GoogleマップのAsk Maps機能でリアルタイムの交通情報を確認し、会場内の充電ステーションや給水所など必要な施設を簡単に見つけられます。
- SearchのAIモードやGemini Live、Search Liveを通じて、最高の屋台料理を発見したり、カメラで展示物についてリアルタイムで質問し、情報を得たりできます。
- Geminiの画像生成機能を利用して、撮った写真を1950年代のヴィンテージはがき風にしたり、自分をロデオチャンピオンにするなど、創造的な記念品を作成できます。アイオワ、ミネソタ、テキサスの州の祭典（8月13-15日、8月27-29日、10月9-10日）では、Gemini Visitor Centerでこれらの機能を体験できます。
