# June Pixel Drop: New features for creators, Gemini upgrades and more

## Key Points
- June Pixel Dropでは、AIを活用した新しいツールや機能がPixelデバイスに導入されます。
- スクリーンレコーディングに自分のセルフィー動画を直接追加できる「Screen reactions」機能が利用可能になります。
- Geminiは、テキスト、画像、動画を組み合わせたカスタム動画の作成、オリジナル音楽トラックの生成、写真編集をサポートします。
- 新しい「Bubbles」機能により、あらゆるアプリをフローティングウィンドウに変えてマルチタスクを容易にこなせます。
- 緊急機能が強化され、衝突検出、転倒検出、脈拍喪失検出時に自動的に緊急連絡先に通知されるようになりました。
