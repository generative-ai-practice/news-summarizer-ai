# Intelligent transcription with Gemini 3.5 Transcribe

## Key Points
- Gemini 3.5 Transcribeは、インテリジェントな音声インタラクション向けに設計された、Googleの最も正確な音声テキスト変換モデルです。
- このモデルは、背景ノイズ、複雑な専門用語、および言い淀みを処理し、生の音声を正確で洗練された形式のテキストに直接変換します。
- 開発者は、リアルタイムストリーミング用のLive API (`gemini-3.5-transcribe-live`) と、事前に録音されたオーディオ処理用のInteractions API (`gemini-3.5-transcribe`) を通じて利用できます。
- 以前のモデルChirp 3と比較して、最終的な文字起こしまでの時間が70%短縮され、ストリーミングで4.0%、非ストリーミングで2.6%の単語誤り率（WER）を達成しています。
- スマートな文字起こし、カスタム語彙の認識、85以上の言語サポート、および最大3人までのマルチスピーカー識別機能を提供します。
